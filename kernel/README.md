# 固定期货内核

本目录集中全部 Rust 内核模块；父目录不是 crate，不提供替换、安装、激活或停用入口。项目只做期货，不预建其他资产领域。

| 目录 | 层级 | 职责 |
|---|---|---|
| `foundation/` | L0 | 标识、错误、时间契约、十进制及纯校验 |
| `mechanisms/` | L1 | 授权、任务/租约、事务、工件、通信、诊断与进程 |
| `futures/*` | L2 | 身份、交易时间、规则、行情、角色及账户等固定期货语义 |

依赖从领域指向机制和基础，L2 同层依赖遵循[架构白名单](../docs/architecture.md#层级与模块)。应用编排位于顶层 `services/`，内置来源与券商适配位于顶层 `adapters/`，两者都属于 L3。

目录归类不表示能力完成：`execution` 当前仍是有限日线账户，`continuous`、`rollover` 尚无实现；通用插件宿主仍待收缩为策略宿主。实现与真实验证范围见[进度](../docs/ROADMAP.md)和[期货领域基线](../docs/futures-domain.md)。
