# 实时行情状态 · L2

Rust 独占每个连接的有界报价缓存、订阅筛选、会话代次、乱序拒绝、时间状态及以昨结算为基准的涨跌计算。最多 50 个订阅；未知订阅不能累积错误记录。配置修订变化清空缓存，重新连接时旧代次报价保持非当前状态，直到新代次收到报价。

`QuoteEvent` / `Quote` 的 Rust schema 生成 Python DTO；Python 仅转换参数和结果。CTP 字段解析仍在 L3 接入插件，用户自选文件、业务 API 和来源目录编排仍在 L3 应用，界面在 L4。领域状态不进入通用内核。

当前接入为只读报价投影，没有无损行情队列、行情归档、完整来源序号缺口检测或交易执行许可；时间状态不证明供应商数据完整。规范实际合约的持久身份与交易时段绑定、原生 L2 的完整宿主装配仍需进一步收敛，不能据此宣称整个 market-feed 已通过实盘验收。

回归覆盖有限数字与十进制涨跌、旧代次回调、重连、迟到及未来时间、来源交易所冲突、订阅更新的原子校验与配置修订失效。
