# 上期所库存周报样本

JSON 截取下列原报的明细与合计，省略排序和排版字段，数量与时间保持原值：

- [2014-05-23](https://www.shfe.com.cn/data/tradedata/future/weeklydata/20140523weeklystock.dat)：铜库存、重复合计、同名沥青仓库与厂库，以及独立的黄金库存汇总。
- [2025-01-03](https://www.shfe.com.cn/data/tradedata/future/weeklydata/20250103weeklystock.dat)：括号中的仓库类型、独立燃料油分表与品级、黄金明细占位和汇总、能源中心分表、更新时间。

[官网库存周报](https://www.shfe.com.cn/reports/tradedata/dailyandweeklydata/?query_params=weeklystock)将黄金三列标为上周库存、本周库存、库存增减，注释说明库存为已注册成标准仓单的黄金数量；其余品种分别列库存小计、期货及可用库容量。
