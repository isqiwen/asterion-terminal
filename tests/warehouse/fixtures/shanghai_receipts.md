# 上期所与能源中心仓单样本

JSON 截取下列原始报告的仓库明细与合计，省略排序和排版字段，数量及时间保持原值：

- [上期所 2018-11-13](https://www.shfe.com.cn/data/tradedata/future/dailydata/20181113dailystock.dat)：包含 Tushare 缺失的仓库、黄金单位及原油跨所记录。
- [能源中心 2018-11-13](https://www.ine.cn/data/tradedata/future/dailydata/20181113dailystock.dat)：完整的八个仓库及合计。
- [上期所 2025-01-03](https://www.shfe.com.cn/data/tradedata/future/dailydata/20250103dailystock.dat)：普通铜与国际铜的品种代码、JSON 数值数量。
