| --- | --- | --- |

| Order & Execution | 基础实现：限价单状态、部分成交、成交幂等和终态保护 | 撤改单回报、外部乱序归一化、授权执行链、持久恢复 |
| Position & Portfolio | 基础实现：单合约、多空逐笔持仓、今昨桶、FIFO 成本与盈亏 | 统一持仓/组合、成本与盈亏、重放一致性 |
| Account & Balance | 基础实现：Decimal 账本、冻结、保证金、手续费、成交去重和恢复 | 资金、冻结、余额、费用与统一账本 |
| Calendar & Settlement | 基础实现：显式价格手动结算、今仓转昨仓；显式交易日/UTC 时段、CSV 结算表不可变发布、回测/策略版本绑定、交易进程日终约束与逐日结算恢复；无交易所日历自动补全 | 时区、夜盘、休市、交易日、结算、资产规则与恢复 |
| Risk Foundation | 基础实现：开仓资金、平仓可用数量、步长与重复回报校验 | 强制检查的不可绕过执行链、拒绝语义与风险上下文 |

## 已实现契约的边界

- Decimal 是固定八位小数，非任意精度。没有隐式舍入、浮点输入、指数或千分位格式；乘法无法精确表示时拒绝。除法和步长量化默认要求精确，调用方可以显式选择截断、向下、向上或半偶舍入。不能据此宣布所有资产的金融精度要求都已覆盖。
- Instrument 分类支持七类资产，但分类本身不是结算/保证金/合约规则。允许负的衍生品价格；具体资产的合法价格规则尚未实现。
- Order 处理归一化后的本地限价订单生命周期，不能直接代替券商回报恢复层。终态后的新成交拒绝；重复的已知成交幂等。FuturesAccount 在此之上补齐单合约持仓、冻结、每手费用、账本与手动结算，非完整券商账户模型。
- EventBus 是同步单线程控制面分发，不是高吞吐行情引擎。订阅变更下一次生效，保留有状态回调；某回调异常后仍通知其他回调，最后重新抛出首个异常。调用方不能简单重发整个事件来重试某个回调。
- CSV 在读取时逐行校验，后续行错误不会撤销已分发的前缀；失败后源进入失败状态，不能跳过坏行继续。CLI 只有整个文件成功读取后才输出成功摘要；这不是原子导入或已发布数据版本。
- Terminal 的历史预览在完整文件校验后才替换当前会话状态；失败保留此前成功的预览。预览本身不是持久发布；用户显式提交 Data Pipeline 任务后，完成结果保存不可变数据版本与来源证据，可在删除原文件、重启服务后恢复。尚无跨服务统一数据目录或行情覆盖结论。期货交割月份和规格由用户手动提供，不是交易所验证资料。
- 当前只有明确标识的历史模拟执行入口，没有实盘执行或真实数据凭据验证。桌面 UI 使用本机 C ABI；交易服务可显式配置 TCP+mTLS 监听，Terminal 作为客户端连接。开发服务器限制在本机。模拟测试数据只写在测试源码与测试临时目录。

## 交付顺序

按维护者最新优先级，先交付 Asterion Terminal 与期货业务。原工作台到 C++ 历史模拟链路已接通，单合约账户、持仓、冻结、手动结算和文件日志恢复已实现。接下来完善交易日/规格来源、可插拔风险规则与真实数据接入；订单限额 RiskPort 与单合约显式多日回测已接入，但不能等同于完整风险体系、交易所日历或实盘链路。随后逐个接真实数据源、券商、策略 SDK 和其他 UI。所有阶段保留图中的完整目标，状态由实现与验收证据更新。

历史模拟执行和文件存储的契约、算法假设、容量与恢复边界详见 [期货模拟交易](paper-trading.md)。

独立交易进程、CLI11、Protobuf 与后续 market-data 的当前边界见 [进程架构](process-architecture.md)。交易进程与桌面隔离已经实现，不能据此宣称不可信策略沙箱或实盘可用。

跨机器部署：已实现模拟交易服务独立存活、TCP+mTLS、Terminal 具名连接配置、重新附着与服务端日志恢复。交易服务已支持有界并发连接；Node Agent 已提供模拟、行情、研究与可信策略服务部署、监督和有限重启。细粒度证书授权和实盘执行未实现。测试与部署边界见进程架构和 terminal-validation。

默认本机与 Node Agent：后台专用心跳、节点/进程/业务状态区分、多节点监控、程序分块上传、SHA-256 与原生平台校验、部署/启动/停止、有限重启已接入；本机 OS 用户任务注册已接入；本机注销后机器级常驻、在线升级和跨节点迁移尚未实现；远端 SSH 系统服务注册已有实现，远程范围仅 Linux，仍需物理目标机验收；本机三平台的系统服务升级验收不能相互替代，校验边界见服务管理文档。详见 service-management。

部署防火墙：应用层已实现 SSH / Agent Protobuf 检查、单来源 IP 与端口预览、显式确认、状态重检、受管规则撤销和 TLS 连通性反馈。Linux UFW 与 Windows 适配已接入；macOS 提示手动配置，其他后端及外部安全组不自动修改。Linux/macOS 原生回归和真实 Linux 只读检查已执行，特权写入与 Windows 实机仍未验收；范围见 service-management。

Linux 专用账户初始化脚本和受限 systemd 注册入口已实现，权限与未验证范围见 [机器初始化](host-initialization.md)。实际 Linux 特权初始化仍待验收；远程 Windows/macOS 已明确不在支持范围，本机三平台支持保留。


桌面分发内置同版本的本机服务、Linux x86_64 远程服务及 Linux 初始化脚本。Terminal 提供脚本导出，自动探测远端架构并选择内置程序；不要求用户下载部署材料或选择可执行文件。Linux x86_64 构建产物由 CI 汇集，校验版本、架构和摘要后打入每种桌面安装包。
