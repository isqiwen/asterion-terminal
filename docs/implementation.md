## 已实现契约的边界

- Decimal 是固定八位小数，非任意精度。没有隐式舍入、浮点输入、指数或千分位格式；乘法无法精确表示时拒绝。除法和步长量化默认要求精确，调用方可以显式选择截断、向下、向上或半偶舍入。不能据此宣布所有资产的金融精度要求都已覆盖。
- Instrument 分类支持七类资产，但分类本身不是结算/保证金/合约规则。允许负的衍生品价格；具体资产的合法价格规则尚未实现。
- Order 处理归一化后的本地限价订单生命周期，不能直接代替券商回报恢复层。终态后的新成交拒绝；重复的已知成交幂等。FuturesAccount 在此之上补齐单合约持仓、冻结、每手费用、账本与手动结算，非完整券商账户模型。
- EventBus 是同步单线程控制面分发，不是高吞吐行情引擎。订阅变更下一次生效，保留有状态回调；某回调异常后仍通知其他回调，最后重新抛出首个异常。调用方不能简单重发整个事件来重试某个回调。
- CSV 在读取时逐行校验，后续行错误不会撤销已分发的前缀；失败后源进入失败状态，不能跳过坏行继续。CLI 只有整个文件成功读取后才输出成功摘要；这不是原子导入或已发布数据版本。
- Terminal 的历史预览在完整文件校验后才替换当前会话状态；失败保留此前成功的预览。预览本身不是持久发布；用户显式提交 Data Pipeline 任务后，完成结果保存不可变数据版本与来源证据，可在删除原文件、重启服务后恢复。尚无跨服务统一数据目录或行情覆盖结论。期货交割月份和规格由用户手动提供，不是交易所验证资料。
- 当前只有明确标识的历史模拟执行入口，没有实盘执行或真实数据凭据验证。桌面 UI 使用本机 C ABI；交易服务可显式配置 TCP+mTLS 监听，Terminal 作为客户端连接。开发服务器限制在本机。模拟测试数据只写在测试源码与测试临时目录。
