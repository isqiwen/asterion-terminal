# Python 研究服务（lab）

`asterion_lab` 是每个本机节点上的 Python 服务，代码在 `apps/services/lab/`，用随包 Python 以
`python3 -I -B -m asterion_lab` 运行，由 Node Agent 托管（见[服务](services.md)）。它按计划逐步接管
历史数据与研究；现在负责期货数据仓库和 Tushare 采集。旧的 Data 服务在过渡期间照常工作，两边互不读写。

## 协议

请求与回复是 `protocol/proto/asterion/lab.proto` 中的 `Request` / `Response`，经本机 Unix socket 以
4 字节大端长度分帧，每个请求带 `service_id` 和 `correlation_id`。

| 请求 | 作用 |
| --- | --- |
| `health` | 实例、版本、运行时长，以及内存中持有凭据的数据源 |
| `configure_source` | 只由 Terminal 原生层发送（命令 `lab.source.configure`）：从钥匙串读出已保存的 Tushare 凭据和每分钟请求上限交给服务。凭据只留在服务内存，不经过界面，服务重启后需再次发送 |
| `acquire` | 采集 `[begin_day, end_day]` 内全部交易所的日历、合约表和日线 |
| `tasks` / `cancel` | 采集任务的进度与取消 |
| `summary` | 当前数据集版本及各表行数、分区数和日期范围 |
| `coverage` | 每个品种每个月有日线的天数和交易所开市天数 |
| `daily_bars` | 一个合约在一段日期内的日线，数值为精确小数文本 |

## 数据仓库

位于服务目录下的 `warehouse/`：

```
warehouse/files/<表>/<交易所>/<分区>-<摘要>.parquet
warehouse/versions/<版本>.json
warehouse/current
```

| 表 | 分区 | 内容 |
| --- | --- | --- |
| `daily` | 交易所 × 月 | 每个合约每个交易日一行：开高低收、结算、前收、前结算、成交量、成交额（元）、持仓及变化、交割结算价 |
| `calendar` | 交易所 × 年 | 每个自然日是否开市、前一交易日 |
| `contracts` | 交易所 | 带交割月份的合约：合约标识 `交易所/品种/YYYY-MM`、上市与退市日、乘数、单位、报价与交割说明、交易时间说明 |

- 分区文件写入后不再改动，文件名带内容的 SHA-256 前缀；写入经临时文件、落盘、改名发布。
- 数据集版本是全部分区文件及其摘要的清单，版本号是清单本身的 SHA-256。`current` 指向最新版本。
  旧版本和它引用的文件保留，不改写、不删除。
- 数值以 `DECIMAL(28, 6)` 精确保存。来源数字从 JSON 原文按十进制读取，超过 6 位小数的值让采集失败，
  不做舍入。
- 查询用 DuckDB 直接读取当前版本的文件。只有采集写入仓库，而且只通过提交新版本写入。

## 采集

同一时间只运行一个采集任务，在独立线程中执行：

1. 每个交易所每年的日历：没有存过的年份，以及当年，各请求一次。
2. 每个交易所的合约表各请求一次，按当天快照保存。
3. 区间内每个开市日、每个交易所请求一次日线，已入库的日子跳过。来源当天还没有数据的日子不算入库，
   下次再请求。每完成一个交易所的一个月就提交一个版本；任务失败、取消或服务停止时，已经读到的日子
   仍写入，只丢失尚未提交的部分。

请求经同一个每分钟额度发出，额度来自已保存的设置。规则与旧 Tushare 插件一致：

- 只保留带交割月份的合约代码；Tushare 自己的主力、连续代码和月均价合约不保存。
- 郑商所代码的年份只有一位，十年重复一次，Tushare 补的年代并不总对；对不上时按“字母加末三位、
  当天在市”找到所指合约。
- 当天没有连续竞价成交的合约，上期所、能源中心给空值，郑商所、大商所、广期所给 0；两者都存为空值。
- 成交额按万元发布，存为元。
- 返回行数达到接口上限的答复可能不完整，整个任务失败，不存部分结果。
- Tushare 的拒绝分为凭据无效、无权限、达到频率上限和其他错误；错误与日志不含 token。

## 限制

- 只有日历、合约表和日线；交易时段、主力连续、分钟线和录制尚未接入。
- 采集任务只在内存中登记，服务重启后列表清空；已提交的数据保留，重新提交同一区间只补缺。
- 只有本机节点有 lab 服务。
