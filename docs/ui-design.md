# Terminal 界面设计

## 最新视觉与多客户端决定

维护者要求对齐同花顺期货通的 UI 与界面操作逻辑。当前仅实施 macOS Terminal，其他客户端与平台范围以 `AGENTS.md` 的最新决定为准。已完成本机市场、自选、合约及周期切换的实际操作观察，证据与本轮对齐边界见 [期货通交互观察](futures-ui-observations.md)。下文历史验收记录保留为历史，不代表其他客户端仍在实施，也不代表参考产品的全部交互已复现。

## 方向

2026-09-28 按维护者要求，Terminal 采用极简、精密的未来控制台风格，替代此前沿用历史 Rust 分支外观的约束。保留现有业务契约与工作流。科幻感通过比例、精确对齐、受控的色彩和交互反馈表达，不依赖扫描线、装饰性行情、常驻光晕或循环背景动画。

- 深石墨背景分为画布、面板、浮层；琥珀色仅用于当前导航、主要操作和焦点。涨跌色使用独立语义，可按中国/国际习惯切换。
- 正文使用系统无衬线字体，金额、价格、代码使用等宽字体和等宽数字。保留紧凑/舒适密度，焦点轮廓与减少动画偏好。
- 侧栏使用统一的线性 SVG 图标；顶部提供产品/模式栏与搜索工具，不重复显示工作区页签；没有接入的产品类别不提供空按钮。侧栏继续由 Cmd/Ctrl+B 折叠，任务和设置保持原有入口。
- 总览仅展示可用业务状态；未连接行情、未创建账户显示真实空状态。已有布局配置仍有效，不生成假行情填充空白。
- 交易优先展示会话、账户指标和下单操作；开户参数分为账户与保证金、交易费用、委托与持仓限制。策略区独立位于后方，运行授权、撤销、进度和诊断仍可访问。
- 数据、研究、行情使用相同表单、数据表与详情层级；长表格拥有局部滚动区域，小窗口不应撑宽整个页面。
- 设置继续使用独立且可复用的窗口，保持工作台输入；部署技术内容仍按需展开。启动设置与工作台共用主题。

## 实现位置

主题令牌和通用控件位于 `apps/clients/terminal/src/ui/`。宿主导航样式位于 `src/host/workspace/workbench.css`，设置样式位于 `src/settings/settings.css`，插件各自持有业务布局。插件贡献 React 图标节点，宿主不根据插件 ID 硬编码图标；删除无使用者的 `workspace.section`。

## 验收

`visual-layout.spec.ts` 检查中英文五个工作区在 1440/800 像素宽度及设置在 640×440 时的横向布局、页面异常和减少动画偏好，并输出实际页面截图。业务端到端测试继续验证数据导入、研究、策略、账本恢复和窗口状态。

Electron 原生测试验证实际 C++ 桥接、窗口关系、快捷键、跨窗口语言、草稿保留以及整个桌面重启后的模拟账户恢复。浏览器截图不是其他操作系统原生验收的替代；本轮平台证据见交付记录。

本轮完整浏览器回归为 46 通过、1 项 Linux 专属远程部署测试跳过；macOS 与 Linux 原生 Electron 桌面流程通过。构建、lint 和格式检查通过；Windows 与重新打包后的安装体验不在本轮已验证范围。

## 工作区草稿与业务衔接

宿主 `src/host/workspace/drafts.tsx` 提供按插件命名空间隔离的窗口内草稿机制，插件通过公开契约选择保留哪些输入。切换工作区不会删除草稿；重新加载、关闭整个窗口后清空，不写入磁盘，也不跨窗口同步。后台任务、账本及研究结果仍由服务持久化，不能把草稿保留当作业务恢复。

数据插件保留 CSV 合约配置与结算表路径；研究插件保留分析模式、参数、交易日及按研究服务隔离的结算表选择；交易插件保留模拟账户创建配置。手工委托和结算操作不接入通用草稿恢复。插件离开后仍正常卸载，不通过隐藏挂载维持后台副作用。

数据发布、结算表发布及研究提交在结果未知时保留请求编号；相同输入及目的服务下，用户返回工作区点击确认会复用编号，依靠服务端去重，不自动重发。已发布数据提供“使用并开始研究”：成功载入选定版本后才导航，载入失败留在原页。该动作不创建研究任务、不创建交易账户、不提交委托。

`research.spec.ts` 覆盖三种交易日配置的导航保留与刷新清空边界；`paper.spec.ts` 验证开户配置与研究参数隔离；`data-publication.spec.ts` 验证发布版本衔接，以及真实 C++ 已受理任务后丢失回包、离开返回再确认只保留一个任务。Electron 桌面测试也检查数据与研究输入跨导航保留。

## 历史数据页面

数据工作区用低对比度的二级导航区分「历史数据」与「文件与结算表」。历史页复用主题字体、细分隔线和琥珀色焦点，左右排列新建下载与任务／数据集，在窄窗口改为单栏，不用装饰性图表或虚构统计填补空白。数据源只列已实现能力；查询条件按来源保留，凭据不保留。来源、请求区间和校验边界进入数据集详情，路径与摘要进一步折叠。

## 共用行情图表

参考维护者提供的同花顺期货通截图：行情列表旁展示同一合约的分时、成交量与 K 线指标，图表周期栏和标题结构一致。这是静态视觉观察，不代表已验证其内部组件复用或拖动、实时跟随行为。Asterion 保留自身低对比度石墨底色与克制的琥珀焦点。

共享 `packages/client-ui/src/PriceChart.tsx` 提供价格折线、OHLC 蜡烛、成交量、十字光标和已加载记录的视窗交互；历史分钟查看与最近实时报价共用。左右键查看精确记录，+ / − 缩放，拖动或 Shift + 左右键平移，Home 到首段，End 返回当前已加载末尾。图表不获取数据、不补休市记录、不聚合行情、不连接供应商；原始小数字符串用于光标，浮点数仅用于坐标。

实时页面已接入有界事件流的最近报价折线，支持追加跟随和回看；实时分钟聚合、跨页拖动加载和历史／实时衔接尚未完成，不将报价快照或报价事件伪装成完整分钟柱。不同数据源不得无标识拼接。历史查看保留独立分页、区间和来源说明。

## 历史数据仅通过数据源获取

历史行情下载、选择和查看入口统一指向数据源；不提供用户历史 CSV/JSON 导入。桌面「历史数据」保留 Tushare 下载与查看，「数据存档与结算表」只保留已有存档和独立结算配置。移除 UI 插件的 inspect 能力。Web/Mobile 的数据服务未接入时，只显示明确状态，不用文件输入作为替代路径。

## 行情工作台整体重排（2026-09-29）

按期货通参照继续调整整体比例：展开侧栏 48px、折叠 36px，产品/模式栏 24px；减小圆角，强化红／绿涨跌和青色量仓数字。市场默认使用 20px 行高，舒适密度保留放大行距。移除行情页对总览卡片表格样式的依赖，避免总览留白规则覆盖行情密度。

桌面市场列表约占 74%，1250px 以上按交易所双列分组；右侧约占 26%、至少 320px。搜索与交易所筛选合并为一条工具栏。排序列提供 aria-sort，合约选择不随排序跳动，空价格／昨结算不显示虚构涨跌。涨跌为基于昨结算的展示计算，不作为账本或执行依据。

右侧上下联动当前合约：上方为有界最近报价走势，下方为已经下载的同月份合约历史分钟 K 线与成交量。历史数据由 Task Service 分页接口读取，来源和非实时属性明确标识；匹配交易所与月份代码，不使用主力连续代码代替月份合约。自动读取最新提交的已完成数据集，可切换版本、翻页、跳至末页和失败重试；切换合约卸载前一查看器，无数据时提供数据源下载入口。

## 对齐进度与均线（2026-09-29）

来源切换、连接配置与状态收进列表侧同一工具栏，右侧双图从工作区顶部开始；连接配置展开不再推移图表。连接详情放回配置内。交易所使用 CTP 契约中的 SHFE/DCE/CZCE/CFFEX/INE/GFEX。历史 K 线工具栏展示实际数据周期和 MA 开关，数据版本选择折叠。新增 MA5/10/20/30/60，算法属于 Terminal 行情 UI 插件，共享 PriceChart 只接收对齐的曲线值并绘制。均线仅供图形展示，使用浮点计算，不供研究、风控或执行使用。

桌面双图按剩余高度平分伸展，共享 PriceChart 的可选 fitHeight 根据绘图区实际尺寸计算坐标，保持文字字号；窄屏恢复顺序布局。价格轴使用五档刻度与虚线网格，上涨蜡烛空心、下跌蜡烛实心。头部随选中合约显示昨结算涨跌额与百分比；这些都是展示计算。

历史图每页展示 100 根，读取时携带最多 59 根前序记录（请求上限 159，小于服务端 200 上限），保证相同 K 线的均线值在不同页一致。数据集起点不足周期时返回空值，不用零值或短窗口代替。均线随光标显示、随视窗缩放，开关不改变原始数据。

历史行情入口现在列出 Task Service 已完成的月份合约数据，复用 `ContractHistory`，不再展示旧逐笔快照。没有实时行情连接也可查看已下载分钟数据。周期列表来自服务端任务摘要 `minute_interval_minutes`，选择周期读取对应的最新已完成版本；版本下拉仍可选旧的已下载版本。MACD 与成交量在同一副图区切换，价格主图、均线、指标和光标使用同一索引；时间刻度按空间自动减少标签，固定北京时间。

MACD(12,26,9) 的展示算法位于 `plugins/tools/chart_indicators/`。按数据集第一根收盘价初始化两个 EMA，DEA 初始为 0，柱值为 2×(DIFF−DEA)，前 33 根不输出。分钟查询显式传入 `include_macd`，服务端在 Task 状态锁外逐段校验前序数据并推进计算，返回当前页的指标，未读取完整前序时不伪报指标。普通无指标查询保留原来的按需分段读取。首次及每次指标查询目前都需要前序扫描；尚无检查点缓存，大数据集延迟未完成验收。原始价格仍为 Decimal，浮点指标只供展示，不进入账本、风控或研究结果。

数值验证包含单位斜坡的闭式 EMA 对照、预热、跨页、时间筛选、禁用指标、前序损坏拒绝，以及真实 Task Service IPC 的 MACD 和周期摘要读取。浏览器检查覆盖两个已下载周期的不同数据集请求、指标切换、无实时服务的历史入口、合约搜索、1440/2048/800 布局；界面截图使用显式测试数据，不代表生产接入。

macOS 主窗口使用 Electron `hiddenInset` 标题栏，账户栏同时作为可拖动标题区，原生红黄绿按钮保留。账户按钮和权益弹层标记为 no-drag；登录屏顶部保留拖动带。适配代码仅位于 Terminal 宿主，平台标识由受限 preload 提供，不把 Electron 依赖引入共享账户插件。原生测试验证平台标识、拖动/点击区域 CSS、登录和退出、独立设置窗口、快捷键与重启恢复；系统按钮点击、拖动与全屏仍需人工原生验收。Windows/Linux 保留原生标题栏，本轮未进行这两平台的原生 UI 验收。

最近报价图的成交量使用同一合约、同一交易日相邻可用事件的累计量差值。首条、事件缺口、断线、换日或计数回退后的基准报价不绘量柱；换日和回退同时断开旧价格曲线，其他合约保留。量柱采用报价价格方向配色，不代表主动买卖方向。价格、量柱和光标共用视窗，副图高度随面板伸缩，短报价序列时间轴显示到秒。C++ 边界测试与浏览器布局测试覆盖上述接入；没有真实行情账户验收，不将有限报价序列称为完整分时。

最近报价图支持昨结价参考轴：有效且为正的昨结价由实时行情快照传入，价格范围围绕该值对称，左侧显示价格、右侧显示相对昨结价的百分比，并标出零涨跌虚线；红绿刻度表达相对昨结涨跌。缺失、零、负数或非有限参考值不绘制百分比轴。共享图表只接收参考值，不查询或推算昨结价；历史 K 线不启用该轴。浏览器回归覆盖参考价动态变化、无效/缺失参考值、鼠标定位和窄屏布局。全天分时、均价和参考软件隐藏交互仍未完成验收。

市场总览改为两列独立堆叠交易所分组：默认左列上期所/郑商所/大商所，右列中金所/能源中心/广期所；参考截图中的境外市场未接入，不创建伪行情。默认紧凑密度行高 20px，图表区占约 25%；舒适密度仍保留。正常实时状态只在合约详情显示，主行情表取消重复状态列；异常状态与诊断代码在合约旁显示。表头与数值继续共用右对齐边缘。测试使用不同分组长度检验独立堆叠，另覆盖窄屏、排序与真实 C++ 测试行情断线提示。该调整仍不意味着整体 UI 已与参考一致：全市场目录、参考报价字段、产品导航和全天分时等仍有差异。
