# 日线研究策略插件

当前实现遵循“核心提供机制，插件实现功能”。策略、研究成交模型和界面都属于功能插件；核心插件宿主、任务调度和工作台外壳没有增加策略分派分支。

## 当前契约

研究仅接受单实际合约标准日线，收盘产生做多/空仓意图，下一根日线开盘执行。此接口属于日线研究，不是实时交易或任意事件策略协议。

策略作者从 `asterion.research.public` 导入 `Strategy`、`StrategyInfo`、`StrategyRef`、`IntegerParameter`、`DecimalParameter`、`BooleanParameter`、`EnumParameter`、`Choice`、`ClosedBar`。每个策略声明：

- 唯一 ID、版本和实现源码 SHA-256；展示名称、说明、所需 `futures.daily` 数据及 `long-flat-next-open` 执行语义。
- 完整参数字段、名称、类型约束与界面初始值。支持整数、小数、开关和枚举；类型由 `type` 判别，不接受跨类型字段。
- `validate(parameters)` 验证字段间约束；`warmup(parameters)` 返回所需收盘条数（1—4999）。
- `create(parameters)` 每次计算创建独立会话；`close()` 释放会话资源；`on_close(ClosedBar)` 每根日线接收不可变交易日与 Decimal 收盘价，返回严格 bool。

`True` 代表下一开盘目标为研究配置的手数，`False` 代表空仓。策略不能通过该接口指定成交价、费用、保证金或跳过校验。引擎控制预热、下一开盘执行、持仓估值、手续费、滑点和资金约束；预热完成前的意图不执行。策略不取得未来日线、数据服务、账户、存储或凭据端口。

界面初始值只在用户明确选择策略时生成参数，不用于服务端补齐缺失输入。执行参数必须完整，未知字段、布尔值冒充整数、越界值和非法组合全部拒绝。参数改变不会修改已提交运行。

## 参数值契约

- `integer`：`minimum`、`maximum`、`default` 为整数，范围在 JSON/JavaScript 安全整数内；不接受布尔值或字符串冒充整数。
- `decimal`：`minimum`、`maximum`、`default` 和实际值均为十进制文本；`scale` 指定最多 0—12 位小数。最多 40 字符，不接受科学计数法、NaN、Infinity 或 JSON 浮点数。计算时插件显式使用 `Decimal`。保留输入文本及末尾零，不自动改写表示。
- `boolean`：`default` 和实际值必须为 JSON 布尔值，`false` 是完整有效输入。
- `enum`：`choices` 为 `{value,label}` 列表，值唯一且初始值必须属于选项。实际保存稳定字符串 `value`，不用展示名称代替。

共享表单按声明校验类型、范围、精度与选项；小数范围比较使用整数缩放，不经过浮点数。服务端独立执行同一语义校验后，再调用策略的字段间约束。草稿允许空值和未填写的小数文本，执行输入必须完整有效；参数类型随任务、报告及复现包保存，备份检查复用同一声明校验。

## 登记与生命周期

参考 `src/asterion/strategies/sma.py` 和 `momentum.py`。二者分别提供 `asterion.strategy_sma`、`asterion.strategy_momentum` 插件，导出类型为 `Strategy` 的能力。插件启动时生成只读描述和无外部资源的会话工厂。

发行版 `distribution.strategy_plugins()` 显式装配策略插件及 `catalog_plugin(capabilities)`。目录插件通过声明的 `requires`、`consumes` 读取策略能力，拒绝重复 ID、重复参数和非法初始值/预热声明，再导出 `research.strategies`。研究插件声明依赖该能力；缺少必需插件时宿主启动失败。

Worker 和备份校验使用同一发行版清单与真实 PluginHost 激活校验，取得纯策略目录后关闭临时宿主。策略贡献不得持有后台连接、线程或需要宿主维持生命周期的资源。每次回测独立创建会话，无全局信号状态。Worker 只通过声明的 `STRATEGY_RESOURCE` 获得目录；缺少资源不能执行。

新增受信策略只需要提供插件及修改发行版装配清单；研究引擎、API 路由、核心任务分派和业务表单不需要添加策略 ID 分支。`GET /api/v1/research/strategies` 受账户/PIN 与请求权限保护，返回当前激活目录。研究界面通过共享控件自动生成相应参数表单，切换策略会重置参数并要求重新确认研究假设。

## 固定身份和复现

运行参数使用必填 `strategy: {id, version, digest}` 与 `parameters`，不再使用顶层算法专属字段。研究引擎身份为 `daily-session-settlement.v6`。提交、Worker 执行、结果发布、按原输入重跑、复现包核验均验证当前策略身份；任何一项不匹配都拒绝执行，不自动选择另一实现。

实现摘要由内置插件读取自身完整源码计算，包括参数定义、校验、预热和会话算法。当前两个插件均为自包含算法模块；禁止把行为藏入未计入摘要的可变文件。外部多文件策略使用整个 ZIP 工件摘要，覆盖入口、包内依赖和描述。摘要用于识别实现，不是签名、依赖环境镜像或安全认证。语义改变仍需更新策略版本；通用成交语义变化需更新引擎版本。

打包通过 PyInstaller `--collect-all asterion.strategies` 携带源码，源码运行和冻结运行可计算相同摘要。源码缺失则启动失败，不回退到固定常量。

固定身份及参数随草稿、任务输入、结果报告和复现包保存；身份不受支持时可保留事实记录，但不迁移、不改写、不复用当前算法冒充原结果。复现包只含数据，不加载或安装其中声明的可执行代码。

## 验证与边界

契约测试覆盖独立第三个测试插件只靠装配接入、逐根收盘输入、预热及下一开盘、非法信号拒绝、参数严格校验、版本/摘要不匹配、缺失插件拒绝和第二策略结果发布/复现。浏览器覆盖动态策略参数切换、假设重新确认、固定身份提交和草稿/模板恢复。

## 外部策略安装

设置中的本地插件安装支持 `research.strategy`。参考独立样例 `examples/plugins/close-momentum`：复制到仓库外开发，使用公共 `asterion_plugin_sdk` 打包，无需导入终端业务代码或重建应用。安装不执行代码，显式信任并启用后，在研究界面刷新策略即可选择。

声明包含包 ID、名称、说明、类型化参数、`futures.daily`、`long-flat-next-open` 与 `dependencies: stdlib-and-sdk`。包 ID 必须与策略 ID 相同，禁止占用内置命名空间；依赖仅支持标准库、随终端提供的 SDK 和计入 ZIP 的源码。不支持 pip 安装、原生扩展或其他已安装插件依赖。

研究插件把外部声明转换为同一 `Strategy` 贡献。通用进程机制提供可撤销 JSON 行会话，策略领域负责 `strategy.prepare/open/close` 语义。每次回测创建独立进程，逐根发送交易日与收盘价，不发送整段行情、账户或凭据。会话总墙钟时限 30 秒、协议单次输出与错误文件合计限制 8 MB；执行完成或失败均关闭进程组。停用与工件完整性在执行前后再次检查。

安装/启用入口验证所有贡献契约；工件读取机制只验证完整性，消费插件校验自己拥有的领域声明。这使同一个包可被不同领域读取，而不要求核心识别策略或数据源。

固定输入使用整个 ZIP 的 SHA-256；同一 ID/版本不能换内容。移除保留工件，更新不会改写既有运行。执行原运行必须安装并启用完全相同工件；当前每个 ID 只能启用一个版本，不自动切换版本。复现包不携带或安装可执行代码。

备份恢复验证外部研究输入、结果和对应工件的完整性，不自动执行外部策略。报告中的 `research_external_not_recomputed` 明确计数，界面提示这些结果未复算。需要复算时，由用户检查插件后通过研究重跑/复现操作发起。

独立进程是故障边界，不是 OS 沙箱：代码以本机用户权限运行，仍可能访问文件和网络。OS 沙箱、第三方依赖环境锁定、实盘/模拟盘策略接口、多合约、做空和优化任务尚未实现。
