# 终端 UI 规范

2026-09-22 整理。本文只保留当前界面规范；体验要求见 [终端体验](terminal-experience.md)，Fincept 观察与验证边界见 [交互记录](fincept-interaction-review.md)。

## 主题与共享控件

启动、账号入口、工作台和独立设置窗口共用 `presentation/ui-kit/src/theme/tokens.css`；Canvas 图表也读取这些变量。

- 近黑画布、黑灰面板、轻微层次的标题栏；橙色用于当前导航、主操作和焦点。主按钮采用橙色文字、深橙底色及细边框。
- 字体采用 SFMono-Regular / Menlo / Consolas 与中文回退；表格使用等宽数字。控件直角、1px 边框，复用统一高度和紧凑/舒适偏好。
- 成功为绿色、错误为红色；行情涨跌独立遵循红涨绿跌/绿涨红跌偏好。行情红/绿为 `#ff3b30` / `#00c853`，不替换其他状态色。
- 启动、账号入口与空态共用细网格；表格和图表保持清晰的数据背景。插件不引入另一套品牌色、全局字体或窗口框架。
- 可点击控件具备一致悬停、按下、键盘焦点和忙碌反馈；禁用项降低对比度，不出现可点击高亮。反馈不改变尺寸和位置。
- 原生下拉选项及分组显式使用主题背景与文字色，禁用占位使用弱文字色；连接选择占位统一为“选择连接”。

## 信息层级

| 区域 | 默认显示 | 按需展开 |
|---|---|---|
| 业务主视图 | 当前对象、关键结果、适用交易日、更新状态、主要操作 | 必要的业务选择 |
| 配置 | 已选配置摘要 | 连接、规则、候选范围及影响执行的参数 |
| 任务入口 | 阶段、进度、异常摘要 | 统一任务中心中的子任务、错误与恢复 |
| 详情/检查器 | 用户主动打开 | 来源、候选排除、版本、校验依据和完整标识 |

阻断错误和未知信息不能收进详情后隐藏。后台刷新、数据采集和重新计算使用不同名称；交易日、生效时间和更新时间不混用。主视图避免重复刷新按钮、状态表格和长篇机制说明。

## 导航与 Dashboard

主导航固定左侧：展开 64px、收起 40px；图标 16px、文字 12px、行高 40px。展开显示图标和双字标签，收起通过图标与悬停说明识别。顶部标签表示本会话已打开工作区；新工作区默认进入总览，已有合法布局不改写。

Dashboard 默认保留三块：实时报价、账户与持仓、风险概览。无数据仍显示这三块结构；未知金额用 `—`，未知持仓不写成空仓。行情位于左侧，账户/风险在右侧，约 6:4；可用容器小于 1050px 时折为单列。空态不撑满窗口，表格局部滚动、固定表头、数字右对齐。

总览只展示实时来源，不能以历史快照填充报价。历史数据留在市场/研究工作区；合约、版本、联动与检查器等对象工具只在贡献声明 `objectTools` 的工作区显示。只读账户与风险比例不代表交易执行或完整风险评估已经完成。

账户区域上方显示资金摘要，下方显示持仓表。报价列为合约、最新价、涨跌额、涨跌幅、最高、最低、成交量、持仓量、行情时间和状态。最新价及涨跌额/幅按相对昨结算的同一方向着色；平盘、未知基准和缺失值保持中性。账户的持仓/平仓盈亏按正负着色，其余金额和比例中性。状态和正负号始终保留。

工具栏日常显示提醒、刷新与编辑入口；布局增删、位置、宽度、密度、保存与重置在编辑模式出现，取消恢复编辑前状态。Dashboard 自身默认不启用紧凑模式。资讯与热力图按需添加。当前前端贡献通过 `dashboard.widgets` 声明组件与默认位置，overview 管理目录及布局，发行版选择默认组合。目标由独立 L4 面板包提供业务贡献（构建期组合），工作台与共享控件也属于 L4；尚未完成替换，见[模块与层级](architecture.md#层级与模块)和[当前代码归属](engineering-structure.md#当前代码归属)。

提醒默认使用覆盖抽屉，异常数和直接错误保持可见；只有用户主动固定才占用右栏。服务详情复用底栏。保存、移除、重排只修改视图，不启动业务任务；不支持的布局和缺失组件引用保留并说明原因。

## 角色与数据界面

主力角色以品种、主力/次主力实际合约、适用交易日、来源和更新状态为主；供应商报告与自行计算明确分开。采集/计算显示简短阶段，完整候选任务进入任务中心；固定版本、算法校验和、候选排除和原始 JSON 进入详情。

数据目录围绕交易所、品种、实际合约及数据内容组织。同步和覆盖检查复用现有工作区，不按后台接口增加一排独立操作区。简化界面不得放松身份、来源、交易时间、可知性、幂等和完整性校验。具体流程与交付边界由所属领域文档定义。
