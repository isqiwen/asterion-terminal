# 终端统一视觉规范

启动、登录/注册/验证、业务工作台和独立设置窗口共用 `apps/terminal/src/theme/tokens.css`。组件不得自行增加品牌色、蓝灰背景或另一套字体；Canvas 行情图表也读取这些 CSS 变量。

- 底色：近黑画布、黑灰面板与层次轻微的标题栏。
- 强调：统一橙色，用于当前导航、主操作、标题和输入焦点。主按钮使用橙色文字、深橙底色和细边框。
- 字体：SFMono-Regular / Menlo / Consolas 与中文回退；表格数字使用等宽及等宽数字。
- 控件：直角、1px 边框、统一控件高度。保持现有紧凑/舒适密度偏好。
- 网格：启动、账号入口与业务空态共用细网格；数据表和行情图保持独立清晰的数据绘制背景。
- 语义：成功为绿色、错误为红色。行情涨跌继续遵循用户的红涨绿跌/绿涨红跌偏好，不使用品牌橙色替代业务含义。
- 设置仍是独立原生窗口，视觉组件和导航选中态与主工作台一致。

新增界面先复用主题变量和已有控件，再补充必要的局部布局样式。
