# 因子分析

本文说明当前 `asterion-factor` 的动量因子评价行为。任务提交、执行尝试、取消、显式重试和结果复核见 [任务生命周期](tasks.md)。

## K 线动量

- 因子 = `close[i] / close[i-N] − 1`，标签 = `close[i+H] / close[i] − 1`，窗口按 K 线根数计。
- 支持全样本、时间顺序留出和固定窗口滚动验证，可只按前段结果选择回看窗口。

日线和分钟线均可作为 K 线输入。交易日、分钟标签、结算价、覆盖缺口、分段拼接及具名数据集的通用约束见 [数据集输入](market-data.md#数据集输入)。

## 日线动量

日线动量因子直接选择已发布的日线数据版本，基于统一日线格式，保留来源与 manifest 摘要。

两种动量在界面上是同一个“因子”页的两种输入数据（“K 线”和“日线”），提交的仍是两种独立的任务，各自的引擎和结果格式不变。

## 观察与标签隔离

第 i 条信号仅使用截至 i 的收盘序列，未来收益标签在评价器中独立计算，不交给信号
算法。留出与滚动评价剔除跨区间标签；选参只使用允许的训练区间，每轮验证不反向
参与该轮选择。日线信号保留交易日期，不制造日内公布时间。

固定输入保留每个来源版本的完整取得时间与来源可知性证据。当前来源公布时间未知，
结果界面明确为事后统计分析，不能证明历史时点可交易；时间顺序留出并不能单独补足
供应商修订可知性。见[历史时间与可知性](market-data.md#历史时间与可知性)。

## 结果与限制

输出 Pearson 与 Spearman（平均秩）相关性以及逐条对齐记录；零方差时相关性为空。

因子评价只支持单合约，没有显著性检验和年化指标。因子与标签是统计值，使用浮点数，不进入账本。
