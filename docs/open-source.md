# 开源准备与发布门槛

2026-09-22 整理。本文记录尚需完成的发布事项，不构成公开许可、插件市场或社区支持承诺。开发规则以 [AGENTS.md](../AGENTS.md) 为准，架构与目录见 [架构设计](architecture.md)、[工程结构](engineering-structure.md)。

## 当前状态

- 仓库尚无项目 LICENSE，贡献授权及正式分发政策待维护者决定；源码可见不等于取得再分发许可。
- 源码提供 `asterion_plugin_sdk` 和独立数据源/策略样例，可打包为当前插件 ZIP；SDK 尚未发布到公共包索引。
- 支持受信内置扩展和用户明确认可的本地 Python 插件，外部 UI 限于声明式表格。独立进程不构成恶意代码 OS 沙箱；任意 React、原生动态插件和在线市场未开放。
- 正式产品使用真实来源与本地导入。合成数据只供开发与测试，不作为产品演示功能随包发布。
- 平台安装与验证范围见 [桌面运行](desktop-runtime.md)，业务完成范围见 [实施进度](ROADMAP.md)，不以目录或界面入口代表交付。

## 交付边界

默认发行版提供经过验收的插件组合；社区发行配置可选择符合当前契约的插件和工作区，但不能绕过授权、交易准入或数据引用保护。具体扩展协议统一见 [插件系统](plugin-system.md)，不在此维护另一套 SDK 设计。

公开交付物应分别说明源码、SDK、示例、文档、品牌和二进制的授权。发布清单覆盖实际打包的 Python/npm/Rust 依赖、图表库、字体、图标和原生 SDK，记录版本、来源、许可及 NOTICE。数据库由系统包管理器提供，仍需说明运行依赖；代码许可不能代替行情和经纪商 SDK 的使用/分发授权。

LICENSE、商标规则和贡献确认方式由维护者决定并集中落盘，不在多份文档给出不同政策。普通插件不应依赖内部 ORM、私有表、主令牌或全部研究依赖。

## 维护与发布要求

贡献者应能按 [贡献指南](../CONTRIBUTING.md) 在无私有凭据的环境运行相关测试，不必为修改普通表格构建完整安装包。架构变更记录问题、边界、取舍和验收；新增抽象由真实需要证明，不要求凑出没有实际需求的使用场景。

发行说明列出当前平台、契约、破坏性变更及真实验证范围。契约改变时直接替换调用方并拒绝不支持的输入；保留历史记录不代表保留旧执行器。安装替换、锁、停止失败和数据保留规则统一见 [桌面运行](desktop-runtime.md#重复安装与失败保护)，不另设自动迁移或升级回退流程。

外部插件安装说明来源、权限、平台和状态；签名只证明来源与完整性，不证明业务正确。停用和移除遵循引用保护，不能删除研究或任务引用的工件。在线市场不是首个发布前提。

默认不上传行情、账户、策略源码或使用遥测。未来诊断导出应允许预览、选择和脱敏，公开报告不得含凭据、受限制行情或私人路径。公开发布前设置真实可达的私密漏洞报告渠道和维护责任，不虚构邮箱、委员会或支持团队。

## 发布检查

以下为发布门槛，本文件未将其标为已通过：

- 明确 LICENSE、贡献授权、依赖和二进制的来源及分发范围。
- 新贡献者按文档在干净环境跑通测试闭环；独立样例通过当前插件契约测试。
- 发布范围内的插件崩溃、拒绝、不支持契约、离线安装和停用不破坏工作台及固定结果。
- 支持平台的全新安装、当前布局/配置恢复、备份恢复、签名和产物摘要有独立证据。
- README、开发入口、平台表、问题模板、维护责任与私密报告渠道真实有效。
- 默认发行版只展示实际能力；研究和只读账户不能描述为完整实盘系统。

首个公开范围可限定为数据与研究预览，完整交易版另按期货领域验收。是否公开发布及采用何种许可仍由维护者决定。
