## 已实施切片与后续准入

2026-09-22 已完成首批源码替换：旧 Python 身份/日历/规则/角色解析算法、任务决策、加解密、宿主拓扑/权限和重复通信校验已删除；调用方改用 Rust 绑定。混合构建、绑定所有权与固定输入计算已进入自动回归。仍不宜提前冻结未迁移机制的接口。目标目录不是要求一次建立所有插件，更不要求每个插件独立进程或独立发布。

| 在对应实现前必须明确 | 完成依据 |
|---|---|
| 模块组合与计算接口 | 内核与适配器静态组合，无提供者选择；Python 计算接口明确输入/输出、关闭时撤销/等待、失效句柄、错误、取消和资源释放；跨语言共享用例通过 |
| 内核与账户授权 | 固定主体/会话所有者与 L3 identity 获准建立/撤销会话的协议；锁定/退出后旧凭据失效，零插件内核可运行且用户操作拒绝；不照搬当前依赖 access hook 的宿主启动方式 |
| 操作与进程所有者 | 每个首批用户操作固定“入口 → 应用所有者 → 领域能力”；明确只读与写入、权威状态所在进程、单写者及重启恢复，避免同一账户/连接多份状态 |
| 发布、工件与产品更新 | 固定跨语言受限事务句柄、线程/资源所有权，明确工件/领域记录/任务/事件的提交边界及取消、panic、过期租约回滚；停止失败不切换程序，仅加载匹配产品构建，历史工件不改写 |
| 性能预算 | 在固定硬件/构建上记录数据规模、冷热状态、扫描字节、峰值内存、p95/p99 与队列积压；给首批场景明确验收阈值，不能用 Rust 选型代替测量 |

首条业务切片已接线：**固定实际合约与交易时间/规则版本 → Rust 领域计算 → Python 覆盖和研究用例 → 独立面板包**。任务仓储/租约、处理器权限、通信控制、计算进程/二进制结果管道、事务事件、结构化诊断、数据库连接池/物理事务/游标、受限文件、流式备份归档、原子目录发布、凭据校验、恢复准入和进程监督已进入固定 Rust 内核。连接状态和报价计算已由 Rust L2 持有；Python 保留接入对象与应用编排。会话记录撤销仍由获授权账户所有者提交。数据导入、同步、累积分区、原始观察和分钟核对的工件读写已改由 L1 `ArtifactStore` 一次写入并按摘要校验读取。累积分区合并、分区索引核对与分区读取已进入 L2 data-store（Rust），预览、分钟核对、恢复读取与备份核验共用。下一批收敛工件引用登记、非累积标准表编码及独立 L2/L3 激活；完整模拟与交易账务仍按 F4–F6 逐项实现。

首批验收至少覆盖：相同固定输入得到相同身份/交易日；代码歧义、夜盘/特别日缺失和未来信息明确拒绝；序列化与工件身份可核验；错误/取消/资源释放跨语言一致；历史记录原样保留；替换范围没有生产双实现；进程重启及冻结包重读通过。新增界面交互时另行遵守 Fincept 实机要求。

实盘与完整 execution 仍按 F4–F6 准入，须以逐事件账务、重复/乱序/未知发送状态和恢复结果验证。当前[研究发布](../src/asterion/research/service.py)在数据库事务内复算结果，[扫描](../src/asterion/data/scanning.py)仍有逐行 Python 转换；这些是后续数据路径重构要消除的具体成本，不能只翻译为 Rust，也不能直接取消结果校验。
