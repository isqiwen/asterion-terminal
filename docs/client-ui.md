# Terminal 界面与未来客户端复用边界

## 当前实施范围（2026-09-29）

当前只实现和交付 macOS Terminal。Windows/Linux Terminal 暂停开发，仅保留架构可移植性考虑；恢复须由维护者明确批准。Web、Mobile、Notebook 等仅在架构设计上考虑，已删除 Web/Mobile 原型及其专用测试、构建入口；恢复须由维护者明确批准。此决定替代此前持续推进多客户端的计划。Terminal 使用的共享图表继续维护，不为假设中的客户端新增抽象或通用 SDK。后续 AI 以 [AGENTS.md](../AGENTS.md) 的“客户端实施范围”为准。

## Terminal 界面参照

桌面工作台以维护者提供的同花顺期货通界面为完整视觉及交互参照，不再仅抽取图表风格。已收到市场、自选和合约三页截图：窄侧栏、顶部产品及市场分类、按交易所分组的紧凑报价表、右侧上下两个同合约图表、分时／周期栏、成交量与指标副图、底部状态区，以及合约页的自选列表、主图、报价与盘口区域。截图未展示的页面、菜单、快捷键、拖动及窗口状态仍需实际观察，不能声称已经完整复刻。保留 Asterion 产品身份与实际能力边界，不生成虚假行情、指标或不可用操作。

维护者要求直接通过 Computer Use 操作参考软件。实际观察应逐项记录：单击/双击选约的目的页面、跨页选择是否保留、排序循环及空值位置、左右键/上下键的含义、周期切换是否影响另一张图、缩放/拖动/十字光标联动、列表右键菜单与面板尺寸调整。观察前不得将 Asterion 已有的这些行为称为参考软件的实际行为。2026-09-29 本次连接中，期货通进程运行，但按名称、Bundle ID、路径和访达重新打开后，Computer Use 均返回 `timeoutReached`；访达可正常读取。此记录仅证明当前连接失败，不能推定期货通窗口无响应或缺少功能，尚未获得上述交互观察结果。

此前建立的 Web 与 Capacitor Mobile 原型已删除；它们未曾交付完整生产数据服务或原生安装包。历史数据仅允许通过数据源获取。以下复用边界用于架构设计，不构成当前实现任务。

## 可复用内容

- 同一 React DOM 渲染环境：设计令牌、图标、表格、图表、表单及纯展示组件可由桌面和 Web 共用；移动 Web 可共用这些组件，但重新组织布局和触摸操作。
- 无平台依赖的状态与类型：合约选择、周期、视窗、数据集标识、任务状态、错误语义和本地化资源可复用。行情聚合、风控及指标算法仍属于对应功能插件；权威业务规则不复制到每个客户端。
- 平台宿主：Electron 窗口、文件选择、本机服务管理和 Node-API 只属于 Terminal。未来其他客户端的导航与网络连接应由各自宿主适配。共享组件通过明确能力接口调用宿主；不从共享目录反向导入 apps。
- 独立原生 Mobile：可以复用纯 TypeScript 状态与数据契约，但当前 DOM/SVG/CSS 组件不能直接视作原生组件。若用 WebView 承载图表，则须单独验证触摸、性能、可访问性及生命周期。

## 当前代码限制

Terminal 插件契约依赖 TerminalContext、宿主草稿、i18n 与 desktop-bridge 类型；它目前不是跨客户端插件 SDK。PriceChart 已与数据源及桌面桥解耦，已提取到 `packages/client-ui/src/PriceChart.tsx`，由 Terminal 历史页面使用，Web/Mobile 待数据服务接入后复用；没有发布公共 npm 包。

出现第二个实际客户端时，先提取具备明确消费者的基础 UI 与纯展示契约，再将跨应用业务 UI 放到顶层 plugins。共享基础包的具体目录随实际工程落地，不将 Terminal 的整个 src 目录移动为通用 SDK，也不复制整套应用。

浏览器不能直接使用桌面 Node-API 或本机 IPC，也不能直接复用现有原生 TCP+mTLS 客户端。Web 交付必须实现服务端认证、授权及浏览器可用的请求/订阅入口；现有浏览器开发桥不是生产 Web 后端。服务端执行、风险校验、任务管理和账本继续由现有 C++ 服务与插件负责。

## 实施与验收顺序

1. 先实现截图中可确认的桌面市场总览与合约联动，记录待观察交互。数据不足时显示真实空状态；保持已有历史下载、研究和交易能力可访问。
2. 继续完善统一图表和实时数据链路，区分逐笔、报价、分钟柱与数据来源，验证缩放、回看、追加更新和断线状态。
3. 当前在 Terminal 内完成历史数据下载、查看、因子研究和回测链路及相关验收。

Web/Mobile 的实际用例、平台适配和交付验收仅在维护者重新批准后制定，不属于上述实施顺序。

代码复用不等于完整客户端交付。各客户端分别验收认证、权限、输入、导航、状态恢复、布局、连接与资源清理；原生和浏览器验证不能互相替代。

## 自选、合约与市场工作区（2026-09-29）

按新增参考截图，Terminal 增加独立自选与合约工作区，并与原市场工作区并列。自选采用左侧紧凑宽报价表、右侧上下双图；合约采用左侧自选列表、中间主图/信息区、右侧报价/买卖盘/成交明细/交易入口。自选支持排序、键盘选约与双击进入合约，市场选约和合约选约共用窗口内最近浏览记录；原有五个工作区的快捷键编号不变。

每张历史图通过插件声明的只读查询独立保存数据页，避免两个周期响应覆盖全局历史页。均线与 MACD 继续使用同一绘图组件和已有服务端指标结果，不复制指标算法。合约页的实时图展示有界报价序列及明确数据说明，不命名为全天分时；买卖盘仅填充接口提供的买一卖一，缺失档位和字段显示空值。资讯、逐笔成交、T 形报价及 F10 尚无来源或能力，不能用虚构内容填充；交易入口跳转现有模拟工作区，不提供未经授权的实盘委托。

结构参照不等于完全复刻或数据能力等同：目前没有完整合约中文名称目录、全天分时/均价线、日/周/月历史周期、五档行情、逐笔成交与资讯源。截图中的已存在测试曲线只来自隔离测试夹具，不进入生产。当前页面和菜单未宣称与参考软件完全一致。

图表进一步采用紧凑周期栏，固定展示常用分钟与日/周/月/季/年入口；仅有真实数据的分钟周期可以选择，其他周期禁用并解释原因。均线和 MACD 图例按两位小数显示，保留原始数据与计算精度；副图补充柱值，K 线标注当前可视区最高价和最低价，随翻页及缩放更新。共享绘图层只接收显示选项，周期可用性和指标命名由 Terminal 插件决定。

三页当前选约统一跟随窗口内最近一次明确选约，切换工作区保留合约；筛选结果不含该合约时只在当前页面选择可见项，不改写最近浏览。历史 K 线增加双侧价格刻度，自适应高度的 MACD 副图采用约 28% 绘图区高度。构建、ESLint、页面联动回归与 macOS Electron 检查通过，新增回归覆盖自选页保留合约页所选项、双侧刻度与最高/最低价标记。
