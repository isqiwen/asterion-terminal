# Tushare 期货历史分钟数据

## 当前实现

数据工作区「历史数据」页面中的 Tushare 数据源按交易所和品种查询真实月份合约，再选择合约与 1/5/15/30/60 分钟周期；不提供手工起止区间。任务提交到本机 Task Service，由 Node Agent 调度 `asterion-data-pipeline`；窗口关闭不影响下载。支持取消、显式重试、分段恢复、任务状态和数据集摘要。远程下载尚未开放。

数据插件位于 `plugins/data/tushare/`，使用公开 `HistoricalBarPort`。Core 只定义供应商无关的 OHLCV/成交额/持仓量模型；Tushare 代码映射、权限错误、频率和字段解析均属于插件。HTTPS 通过 Conan 管理的 cpp-httplib/OpenSSL 实现，校验证书和主机名，固定访问 `https://api.tushare.pro`，不跟随重定向。连接/读写与总耗时有界，单次响应不超过 8 MiB，可通过停止令牌取消。

## 供应商契约

依据 [Tushare 历史期货分钟接口](https://tushare.pro/document/2?doc_id=313) 和 [HTTP 接口](https://tushare.pro/document/1?doc_id=130)，查询使用 `ft_mins`，字段为合约、trade_time、OHLC、vol、amount、oi。分钟数据需要独立权限；拥有普通积分或实时行情权限不等于拥有历史分钟权限。上游费用/额度以用户账户和官方说明为准，不写死付费价格。

代码示例为 `CU2310.SHF`，交易所后缀支持 SHF/DCE/ZCE/CFX/INE/GFE。只接受月份合约；主力与连续映射、换月、复权尚未实现，不用连续代码冒充实际合约。用户可配置 1–500 次/分钟，默认 60；每个任务串行下载，多个任务/其他应用共享账户额度，当前没有跨进程账户级额度协调。

## 数据与恢复语义

- 每次请求覆盖不超过 24 小时的供应商时间标签，起止均包含，后续分段从上一结束秒之后开始。每段最多 8000 行的接口上限一旦触及就拒绝保存，不猜测结果完整。整个请求最多二十年。
- 数值在 JSON SAX 的原始十进制文本上解析，不经 double 重写价格或成交额。八位定点范围以外的数值拒绝，不舍入；数量、OHLC 关系、合约、时间范围和分钟对齐均校验。
- 上游倒序返回统一排序；重复时间戳一律拒绝，不静默挑选冲突值。休市或无数据分段可以为空；“完成”表示全部请求分段已处理，不表示已根据交易日历证明每根 K 线齐全。
- 数据独立存于任务目录的 `minutes/`：`minutes.json` 清单和逐段 `minutes-N.json`。清单记录请求、来源、时区、供应商时间标签语义、记录数及逐段 SHA-256。版本 1 的 bars 行固定为 `[timestamp_ns, open, high, low, close, volume, amount, open_interest]`，时间戳和数值均为十进制字符串。数据文件先持久化，再原子更新清单。崩溃后只恢复相同请求；已写入但尚未加入清单的下一分段须重新验证后才能接续。不同请求、摘要损坏或未知格式拒绝，不覆盖用户已有文件。
- 页面数据与逐笔成交完全分开；不会合成逐笔成交、补齐停盘价格、推断夜盘交易日或合约规格。`read_minutes` 在向研究消费者交付记录前验证完整清单、每段摘要和数据约束。
- 服务重启后未确认完成的尝试显示中断，需要用户显式继续；继续跳过已验证的分段。Task Service 管理重试/取消/尝试令牌，Agent 仅管理进程。独立心跳使 HTTPS 等待或限流等待不阻塞取消与租约续期。

## 凭据

Token 只在密码输入框中输入，不进入草稿、本地浏览器存储、任务定义、任务结果、日志或下载清单；界面每次提交后清空。Token 经本机 IPC 到 Task Service，保存在该任务目录的 `tushare.token`，供关闭桌面后的运行及显式重试使用。POSIX 文件权限为 0600；Windows 继承当前用户应用数据目录 ACL。这不是硬件密钥库或加密凭据保管能力。

Worker claim 仅为受信任的本机工作进程返回 Token，普通任务列表/结果不返回。供应商拒绝详情可能包含敏感内容，因此统一返回可本地化诊断，不回显原始 `msg`。权限不足、网络故障和超时不自动无限重试。若 Token 失效，当前可以重新填写 Token 提交新的下载任务；没有自动轮换或跨任务凭据管理。

## 命令行

流水线也提供 `tushare-minutes` 子命令。`--token-stdin` 从标准输入读取一行 Token，参数和 shell 历史中不放 Token。下载目录必须是已有的专用绝对路径。

```text
asterion-data-pipeline tushare-minutes --ts-code CU2310.SHF --minutes 1 \
  --directory /absolute/dedicated/dataset --requests-per-minute 60 --token-stdin

asterion-data-pipeline tushare-minutes --directory /absolute/dedicated/dataset --inspect
```

`--inspect` 仅验证本机数据，不读取 Token、不访问网络。下载进度以 JSON 行输出，失败保留已完成分段。

## 验收边界与后续接入

单元测试通过注入明确的测试响应验证精确金额、排序、重复/缺字段/错误合约/截断拒绝、取消、断点续传、存储校验、任务持久化和凭据排除。`tests/tushare_agent.py` 是显式在线探测：使用无效测试 Token 走真实 Agent/工作进程/HTTPS，验证错误反馈、桌面独立性和重试取消；不加入默认离线 CTest，不使用账户凭据。

真实账户的权限、实际历史数据质量及长时间下载仍须在用户本机输入有效 Token 后验收。现有因子引擎和模拟撮合按逐笔事件工作，尚不直接消费此分钟数据集。后续需要明确分钟因子时间轴、训练/验证切分、合约规格/交易日历和 bar 撮合假设；不能宣称分钟下载完成就已完成分钟回测。合约目录和存续日期已接入；完整合约规格、日线/结算价、主力映射的下载仍未接入。

## 历史数据工作台

数据工作区默认打开「历史数据」，与「文件与结算表」分开。左侧创建下载，右侧显示可取消／继续的任务与已完成数据集。数据集详情显示数据源、请求区间、周期、记录数及质量边界，存储位置和摘要按需展开。完成仅表示请求分段下载完成，并不证明所有交易时段数据齐全。

UI 的数据源契约位于数据插件内的 `history-sources.ts`，Tushare 的参数映射和能力定义位于 `tushare-minutes.ts`；公共页不根据供应商名称拼接命令。当前只注册实际实现的 Tushare 分钟数据，不展示未实现的数据源或日线选项。扩展数据源需要提供对应的原生插件、受校验的命令／任务契约和 UI 适配器，不能只增加下拉选项。当前分钟任务类型仅归 Tushare 所有，未来若共享任务类型，必须在协议中显式保存数据源身份，不能按名称猜测来源。这里是构建时注册，不是动态插件发现。

页面与各数据源查询草稿在窗口内保留；切换文件页面或离开数据工作区会卸载下载表单并清空凭据。Token 不写入草稿。服务端任务继续遵循原有持久化与账户权限边界。已完成数据集列表来自任务服务，目前不是任意目录扫描或独立数据目录索引。

## 以月份合约为下载单位

使用 Tushare [fut_basic](https://tushare.pro/document/2?doc_id=135) 的普通合约目录（fut_type=1），按交易所及大写品种代码查询；必须具备合约资料接口权限。界面从返回的真实合约中选择，不用手工拼接月份，不根据代码推算上市日。

开始时间取供应商上市日的北京时间 00:00:00；到期合约结束于最后交易日 23:59:59，未到期合约截止到本次目录查询时间（界面明确显示）。这是所选分钟周期的全部历史范围，不代表新增了日线、Tick 或所有周期批量下载。供应商历史覆盖不足仍不能称为交易时段完整。

目录查询在 Terminal 的服务操作锁外执行，网络等待不阻塞其他窗口的状态读取。完整查询结果校验通过才发布；重复代码、缺失／非法日期、错误交易所／品种和触及目录行数上限均拒绝。查询凭据不保存在目录或快照中。提交只接受合约、周期、请求频率和匹配的目录截止标识，由 C++ 根据查询结果计算范围；客户端不能提交起止日期，旧范围参数明确拒绝。目录更换时旧选择必须重新确认。

任务仍持久化确定的 begin/end；取消后继续不重新查询或扩大范围。CLI 同样按合约目录自动确定范围；恢复时校验已有目录从上市日开始且代码、周期一致，并沿用原截止时间。新时间覆盖需要新任务／目录，不静默追加或重写旧数据。

真实 Token 的合约目录与历史数据端到端验收仍未进行。日期范围取自供应商资料，不自动推断夜盘交易日历，也不保证供应商在查询时刻已发布最新分钟。

## 在界面查看分钟数据

「历史数据 → 已下载数据集 → 查看数据」在同一工作区显示合约、来源、分钟周期、总条数和实际首末记录时间。K 线与成交量按本页记录顺序绘制，支持鼠标查看、左右方向键查看和 25/50/100/200 根窗口选择；时间区间筛选与上一页／下一页读取服务端数据。表格保留原始十进制字符串，图表中的浮点只用于坐标绘制。原有元数据详情仍提供文件目录和清单摘要。

Task Service 新增类型化 MinutePageQuery/MinutePage，客户端只传任务标识、时间筛选和分页参数，不传文件路径。仅允许查看已完成分钟任务。服务在锁内取得已完成任务与结果的不可变副本，在锁外读取文件；清单需匹配任务结果的摘要及请求规格。通过清单行数跳过无关分段，只读取实际首末分段、筛选边界及当前页所需分段；单次最多返回 200 根，避免每页扫描或传输整个合约。

质量说明区明确：清单与已读取分段的摘要、时间顺序、重复时间戳及 OHLC 关系已经检查；下载完成时也经过全量校验，但每次分页不会重读无关分段。修改某个未读取分段不会在本页被发现，访问该分段时会拒绝。交易日历覆盖尚未校验，空区间不能直接归因于缺漏、休市或无成交。失败显示诊断并保留上一次成功的页面，不自动重试。

本功能目前面向已完成任务；未提供下载中预览、跨合约连续图、导出或分钟因子／回测消费接口。真实账户数据质量验收仍需本机账户，UI 测试中的合约数值明确为测试夹具。

## Terminal 分页并发与响应归属（2026-09-29）

原生 `research.minutes.page` 的空 `start`／`end` 表示不添加时间筛选，必须仍是字符串；非空值沿用严格时间解析，任务 ID 不允许为空。修复了把可选时间范围交给必填文本校验而拒绝正常图表请求的问题。

Terminal 在短操作锁内验证命令权限与参数、捕获当前研究客户端，然后在锁外执行只读 IPC。多个图表分页可以同时到达服务，不使整个 Terminal 进入命令忙状态，也不阻止状态刷新或其他命令。Core Runtime 的命令分派仍串行；没有把可变 Core 或客户端选择放到无锁线程中。

分页返回值只属于发起查询的调用，不再写入全局快照中的 `history_page`。普通快照保持该字段为空，避免一个窗口的查询结果被其他窗口的轮询取得。研究服务成功切换时增加连接代次；在途查询持有旧客户端以保证生命周期，但旧代次的结果明确拒绝，并返回中英文诊断。没有自动重发查询、交易命令或修改已下载数据。

验证使用真实 Terminal Application、ResearchClient、IPC 通道与受控延迟的测试服务：两条查询在任一返回前均被服务接收，期间快照及独立命令可执行，结果按请求分别返回，切换连接拒绝旧结果并允许新服务继续查询。它不代表真实供应商数据或长历史扫描性能验收；底层请求超时仍沿用现有期限，没有新增远程取消协议。

数据工作区查看器现在通过独立查询取得分页并保存在当前查看器内，普通状态轮询不会清空已读图表，也不再把只读翻页当作全局业务命令。查询期间限制当前查看器的翻页／筛选，仍可返回列表；首次失败可重试，后续失败保留上一页。返回页必须匹配任务与数据源；关闭查看器后忽略迟到结果，切换研究主机／服务后关闭旧查看器。离线时保留已读记录并停用查询控件。

合约历史图表的分页与已加载结果绑定研究主机、服务、本机／远程身份及数据集 ID。自动选中更新版本或切换研究连接时从第一页读取，避免短数据集沿用旧偏移而无法返回；显式选择旧版本后，新任务完成不会抢走选择。周期与指标仍按图表面板保留，不因缺少数据自动替换周期。

MACD 查询仅在存在匹配 K 线时扫描指标前序数据；空筛选结果在完成清单、首末记录与相交边界分段校验后返回，不读取无关前序分段。非空查询仍逐段校验并计算从数据集起点开始的指标，扫描后释放已消费分段。没有加入指标持久缓存或改变 MACD 计算公式。

官方日线正在作为独立交易日期数据接入；目前仅领域模型与 `fut_daily` 读取插件完成，任务、持久化和 Terminal 入口仍待接入。当前分钟工作流不变，具体边界见 [日线接入](tushare-daily.md)。


## 合约计量元数据（2026-09-29）

`fut_basic` 查询现在显式请求 `multiplier`、`per_unit`、`trade_unit`、`quote_unit`，与名称、上市/到期日期一起完整校验后发布到目录快照。数字经原始 JSON 数字文本解析为八位 Decimal，保持精度；缺失值为 null，存在但非正数或超出精度范围时拒绝整个目录。单位文本有长度和控制字符校验。

历史数据下载表单的“合约计量信息”按原字段分开展示乘数、每手单位和计量/报价单位。依据 [Tushare 官方 fut_basic 字段说明](https://tushare.pro/document/2?doc_id=135)，multiplier 仅标明适用于国债期货、指数期货，per_unit 为每手交易单位；当前不自动互换这两个字段，不根据品种硬编码或填补缺失数据。它们尚不作为委托金额或均价换算的权威输入。

供应商请求与解析、Terminal 原生快照和浏览器展示分别有测试；真实 Token 及真实合约单位端到端核验未完成。此次未实现均价计算或持久化完整合约资料库。
