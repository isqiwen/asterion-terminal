# 固定账户日采样损失路径实施合同

## 目标与首条边界

依据 requirements/modules/evaluation/risk.md 的 REQ-EVA-RSK-01、FR-EVA-RSK-01-01 及其100/110/99/105/112和止于105的验收例。首条日损失章节现已接通实际计算、持久任务/原行发布、页面、两格式、人工解释、重启与联合恢复，定向验收见下；不是完整风险分析。冻结1354的1005执行全过只覆盖此前报告链，日路径最新1371整仓验证尚待结果。

首条读取同Research成功正式回测的固定范围日结算权益，形成逐行峰值、回撤金额/比例、峰谷位置和已恢复/未恢复片段。原交易日、原纳秒及原settlement索引保留，不从UTC推算交易日，不补缺日，不把样本顺序的间隔数称完整交易日或自然日时长。仅日采样，不能据此断言盘中极值、历史最大风险、最坏可能损失、未来恢复时间或实际可平仓。

真实持仓总净敞口、相关风险贡献、VaR/ES、静态价格/保证金冲击和动态成交压力均未由此实现。真实资金流调整/多币种未具备时不从原始账本余额猜调整；当前固定来源仍是已有模拟回测单币种无外部资金流账户，明确来源环境与限制，不升级成真实交易账本。

## 归属、替代方案与发布

两个可行方案都沿用Research任务与存储：其一新增独立风险任务/结果种类，适合后续持仓或情景拥有独立输入和运行身份，但首条日路径会重复同一账户区间的固定捕获与报告交接；其二在现有固定评价内增加显式请求的日损失章节，使绩效与日路径共享精确来源/区间/程序及发布。首条选择其二，不把该选择扩大为所有未来风险情景必须塞入绩效任务。涉及独立持仓/冲击输入或动态回测时再按其业务身份定义。UI只读已发布内容，不临时计算或后台补算；不新建服务、数据库或任务框架。

请求明确包含日采样损失路径选项，默认不请求，不后台替已有报告补算。新选项改变固定输入身份，必须创建新报告；未请求的既有报告继续表示未评价，不被重写或迁移。源身份/固定区间/原输入hash和字节数/attempt/原producer与新evaluator仍由原verified ResultRead捕获。只用已保存范围内日结算观察，不用范围外峰值，也不把起始存入资金冒充日结算观察。完整绩效原max_drawdown使用原观测路径；日采样max_drawdown单独命名，不覆盖它或强制两者相等。

## 计算合同

- 每个原日结算是一个观察，保持原顺序、交易日、原时间和权益Decimal。首个观察作为本范围的首个峰值，绝不插入虚构零权益或前一日。
- 当前峰值是到该观察为止的最高日结算权益；等值重现可结束之前的回撤，后续新回撤使用最近一个等高峰，避免把已恢复时间累计进新片段。
- 回撤金额为峰值减当前权益，保留Decimal；峰值和当前权益均严格大于0时比例可定义。非正权益/峰值保留金额和明确不可计算原因，不能补百分比0或把后续正峰值追溯到先前区间。
- 片段在权益低于当前峰值时开始，记录原峰、最深谷和可选首次恢复观察。恢复是达到或超过原峰；未恢复的recovery必须缺失，不是0或最终点。
- 峰到谷、峰到恢复、截至观察末的间隔数按原观察索引计算，明确是观察间隔。原ns缺失不能补午夜或推算秒数；尚未实现真实时长则仅展示原时间及观察间隔，不伪装自然时间。
- 最深谷/最深片段并列时按原先出现者确定，规则固定；最大日采样比例若存在不适用分母，摘要保留覆盖限制，不宣称全路径比率完整。日路径风险为部分分析，敞口/尾部/压力仍明确未评价。
- 原日权益100、110、99、105、112对应日采样最大回撤10%，110峰/99谷，第5点首次恢复；止于105则未恢复。不得把后者恢复时长写0。

算法属于现有performance工具插件，Research将原日结算窗口传入并保存结果。UI和导出只格式化原结果/状态、显示原行证据，不重复计算峰谷或用未来点修改过去观察。取消沿原执行池协作，不发布半份路径；重启按既有中断/准备恢复规则，不自动重跑。

## 展示、引用与验证

原固定评价入口显式选择日路径，原报告读取和人工解释引用精确新版本。显示日采样/原区间/原观察数、峰谷与未恢复、原行表及仅由保存比例绘制的曲线，缺比例处断开并说明原因；曲线是展示不是新的计算权威。HTML/CSV同一章节保留全部原行、缺项和未恢复状态，原报告旧章节和限制不被删去。部分损失分析不能仍声称所有风险未计算，也不能反过来宣称暴露/压力已经完成。
