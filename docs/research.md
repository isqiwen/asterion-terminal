# 研究

Research 服务（`apps/services/research/`）承载分析、策略、回测和评估四个模块的对象与任务。
本页说明每类对象是什么、遵守哪些约束、当前做到哪里。回测引擎与策略规则见 [回测](backtest.md)、
[策略](strategies.md)，因子见 [因子](factors.md)，任务机制见 [任务](tasks.md)。

## 共同约束

- **所有权**：对象属于某个 Research 实例（`node_id` + `service_id`）。Data 拥有原始固定数据，
  Research 只保存对固定数据版本的引用及原输入证据；Manager/Agent 只发现服务。
- **固定身份**：用于计算的定义一旦固定就不可修改；修改产生新对象并保留父对象和修订理由。
  任务接纳时固化所用定义、Data 版本与实际程序（`program_artifact`）。
- **时间语义**：只用当前及更早的完整 bar；决策作用于下一 bar。Data 的 `acquired_at_ns` 是本地首次发布时间，
  不是历史发布时间；历史可得性未知的资料一律标为“事后探索”，不能当作严格回测证据。
- **样本角色**：训练、开发验证与最终留出分开；留出不进入探索统计和选参。
- **缺失即拒绝**：历史不足、分母为零、非有限值分别记录；不填零、不插值、不静默降级所选方法。
- **恢复**：服务重启后按原身份读取；冷备份可在原目录移走后独立恢复对象、原输入、结果和程序。
  不提供旧结构迁移，也不自动重算。

## 分析

| 对象 | 内容 | 当前边界 |
| --- | --- | --- |
| 研究变量 | 有界表达式定义的特征：`close`、常量、四则运算、`lag/return/mean/std/min/max(x, n)` | 检查单位与预热；`std` 用样本标准差；仅单序列；多输入、多周期、拟合变换未实现 |
| 样本 | 从固定分钟/日表选定合约的观察集合及其训练/验证/留出角色 | 只支持显式静态合约选择；动态资格和连续映射未实现 |
| 统计 | 对样本原始价格或因子结果的描述统计；可按 Data 原交易日分组 | 多列关系、时间结构、事件窗口未实现 |
| 因子观察 | 因子任务的逐行证据：成员、因子值、标签收益、角色 | 见 [因子](factors.md) |

## 策略

| 对象 | 内容 | 当前边界 |
| --- | --- | --- |
| 规则逻辑 | 已登记的规则定义（如双均线）与固定虚构样例；试算比较规则输出与预期 | 只做因果试算，不是行情绩效 |
| 策略包 | 固定的单合约 CTA 候选、规则逻辑或组合配置；交付需经显式回测 | 策略包不授予交易权限；实盘交接未实现 |
| 组合 | 固定权重目标在共享账户上离线执行；目标、实际持仓与在途证据分开核对 | 事前组合政策（回测前声明）只有设计，未实现 |

## 回测

| 对象 | 内容 | 当前边界 |
| --- | --- | --- |
| 回测任务 | 固定数据集 + 策略 + 费用/保证金/风控，输出逐日结算的组合账本 | 见 [回测](backtest.md) |
| 滚动验证证据 | 走步训练/验证边界写入结果，评价只读这些边界 | — |
| 成本变体 | 以原回测固定输入派生单个手续费倍数或滑点跳数变体，作为独立任务 | 每次一个变体；不做批量扫描 |

## 评估

评估只读取已确认的固定结果，不重新计算策略。

| 报告 | 内容 |
| --- | --- |
| 绩效评价报告 | 收益、回撤、风险指标；可导出离线 HTML/CSV |
| 绩效上下文 | 指标所依据的数据、费用、资金和样本范围 |
| 合约贡献与账户核对 | 按合约拆分收益并与账本总额核对 |
| 账本归因 | 把评价指标桥接到原账本事件 |
| 敞口与资金切片 | 结算时点的持仓敞口与保证金占用 |
| 损失路径 | 账户日采样的回撤路径 |
| 静态压力 | 固定持仓在给定价格冲击下的损益 |
| 成本情景 | 原回测在手续费扰动下的结果 |

限制：只支持日线、单币种、完整账户范围；策略风险贡献、跨币种、动态压力未实现。
