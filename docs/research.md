# 研究任务

## 任务服务

`asterion-task-service` 持久化研究任务和执行尝试；Node Agent 按任务类型启动工作程序（每个研究服务最多同时 2 个）。

- 状态：`queued → running → succeeded / failed`；取消运行中任务先进入 `cancel_requested`，工作程序确认后为 `cancelled`。
- `failed`、`cancelled`、`interrupted` 可显式重试，每次重试是新的执行尝试，带独立令牌。
- 工作程序 30 秒无进度报告则标记 `interrupted`；服务重启时运行中任务标记中断，不自动重跑。
- 结果先写入并同步，再记录完成状态和 SHA-256；只有确认完成的结果可查询。
- 同一任务 ID 重复提交相同输入返回现状，输入不同则拒绝。

| 任务 | 工作程序 | 内容 |
| --- | --- | --- |
| 回测 | `asterion-backtest` | SMA 策略回测 |
| 因子 | `asterion-factor` | 成交序列动量因子；日线动量因子 |
| 数据发布 | `asterion-data-pipeline` | 成交数据集、结算表 |
| 历史下载 | `asterion-data-pipeline` | Tushare 分钟线、日线 |

## 回测

- 输入：一个已发布成交数据集、一个结算表版本（1–64 个交易日，每日 1–16 个时段）、资金、费用、SMA 参数与风险限额。
- 复用模拟交易的账本、撮合和风控：先撮合上一事件产生的委托，再把当前事件交给策略；时段末撤销剩余委托，每日按结算价结算，持仓续接。
- 输出逐事件权益、手续费与最大回撤金额。

## 因子评价

- 成交序列动量：因子 = `price[i] / price[i-N] − 1`，标签 = `price[i+H] / price[i] − 1`，窗口按成交笔数计。
- 支持全样本、时间顺序留出和固定窗口滚动验证，可只按前段结果选择回看窗口。
- 输出 Pearson 与 Spearman（平均秩）相关性以及逐条对齐记录；零方差时相关性为空。
- 日线动量因子基于下载的 Tushare 日线。

因子与标签是研究统计，使用浮点数，不进入账本。

## 限制

单合约；不处理主力换月、连续合约拼接或复权；没有显著性检验和年化指标；下载的分钟线／日线目前只用于图表和日线因子，不进入回测。
