# 研究任务

## 任务服务

`asterion-task-service` 持久化研究任务和执行尝试：任务清单与每次状态变化写入研究服务目录的 `tasks.sqlite`（任务表带当前状态、尝试次数和更新时间索引），结果以带 SHA-256 的单个文件保存在各任务目录。Node Agent 按任务类型启动工作程序（每个研究服务最多同时 2 个）。

- 状态：`queued → running → succeeded / failed`；取消运行中任务先进入 `cancel_requested`，工作程序确认后为 `cancelled`。
- `failed`、`cancelled`、`interrupted` 可显式重试，每次重试是新的执行尝试，带独立令牌。
- 工作程序 30 秒无进度报告则标记 `interrupted`；服务重启时运行中任务标记中断，不自动重跑。
- 结果先写入并同步，再记录完成状态和 SHA-256；只有确认完成的结果可查询。
- 同一任务 ID 重复提交相同输入返回现状，输入不同则拒绝。

| 任务 | 工作程序 | 内容 |
| --- | --- | --- |
| 回测 | `asterion-backtest` | SMA 策略回测 |
| 因子 | `asterion-factor` | K 线收盘价动量因子；日线动量因子 |
| 历史下载 | `asterion-data-pipeline` | 统一历史格式的分钟线、日线（当前生产插件为 Tushare） |

## 可复用输入

在 K 线数据选择区可将已选合约保存为具名数据集；保存合约单位、日期区间和行情／结算的全部固定档案版本。“拼接更多下载”可显式组合同合约、同周期、同口径的分段下载；重复记录去重，冲突拒绝，不覆盖原始档案。恢复会先核验整组输入，全部成功后再替换当前选择。已有任务的参数与结果保持固定；同名不同输入产生独立版本，不覆盖旧记录。数据集属于当前研究服务，切换服务后需要选择该服务中的数据集。存储边界与限制见 [历史仓库](market-data.md#研究数据入口)。

## 回测

- 输入：一个或多个合约（最多 20 个，交易日必须相同）的固定版本数据集，由历史仓库中固定版本的 K 线与日线结算数据生成，不依赖下载任务记录（合计最多 200000 根 K 线，1 分钟线单合约约一年半到两年半）；资金、风险限额和 SMA 参数，以及每个合约按交易日生效的费用版本表（日期、来源、八项参数）。完整版本表固定在任务输入中，实验详情可查看；重试和结果校验沿用原表，不读取当前模板。
- 复用模拟交易的组合账本、撮合和风控：所有合约的 K 线按时间合并为一个事件流；每个合约有独立的均线，先撮合该合约上一事件产生的委托，再把当前事件交给它的策略；交易日末撤销剩余委托，每日按各合约结算价一起结算，持仓续接。
- 回测输入版本为 8，引擎为 `asterion.backtest.sma-long-flat.v8`；不接受旧输入，不自动改写旧任务。费用切换与持仓重估规则见 [模拟交易](trading.md#按交易日生效的费率)。
- 输出逐事件权益、手续费、最大回撤金额，以及逐日每个合约的结算价与持仓。

## 因子评价

- K 线动量：因子 = `close[i] / close[i-N] − 1`，标签 = `close[i+H] / close[i] − 1`，窗口按 K 线根数计。
- 支持全样本、时间顺序留出和固定窗口滚动验证，可只按前段结果选择回看窗口。
- 输出 Pearson 与 Spearman（平均秩）相关性以及逐条对齐记录；零方差时相关性为空。
- 日线动量因子直接选择已发布的日线数据版本，基于统一日线格式，保留来源与 manifest 摘要。

因子与标签是研究统计，使用浮点数，不进入账本。

## 限制

因子评价只支持单合约；回测组合没有跨品种保证金和相关性风险。不处理主力换月、连续合约拼接或复权；没有显著性检验和年化指标。日线和分钟线都可进入研究；分钟数据必须具备交易日、`bar_end` 标签语义和对应日线结算价，Tushare 分钟线的交易日来自交易所交易日历。数据集会列出结算日历中存在、但所选 K 线缺失的交易日（覆盖缺口），选择时明确提示，不自动补齐。
