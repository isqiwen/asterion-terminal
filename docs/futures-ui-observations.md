## 范围与证据

2026-09-29 在维护者本机操作同花顺期货通 macOS 1.2.0，使用原生窗口截图、辅助功能和鼠标／键盘输入观察。未登录交易、未提交委托、未改变自选合约配置。当前实施范围仍仅为 macOS Asterion Terminal。

## 市场报价列设置

市场表头设置支持拖动及上下按钮调整五个报价列，勾选显示／隐藏，合约身份列固定。所有交易所分组使用同一顺序。编辑过程中不改变报价表，应用后生效；取消或 Escape 丢弃编辑；恢复默认也需要应用。列选择和市场排序在窗口内跨导航保留，刷新窗口重置；不保存到磁盘。

隐藏当前排序列时恢复合约升序，避免不可见字段继续决定顺序。全部报价列隐藏时，合约名称与键盘导航仍可用。设置关闭同步恢复触发按钮焦点，避免延迟回调抢走紧随其后的键盘选择。总览只读表不受市场列设置影响。
