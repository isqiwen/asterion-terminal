# Data材料到Intelligence发布与Research消费

本页是已批准统一数据通路下的实施设计，不改变[情报范围](requirements/modules/intelligence/README.md)。当前具备Data材料取得/固定原件、Intelligence人工保证金公告核验与Data保存后语义发布、Research固定公告时点审阅及三域引用/冷备。新增显式事件及追加更正/撤回已通过真实进程、历史查询和独立恢复；页面已接，最新浏览器结果另列。生产解析/提取模型、完整事件集合与订阅仍未实现，不能把受限人工公告能力等同全部Intelligence。

## 依据与阶段

Data拥有来源授权、原件、取得记录和基础解析（FR-DAT-ACQ-01-05、FR-DAT-PRC-01-06）；Intelligence拥有候选、核验、事件身份及发布/更正/撤回（FR-INT-VER-02-03/04）；Research固定已发布集合及用途（REQ-INT-SRV-01）。默认本机直接业务通信，Manager/Agent只发现与管进程，不搬业务载荷；任务不固定部署配对。

1. Data固定材料库：不可变原始字节按内容复用，各次来源/取得记录独立；纯UTF-8正文保留原字节定位，其他格式明确尚不可读。真实来源通过已选供应商能力取得，不开放任意市场CSV/JSON上传替代来源。先用隔离供应商响应验证持久/重启/重复/取消边界，再接服务、目录和备份；库通过不等于用户链路完成。
2. 材料取得及基础读取页面：明确来源能力、使用范围、请求与费用条件。固定操作身份，先接纳再外部请求，不自动重发中断请求。供应商不可用即失败，不换源、不假定免费。外部来源准入未核实前只承认测试源验证，不声称真实供应商可用。
3. Intelligence人工证据核验到持久发布：复用已有服务宿主/有界池和持久组件，建立实际长期状态。先支持确定性证据片段及人工字段，不冒充自动实体识别、OCR、LLM提取或合格提取评测。缺核心证据/冲突/未配置发布条件阻断；用户点击不替代证据。发布固定字节交Data保存，Data确认后Intelligence确认发布；同次操作重试核对原决定，不能重复事件。候选与核验状态不归Data。
4. 当前/截至时点查询及Research固定消费：准确区分事件时间、来源发布时间、取得、处理、人工核验和持久发布可用时间；更正/撤回追加身份，旧集合不改写。Research只接精确发布身份、用途、限制及证据引用；不产生虚构预测有效性或交易绩效。
5. 随业务接入资源目录、引用保护、冷备/独立恢复及实际进程/浏览器验收。未实现HTML/PDF/表格读取、模型准入/费用/质量评测、订阅补取、远程载荷传输逐项保留缺口，后续按需求推进。

## 最小材料合同和存储

材料内容与取得记录分离：content版本为原始字节SHA-256，原件存在Data私有materials/objects；acquisition使用稳定操作ID，固定来源ID、来源资源定位、声明用途及供应商身份，保存实际取得时间、媒体类型、原件身份及来源发布时间证据。相同字节跨获取复用一个原件，不能合并来源记录。来源时间未知显式缺失，HTTP取得时间不能补成发布时间。

结构元数据采用Protobuf明确字段与边界，大原件单独存储，不强制转Parquet或塞入SQLite。首次先持久接纳，再读取供应商；原件持久成功后原子发布取得回执。崩溃保留接纳状态或完整回执；同ID不同请求冲突；已取得材料不因情报失败回滚。尚未确认的原件不被清理。当前不提供材料物理删除，后续必须先完成精确持有/并发屏障。

基础读取保持独立身份，纯文本UTF-8仅作编码/完整可读范围检查，原始字节不改换行、不修复乱码；证据以UTF-8字节区间定位，必须在码点边界且切片与原件一致。无效编码、二进制、未支持格式报告不可读，不能让解析失败改写取得成功。控制指令只是材料内容，不授予网络/工具/交易权限。

对两种方案的取舍：直接把正文及全部元数据写一张业务大表虽简单，但会把各次来源身份与重复字节混在一起；选择独立固定内容与小取得回执，并沿用Data已有串行writer和持久文件原语。不建立中央Storage或第二套通用队列。哈希仅用于原件固定身份和去重复用，不对整个库重复扫描制造额外证明。

## 下一实施切片：人工核验合约保证金公告

先实现已有事件范围中的一条受限业务链路：人明确选择Data固定纯文本材料和固定合约基础资料，逐字段对照“合约、计划生效日、保证金百分比、计划语气”证据，采用已选择的人工公告核验规则。百分比仅确定性换算为比例，日期只接受原文支持的明确日，不推断相对日期；计划不转为已实施，更不修改Trading风控、下单或伪造提取评测。其它事件/歧义/格式继续明确不可用或待核验。

两个可行方案是由Data裁决发布，或由Intelligence保存核验与发布决定、Data只确认固定内容保存。选择后者，沿用已批准业务所有权。新增目标Intelligence服务必须带真实候选/人工决定/发布恢复状态与协议，不先挂空服务。新材料的取得状态不随核验失败改变；不新建采集、模型或通用任务队列。

- 输入固定Data材料取得Object及其原件版本、Data合约表快照/来源和精确合约ID；证据是UTF-8字节区间和原文字段。Data读取接受预期完整Object，不能只按操作ID取得另一版。合约缺失/多义、日期或比例不支持、用途未选均阻断相关发布。
- 候选和更改是独立固定身份，保留来源、真实处理时间及实际核验程序。人逐项确认主体、时间、单位数量、语气/条件、来源使用范围、冲突处理，并记录操作者和理由；无已选规则或任一项未知不能发布。候选/核验状态归Intelligence，原件仍归Data。
- 合约表已具备删除，因此在候选接纳前复用Data现有精确引用保留；Intelligence准备意图先持久化，原Object/版本不变。来源失联或引用未知保持阻断；不能绕过删除屏障。材料暂未提供删除，原件继续保留，不谎称已有解除权限。
- 核验成功先持久记录发布意图和确切载荷身份。Data通过Agent元数据发现直接读取Intelligence的固定准备内容，保存后给出确切回执；Intelligence确认该回执后才持久发布并记录实际可用时间。重复操作核对原意图/回执，崩溃不重建另一版，不把Data存了字节当作情报发布。
