**这些阈值不是执行约束，不拦单，不授权交易，不保存到原实验，也不是风险平价或组合优化。** 本批交付满足期末预算解释，不宣称新增全程风险预算控制。

## 哪些已经实际约束，哪些仅展示

| 项目 | 实际语义 |
| --- | --- |
| 原单笔手数、总持仓手数、在途委托数上限 | 内置限额插件执行前检查；总手数使用正向持仓总量加待开仓量，不按多空净额抵销，也不预先信用待平仓。实际执行还取决于任务固定记录的风控实现摘要。 |
| 原账户可用资金 | 统一期货账户检查资金与保证金占用，费用/保证金仍沿原固定成本日程及领域规则。 |
| 本页期末手数余量 | 原总手数上限减期末总持仓手数，仅为末态解释，不证明全程或盘中峰值。 |
| 新名义金额/保证金复核限额 | 本次明确输入的只读比较；不是持久实验参数或开仓拒绝规则。 |
| 实际期末总名义占比 | 已取整实际持仓的总名义金额份额，展示用统计比率，不是原策略目标权重。 |
| 总名义、代数净名义 | 总额分别累计各持仓批次绝对手数×末价×乘数；净额保留方向符号。不同合约净额为记账汇总，不代表风险抵销。 |
| 模型保证金 | 对保存各持仓批次按末日生效固定成本计算并相加，保留批次舍入；同时列出记录保证金及差额。 |
| 余额、权益、可用资金、冻结 | 直接展示保存账户数值；名义敞口不是现金，保证金不再次从权益扣除。 |

保存末价可能来自不同交易日，没有改用当前行情。未定价且无持仓合约不虚构价格；没有总名义金额时占比不补 0。历史保证金、乘数及规格适用性仍未在此证实，固定模型的已知数字不能替代这些外部事实。
