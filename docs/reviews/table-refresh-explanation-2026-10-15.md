## 用户能看到什么

| 观察依据 | 准确含义 | 下一步 |
| --- | --- | --- |
| 当前插件声明的表/交易所范围不含目标交易所 | 该插件当前声明不支持此交易所；不是历史日期覆盖结论，也不代表其他来源不支持 | 核对来源或启用明确支持该交易所的插件；本页不提交该请求 |
| 来源声明支持此表/交易所，但没有历史日期边界证据 | 所选日期的历史覆盖未知 | 可显式预览并确认请求；预览不请求来源 |
| 本次请求正常返回空行 | 原因和历史覆盖未知；不能推断无交易、数据不存在、来源不覆盖或以后也不会有数据 | 原内容保留。核实来源公布情况，再读取当前分区、重新预览并显式提交新任务；不重试已成功任务 |
| 失败附带 unavailable/resource_exhausted | 本次未完成、来源不可用或资源受限；不能据此认定日期不覆盖，也不保证故障是暂时的 | 核实来源状态和共享额度，条件允许时显式重试原固定任务 |
| permission_denied | 来源拒绝访问，不是历史日期边界 | 核对来源授权/账户权限后显式重试 |
| conflict | 固定目标/服务状态冲突 | 读取当前分区并重新预览 |
| 其他失败或没有错误码 | 不能确定临时性或覆盖原因 | 查看保留的诊断，目标变化时重新读取/预览，否则可显式重试 |
| 取消/中断 | 执行停止，不说明来源没有数据 | 原固定任务可显式重试；已发布修订保留 |

当前 ABI 只提供表、来源和交易所声明，没有有版本的历史日期覆盖声明。因此本批没有启用任何生产“某日期不覆盖”的推断，也没有编造覆盖边界。范围不支持的界面回归使用明确的交易所声明夹具，不冒充供应商历史日期证据。未请求状态仅指本次操作未提交，不声称用户从未请求过该分区。

## 最小实现

数据发布逻辑没有改变，空响应仍保持旧分区；既有不可变快照与原始账本保留。界面复用 task.action 和读取当前分区操作；空响应提示重新预览创建新任务，不放宽成功任务重试规则。
