# Lightweight Charts 与 QuantStats 直接接入

## 设计与边界

用户明确要求两个模块直接接入产品。本批替换自研主图/分时图渲染，并在 Terminal 回测结果内提供实际运行 QuantStats 的扩展绩效分析。

图表比较两种方案：保留 SVG 并增设可切换引擎；统一替换为 Lightweight Charts。选择统一替换，移除旧坐标、蜡烛、网格及指针绘图实现。现有供应商数据、期货交易日和指标计算继续由原所有者提供；图表仅转换展示坐标。保留缩放、浏览锚点、十字光标、键盘操作、成交量、MACD、均线、昨结价、缺口及中文行情配色。纳秒时间与分时会话槽通过显式坐标映射保留身份，不把缺口补成零值。

QuantStats 比较运行在远程计算服务和随桌面分发的短生命周期分析助手。选择桌面助手：Native 读取 Task 已核验的固定回测结果，取实际逐日结算权益与初始资金，通过 Unix Socket + Protobuf 交给助手；助手执行 QuantStats 的扩展收益分布/风险统计，再返回 typed 结果供本地化 UI 展示。它是一次请求的子进程，不增加常驻服务、任务调度、第二套账本或行情下载。C++ 既有资金、费用、选参和权威统计不变。扩展统计明确采用每日扣费收益、零无风险收益及每年 252 个观测的口径，未定义值保持缺失；非正权益、无足够结算观测明确拒绝。

Python 算法位于 `plugins/tools/quantstats/`。构建时用锁定的 Python 依赖生成包含解释器的冻结助手，桌面包直接携带；运行时不调用系统 Python、不联网安装依赖。现有 C++/JS 继续使用 Conan/pnpm 锁，新 Python 依赖使用 uv 锁。开发准备是显式命令，桌面构建验证已生成的当前产物，缺失或过期则失败。新增助手只支持 Linux x86_64 与 macOS arm64，与 Terminal 一致。

Native 拥有子进程、超时和私有 Unix Socket 目录的生命周期；结果服务变更或源摘要不符时拒绝展示。仅从真实固定回测读取数据，不接收界面伪造的收益序列。测试夹具只用于隔离测试。

## 验收

图表验证真实 Canvas 渲染、夜盘/日线标签、数据更新时保留浏览位置、缺口与副图、缩放及键盘行为。QuantStats 验证库真实执行、输入边界、固定任务身份、错误语义与前端展示；完成冻结产物及隔离端到端链路测试。更新中英文文案、构建/开发指南和整改进度。记录实际结果和未验收平台，不把既往测试算作本次通过。

## 实施与验证记录

2026-10-15 开始实施，2026-10-16 完成当前 Linux checkout 验证。基线 `0a040bd`，工作目录 `/home/qiwen/Code/quant/asterion-terminal`，直接修改 `main`。

- Lightweight Charts 5.2.1 锁入 pnpm，统一用于 K 线、Tick、分时、回测权益和 QuantStats 日收益。移除旧主图、分时与权益 SVG 实现及对应坐标/样式；列表微型趋势图仍是其原有独立组件。真实 Canvas 覆盖均线、成交量、MACD、高低点、昨结价及双轴。源金额与时间标签仍由原始字符串提供。
- 窗口统一使用包含首尾观测的整数区间。按钮/键盘立即记录窗口，图表异步缩放通知更新同一入口；保留有界缓存中的时间锚点。焦点只由真实指针/键盘输入更新，忽略引擎的数据刷新事件，避免滚动时把旧坐标当成新选择。标记插件由图表实例统一拥有，在图表销毁前解除，消除跨页面访问已释放 Canvas 的问题。断开的分时记录使用独立连续段，不画出缺失期间的价格连线。
- QuantStats 0.0.86 实际计算 Sortino、Omega、尾部比率、Ulcer Index、日 VaR95、日 CVaR95；报告包含日收益、库版本、任务身份与结果摘要。UI、诊断均提供中英文。入口 `task.quantstats.analyze` 只读取 Task 已核验结果，不接受收益数组。Native 用 30 秒有界子进程与 Kernel Unix Socket 分帧的 Protobuf 交换，核对返回身份/日期/有限数值，私有 Socket 目录随请求释放。
- 收益求差先用 Decimal；初始资金进入净值/回撤基准。Sortino/Omega 在没有负收益时保持无定义，避免库的收益/价格自动判断误处理全正且超过 100% 的收益序列。VaR/CVaR 明确使用库的正态模型。该报告覆盖全程，包含训练段，不改变权威账本、策略选择、费用归因或既有 C++ 统计，也不生成默认英文 HTML tear sheet。
- CPython 3.12.12、NumPy 2.3.5、SciPy 1.17.1、Protobuf 5.29.3、PyInstaller 6.22.3 及传递依赖进入 uv 锁。NumPy/SciPy 版本和 wheel 目标保留 macOS 13 支持；Matplotlib 显式使用 Agg。准备入口为 `pnpm prepare:quantstats` 或桌面命令的 `--prepare-quantstats` 显式选项，运行时不安装 Python 或依赖。
- 冻结助手进入 Electron extraResources，CI 与桌面构建同步准备/验证；源码身份、文件摘要、平台、Mac 最低系统版本及 Debian 共享库依赖进入检查。冻结环境只在 `build/` 中，避免 Python 依赖树污染服务源码指纹。署名与许可证随应用分发。本机最终目录包含 1124 个清单文件，文件内容合计 347,112,636 字节（约 331 MiB；磁盘占用约 335 MiB）。
