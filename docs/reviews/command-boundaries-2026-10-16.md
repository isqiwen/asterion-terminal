# 实盘命令、政策类型与架构检查收敛

## 基线与取舍

2026-10-16，用户批准继续推进命令入口类型化、政策类型化、架构失败用例和快照测量，
完成后重建交付产物。工作目录为主 checkout `main`，HEAD `723f418` 加之前未提交的
[观察出口修改](live-observation-2026-10-16.md)，没有回滚或替换此前修改。
复核架构设计、历史实施与审计进度后，保留当前服务进程、账户线程和日志写入线程的所有权。

命令原来从 Protobuf 转为 JSON，再解析成已有 `AccountRequest`；政策在接纳、准备和
恢复之间传递动态 JSON。比较直接让账户逻辑读取协议消息、以及在入口一次映射为已有
业务命令两种设计，选择后者：复用 `SubmitOrder` 等类型，账户不再承担外部格式解析。
政策采用 `PolicyDefinition` 值，包含限额、价格偏离和合约清单，供命令、准备和政策实例共享。
不新建 RPC 框架、插件装配框架或第二套执行路径。

JSON 仍是当前日志的持久形式。`from_wire` 直接读取协议字段生成业务操作，同时生成
用于日志的 JSON 内容；业务不反解析它。`from_record` 在日志边界恢复业务类型，并保留
原 JSON 内容用于同一请求 ID 的精确核对，不改写、迁移或删除记录。不能把“没有 JSON
中转业务操作”表述成“命令完全不产生 JSON”。

## 实现与不变量

- RPC 入口用 `AccountRequest::from_wire`，`LiveSession::execute` 只接收类型化请求；
  删除账户循环中的 JSON 解析及为解析异常创建 future 的包装。入口失败仍由 RPC 现有
  错误处理返回 `ErrorCode`，发生在账户接纳之前。
- 策略派生的撤单、报单同样使用当前命令入口；删除不再使用的方向字符串转换函数。
  原有撤权接纳、控制代次、持久后发送、一次性发送许可和断线不重发不变。
- `ChangePolicy`、日志线程准备以及恢复采用 `PolicyDefinition`。`AccountPolicy` 组合
  该定义与风控实例，删除未使用的 JSON 定义出口。协议政策校验独立于展示 JSON 构造，
  合约唯一性、数量与风险配置约束继续在边界拒绝。
- `Architecture.LinkGuards` 创建临时 CMake 目标图，验证正常向下链接与单纯构建顺序依赖
  可通过；向上 `LINK_ONLY`、Task 通过 alias/条件依赖间接链接引擎、Agent 链接引擎必须
  以指定架构诊断失败。沿用现有 CTest/CI，无新运行时组件。
- 新增聚焦命令测试验证政策值、金额精度、日志内容往返及缺少风险/重复合约/非法方向拒绝；
  既有政策、重试去重、撤权和恢复测试继续验证执行语义。

## 快照测量

`Live.DISABLED_ObservationScaleMeasurements` 是显式运行的 Release 测量，普通 CTest
不执行。测试 CTP SDK 预置只读历史，每账户 0、250、1000 条委托及对应成交，另测 4 个
账户各 1000 条；账户使用独立目录与身份，读取同一测试历史模板。没有外部行情、柜台或报单。

每组预热 5 次、记录 30 次：观察耗时包括并发发送 future 到全部账户并收齐回复的墙钟时间，
不能当作单独账户线程 CPU 时间；随后单独测 Protobuf 编码与 UI 解码加 JSON 输出耗时。
同时记录合计字节数与整个测试进程累计 RSS 高水位，后者不能相减当作单账户常驻内存。
这是开发机样本，不是生产容量承诺或全负载基准。

测量首次失败是夹具未预建账户目录；修正测试准备，未修改产品的目录约束。
Release 实测通过（31.683 秒），数据见 `snapshot-scale.json`：

| 账户 × 每账户委托/成交数 | 观察 p95 ms | Protobuf 编码 p95 ms | UI 转换 p95 ms | 协议总 KiB | JSON 总 KiB | 进程峰值 MiB |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 × 0 | 0.007 | 0.001 | 0.016 | 0.3 | 1.0 | 19.2 |
| 1 × 250 | 0.151 | 0.037 | 1.408 | 35.4 | 96.0 | 21.2 |
| 1 × 1000 | 0.801 | 0.174 | 5.431 | 141.7 | 381.6 | 28.7 |
| 4 × 1000 | 0.860 | 0.810 | 22.204 | 566.6 | 1526.5 | 47.4 |

该测量在同一测试进程内运行多个独立账户线程，不含真实独立进程之间的 RPC、网络或 React
渲染；执行时本机还在跑回归与下载构建依赖，不是独占机器基准。样本显示主要转换成本在
Native 的 UI 投影，账户观察本身较小，不能把 UI 投影时间解释成账户线程被阻塞。
本轮不据此增加分页、缓存或状态副本：尚无真实负载的等待预算违约证据。后续若出现实际
延迟，应优先测 Native 投影及回复体大小，而不是改造账户执行线程。

证据目录为 `build/reviews/command-boundaries-2026-10-16/`。
