## 问题与处理

原需求把业务功能拆分直接转换成独立页面和导航，导致布局、入口、按钮、偏好保存方式及任务呈现与实际软件不一致。需求仍覆盖规则策略与多因子组合；本轮只修正文档中的界面表达，没有按虚构原型修改产品代码。

- 用 17 张实际运行截图替换原先 41 张原型页面/状态图。截图没有补造行情、资金、成交或实验结果。
- 主导航保持自选、合约、市场、数据、研究、交易；数据保持历史数据、历史数据仓库、全市场数据；研究保持回测、因子。设置使用独立窗口，任务中心使用底部抽屉。
- 38 个 UI 编号成为业务需求与实际入口的对应条目，分别说明部分对应、待设计或尚未具备运行验证条件。实际页面字段、操作名、流程和源码依据集中在[实际界面说明](../requirements/common/screens.md)。
- 偏好明确为语言、显示密度、涨跌配色三个即时保存的下拉项；删除不存在的保存/放弃步骤，统一时区选择作为待设计能力。
- 保留 41 个业务主题、182 条功能需求、18 条目标业务旅程及有效评审输入。业务算例明确不是产品截图。功能及旅程中的未实现步骤不作为当前操作手册。
- 正文、界面浏览、图文阅读版和 Excel 台账同步；过时图片撤下，不建立旧版原型入口。
