# 跨模块业务流程

[返回上级](../README.md) · [需求总纲](../README.md) · [界面操作指南](../common/screens.md) · [跨模块流程](README.md)

开发前需求规格。本页定义42条从准备输入到形成业务结果的目标流程；业务算例为隔离验收输入，所有生产数据、账户和授权必须通过对应准入条件。

目标操作按[七模块导航](../common/ui-designs.md#target-navigation)到达。每一步引用所属模块的界面条目，说明输入、操作、反馈、异常和下一步。新用户先执行JRN-012；其他流程可消费由前序流程产生且通过检查的对象，无需重复创建已有固定输入。

### 全部流程共同遵守的操作契约

- **上下文携带：** 跨页自动携带工作位置、研究/运行身份、固定输入、账户与模式、时间范围及来源步骤；只携带引用，不复制可变业务状态。接收页列出继承值与仍需填写项，不能要求用户凭记忆重新选择。进入交易时重新核对时效与权限。
- **返回与取消：** 返回来源页保留选择、筛选与草稿。未提交编辑提供保存、放弃和留在当前页；取消编辑不取消已受理任务。已提交任务、未知结果和取消等待按原身份查询，不因返回或再次进入产生重复执行。
- **任务衔接：** 提交、等待和查看结果可在原业务页完成，全局任务中心是同一任务的补充入口。完成后提供带结果身份的“继续下一步”；失败定位到输入或依赖，修正只派生新的明确尝试。
- **统一决策时钟：** K线收盘、情报事件和定时调仓采用固定策略包内相同的bar边界规则，遵守[统一决策时钟](../common/contracts.md#decision-clock-contract)。边界之间到达的事件在下一根完整bar结束时消费；与边界同刻的事件按已声明序号和截止规则归入本次或下一次，历史回测、本地模拟、柜台仿真及实盘四种模式不得自行改变。例：09:00:20可用事件由09:01完整bar决策消费，订单只在该决策之后的可观察市场事件撮合，不回填到09:00开盘。
- **最低决策证据：** 每个决策点均保留实际消费输入及其身份/值/可得时点、稳定顺序或可重建检查点、策略与政策身份、状态起点、输出和原因；无信号、目标不变、无下单、拒绝也必须留证。可选全量行情留存关闭不关闭这些必要记录。记录不可可靠保存时阻止依赖该证据的新交易发送，并给出核对入口。
- **运行值守：** 真实运行按[有人值守](../common/contracts.md#attended-operation-contract)条件准备，确认当前可达的控制终端、通知路径和外部紧急处置入口。关闭窗口与继续服务分别说明；使用者离开监控前暂停新增风险，失去约定监控连接时按事先固定政策处置。通知失败不阻止应执行的风控动作，也不解除已有交易限制。
- **引用与选择历史：** 按[资料与研究连续性](../common/contracts.md#reference-protection-contract)保留固定输入、候选、实验、报告与决策证据依赖。重命名、复制研究、派生快照及恢复到新位置不重置样本的选择使用历史；缺少可证明独立性的记录时，不能标成未接触验证样本。
- **验收组织：** 每条旅程建立一套能连续执行的成功基线，异常分支从该基线改变明确条件。逐AC关联具体步骤、断言和证据；页面共用仅说明导航关联，不推断行为覆盖。记录首次和重复任务的耗时、重复输入与人工处置步骤，以检验个人使用负担。

**目标：** 完成三子模块间交接，形成可解释的研究输入。

## JRN-004 从真实数据准备到第一份可复核回测

**目标：** 得到明确数据、策略、成本和风险条件下的独立回测结果，不发生实盘交易。

**开始前：**

## JRN-017 从多因子研究到组合模拟与独立实盘放行

**目标：** 用一套明确的成功基线贯通因子冻结、完整策略回测、模拟运行和独立实盘准备；在相同基线上派生超限与部分成交分支，保持研究证据、账户事实与授权独立。

**开始前：**
