## JRN-001 从采集到加工、发布并固定研究输入

**目标：** 完成三子模块间交接，形成可解释的研究输入。

**开始前：**

- 明确数据来源、权限和用途；示例仅用于离线评审。
- 涉及取数费用、启停或删除时，需要本次明确确认。

### 分支与恢复

| 发生位置 | 条件                       | 反馈                     | 怎样继续                               |
| -------- | -------------------------- | ------------------------ | -------------------------------------- |
| 历史下载 | 额度不足                   | 列成功、失败及未执行范围 | 新建剩余范围计划，重新确认             |
| 质量检查 | 日历缺失                   | 完整性未知               | 补足来源依据后重查                     |
| 发布     | 研究要求历史可得但证据未知 | 阻止声称满足该用途       | 取得证据或明确调整研究设计，不绕过条件 |

### 完成标准

- 数据来自合法来源，原始记录保留。
- 加工、发布、研究运行是不同状态。
- 研究草稿固定快照、规则、基础资料和质量限制。

### 保留的资料

- 来源与对象身份、输入范围、规则、质量报告和操作结果。
- 确认内容、时间证据、未完成范围及其原因；不含明文秘密。

| 发生位置 | 条件             | 反馈                         | 怎样继续                                     |

## JRN-017 从多因子研究到组合模拟与独立实盘放行

**目标：** 保留多因子证据、冻结信号与组合预算来源，先获得可核对的模拟运行结果；用户独立决定进入实盘时，只有授权和风险均满足才能经统一执行启动。

- 研究项目已有可追溯的数据快照、交易时段、时点可得样本池和连续合约依据；因子定义与输入说明可辨认。

### 分支与恢复

| 发生位置 | 条件 | 反馈 | 怎样继续 |
| --- | --- | --- | --- |
| 恢复 | 备份损坏/结构不支持 | 拒绝对应对象且保留原件 | 使用有效当前备份，不自动改写 |
| 节点 | 身份不符或访问失效 | 新任务受阻，不承诺远程已停 | 重新核验并查询原工作 |
| 插件维护 | 必要插件被活动运行引用 | 阻止直接停用 | 转业务停止并取得明确结果 |

### 完成标准

- 资料与当前业务状态分开；未自动启动、发单或复制秘密。
- 缺项可定位，成功只对检查通过的能力成立。

### 保留的资料

- 安装身份、恢复报告、节点信任结果、插件影响、重新准备记录
