# 首个发布切片 R1

2026-10-25 决定。R1 只交付一条可用的纵向闭环：

**数据 → 规则策略 → 回测 → 评估 → CTP 仿真柜台**

## 支持集合

| 维度 | R1 支持 | 不在 R1 |
| --- | --- | --- |
| 市场 | 中国境内期货交易所的期货合约 | 期权、股票、境外市场 |
| 周期 | 日线、1 分钟线 | Tick 回测、其他分钟周期的独立来源 |
| 历史数据源 | Tushare（分钟线、全市场日线表）；SHFE 历史保证金（已核验窄范围） | 其他供应商、本地 CSV/JSON 导入 |
| 实时数据源 | CTP 行情 | 其他行情网关 |
| 策略 | 四条单合约规则（均线交叉、通道突破、时序动量、布林回归）、截面排序规则、固定权重组合 | 模型训练与预测映射、混合决策、自定义脚本 |
| 回测 | 组合账本、逐日结算、主力换月、费用版本表、滑点、风控限额、留出与滚动验证 | 成本批次与稳健性审阅、涨跌停成交限制 |
| 评估 | 绩效与归因、损失路径、静态压力、账户核对、离线报告导出；观测不足一年时不年化收益 | 跨环境一致性、策略风险贡献 |
| 执行 | CTP 仿真柜台（限价单） | 本地实时模拟撮合、真实资金交易、自动接管、断线重发 |
| 平台 | macOS Apple Silicon、Linux x86_64，本机完整运行 | Windows、Web、移动端 |

## 外部条件

R1 的完成依赖以下外部条件，均由使用者本人提供，不由软件预置：

- Tushare 账户与足够的接口积分；
- CTP 行情前置与一个 CTP 仿真柜台账户（如 SimNow），及对应的授权码与 AppID；
- 每个仿真账户的风控配置（单笔数量、总持仓、在途委托、价格偏离）。缺少风控配置时拒绝执行。

## 完成判据

R1 完成需要同时满足：

1. **闭环可走通**：在一台全新安装的 macOS 与一台 Linux 机器上，按以下步骤各走一遍并留存截图：
   连接 Tushare 下载一个主力品种一年日线与一个月 1 分钟线 → 建立数据集 → 用一条规则建策略包 →
   回测（含费用、滑点、换月）→ 生成绩效与风险报告并导出 →
   用 1 分钟线回测同一规则并建立 1 分钟策略包 → CTP 仿真柜台以该策略包运行一个交易日并核对成交与资金。
   实盘运行只接受 1 分钟策略包（2026-10-27 决定），日线策略包只用于回测与评估。
2. **结果可复核**：回测的账本、结算与评价指标能在报告中逐项追溯到固定数据版本与费用版本；
   仿真柜台的成交与资金与柜台回报逐笔一致。
3. **安全规则成立**：断线后不重发命令；缺授权、缺风控或风控插件不可用时拒绝执行；
   凭据不出现在日志、配置文件与界面存储中。
4. **质量基线**：GitHub CI 在 macOS 与 Linux 上全部通过；`pnpm run test:e2e:journeys` 覆盖第 1 条的软件内部分。
5. **文档一致**：[现状](../status.md)只描述 R1 实际能力与限制；R1 页面的界面与[Terminal 设计](../terminal.md)规则一致。

R1 不包含真实资金交易。启用真实账户另需专门验收（见[CTP 仿真验收](../acceptance/ctp-simulation.md)）。
