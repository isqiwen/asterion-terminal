## 系统管理的范围

七个核心业务模块之外，系统管理提供安装与配置、任务调度与运行节点、资料维护与诊断能力。配置、日志与调度是公共机制，业务含义保留在所属模块，不将系统管理变成另一套数据、账户或研究状态来源。

| 能力     | 系统管理负责                                             | 业务模块负责                                                           |
| -------- | -------------------------------------------------------- | ---------------------------------------------------------------------- |
| 配置     | 节点、连接、插件、凭据入口及通用偏好，配置索引与状态查询 | 数据源用途、情报提取方案、策略参数、回测条件、实盘账户限额的规则与生效 |
| 定时任务 | 时间规则、节点、触发身份、错过与重叠处理、提交记录       | 任务内容、实际输入范围、授权预算、执行前提、实际进度与产物             |
| 运行日志 | 收集、按来源与时间检索、关联定位、明确诊断留存与脱敏导出 | 订单成交、材料证据、研究记录、账户政策及其操作审计                     |
| 运行告警 | 节点不可达、任务调度异常、存储问题等系统事件及其恢复确认 | 行情异常、情报冲突、研究失败、账户风险等业务触发与解除                 |
| 通知     | 提供所需运行机制，通知呈现遵守公共交互规范               | 各模块产生有身份的事件；通知渠道不控制业务处理                         |

统一入口、统一检索和共同基础设施都不改变业务状态的唯一责任方。系统页可以跳转账户风险设置，但不独立保存另一份限额；日志可定位订单，却不能取代实盘账本。

## 配置、调度与运行的衔接

业务模块先形成明确的任务定义或输入范围规则，调度只引用并管理时间条件。启用前预览节点、时区、业务日、预算、错过及重叠行为。实际触发仍由业务模块核对权限和条件，失败保留触发与业务结果两种事实。

计划暂停影响未来触发，已有任务取消需要独立动作。安装版关闭窗口不等于服务和计划停止；机器休眠、关机或节点失联可能造成缺口。开发入口退出停止本地服务，不能声称本地调度仍执行；远程工作按其真实位置核对。

策略定时调仓归策略与实盘运行，不向公共调度开放任意交易指令、脚本或断线后补发。任务被触发、已受理和业务完成分别显示，未知受理结果先查原身份。

## 日常操作与证据

目标工作台包括配置索引、计划/触发列表及日志诊断。通知中心归[公共通知规范](../../common/interaction.md#req-com-ux-02)，触发和解除依然由所属模块确认。没有新增独立风控或告警业务模块。

完整流程见[配置生效核对](../../workflows/README.md#jrn-035)、[定时任务与离线恢复](../../workflows/README.md#jrn-036)、[日志诊断与资料保护](../../workflows/README.md#jrn-037)、[告警与业务限制](../../workflows/README.md#jrn-038)。现有设置、任务抽屉和关于页面保留实际截图；新增完整工作台明确标为待设计，不表示产品已经实现。

## 系统交付范围

以下是本次交付版采用的设计规格，源于用户授权完善文档；不冒称已经逐项获得用户确认或已经实现。具体部署资料按[交付与验收](../../delivery.md)核验。模块内通用“支持的方法/来源”以此有限集合及显式能力检查为准。

| 能力 | 必须交付的行为 | 限制与拒绝条件 |
| --- | --- | --- |
| 安装与准备 | macOS Apple Silicon和Linux x86_64桌面；Linux x86_64远程节点。提供可核验安装产物、依赖完整性、首次目录/用途清单、插件能力及冲突检查、卸载影响预览。 | 核心提供机制、插件提供来源/存储/策略/风险算法；不增加Web、Windows、Notebook或独立CLI。支持OS最低版本随发布产物锁定并实际验证。 |
| 配置与资源 | 偏好即时保存；数据源认证修改需明确重连，账户/风险变更通过业务检查生效；节点地址/信任及服务参数显示需重连/重启的具体对象与影响。 | 没有默认自动重启交易服务；配置索引只引用责任模块。节点信任失效拒绝敏感操作，移除节点不删除远程业务资料。 |
| 任务与调度 | 单用户任务队列，默认1项计算、允许最多2项并发研究；定时采用每天/每交易日固定时刻和最短1分钟的固定间隔。支持跳过、记录漏触发及人工批准一次有限补跑。 | 默认不补跑、同计划不重叠；默认每计划待处理最多1次，已有未决触发先核对。禁止调度补发交易命令。节点费用与云采购不纳入管理。 |
| 资料与日志 | 手动完整备份、校验、独立目录恢复及依赖预览；无默认删除数据/账本。诊断日志默认保留30日且最多1GiB，先到限制先清最旧可清诊断；业务审计独立保留。 | 诊断额度不是业务资料限额；业务记录不随日志轮转清理。备份不含秘密；自动备份默认关闭，启用必须选路径、频率和保留数量。 |
| 导出与通知 | 研究/交易明细CSV和离线HTML报告，诊断脱敏包；字段顺序采用预置模板。通知含信息/警告/阻断级别，按同对象与同原因聚合，应用内持久显示；桌面提醒默认关闭。 | 已读与业务解除独立；阻断状态不可隐藏或被静音解除。通知记录默认90日，清理不影响源事件或账本；导出不自动上传。 |
