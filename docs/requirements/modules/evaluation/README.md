# 评估

开发前产品需求规格。本页定义目标功能、界面操作、业务规则及验收条件。

**模块目标：** 统一评价回测、模拟和实盘的绩效、风险及证据可靠性，形成可追溯结论和报告。

**职责边界：** 只读固定来源事实；不修改原账本、代替特征评价或执行账户风控与交易。

目标入口为**评估 → 绩效与归因 / 风险与压力 / 稳健性与综合评价**，具体视图见[界面设计总览](../../common/ui-designs.md#target-navigation)。一级和二级导航分别对应本模块与子模块。页面字段、动作前提及状态在对应UI条目中定义。

## 已确认的业务划分

评估（Evaluation）是数据、情报、分析、策略、回测之后的第六个核心业务模块。用户已确认三个子模块：**绩效度量与归因、风险分析与压力测试、稳健性验证与综合评价**。分析报告是三者共用的输出能力，由综合评价集中管理结论和报告流程，不单列第四个子模块，也不复制指标计算。

| 子模块               | 回答的问题                     | 核心输出                                   |
| -------------------- | ------------------------------ | ------------------------------------------ |
| 绩效度量与归因       | 表现如何，收益从哪里来？       | 带口径的绩效、交易统计、基准与收益成本贡献 |
| 风险分析与压力测试   | 承担什么风险，不利情景会怎样？ | 损失路径、敞口、资金约束、压力损失及限制   |
| 稳健性验证与综合评价 | 结果可靠吗，证据支持什么决定？ | 独立性、敏感性、跨环境偏差、结论及统一报告 |

## 评价对象与固定上下文

支持回测、模拟交易与实盘来源，评价对象可为单策略、组合或账户。范围不能混同：共享账户下的策略分项依据明确归属政策，未分配费用和风险保留在组合层；独立回测净值相加不等于可交易共享账户组合。环境名称、策略内容、账户范围、数据或账本切片、观察截止、交易日历、币种单位、资金流、估值/费用口径和实际覆盖共同构成固定评价上下文。

实盘仍在变化时，新成交不会改写已保存的历史评价。用户显式选择新截止生成新评价。只读评估不要求新增交易授权；需要执行新回测或真实控制动作时分别回到对应模块检查条件。未支持的跨币种、统计方法或来源组合明确不可计算，不通过默认换汇或拼接结果伪装支持。

## 端到端闭环

选择并固定来源 → 核对上下文和缺口 → 度量绩效与归因 → 分析风险与压力 → 检查独立性、稳健性和偏差 → 保存支持/不支持/证据不足及理由 → 生成统一报告 → 显式交接新研究、策略候选或交易审阅。

评价问题和方法在评估中固定，回测将它们落实为执行条件和运行清单。已有执行计划不能被后来的评价重新包装为事前计划；事后探索须明确标识。运行中的真实风控仍按已授权政策工作，评估工作不能成为其继续控制风险的前置依赖。

## 风险分析与稳健性验证的区别

风险分析回答某个情景损失多少、资金是否不足、能否退出；稳健性验证引用同一情景结果判断原策略结论是否依赖脆弱假设。前者保管情景计算和损失，后者保管证据解释，不重复计算。静态持仓冲击在评估计算，动态策略和撮合变化由回测执行，禁止把静态重估冒充真实平仓过程。

## 报告与交互边界

报告共用绩效、风险、验证和偏差结果，冻结输入、方法、图表、结论及限制，导出不另算指标、不发送交易或自动上传。评估工作台通过固定评价身份联动绩效、风险、稳健性、偏差及报告。目标菜单按模块组织，但不据此改变进程或插件划分。核心提供机制，评价算法由可信插件承担；方法与格式清单按本章交付范围，判断阈值按具体研究显式配置。

实盘评价需要识别真实入金和出金，这不扩大回测的初始账户或资金流模拟范围。回测未支持的条件仍明确拒绝；评估仅对来源实际具备的事实采用相应计算方法。

## 情报驱动结果的评价限制

评价情报驱动策略时保留材料覆盖、提取错误/遗漏、核验规则、信息延迟和历史加工模式。情报提取准确率不等同于预测能力或策略绩效；后者仍由分析和评估按各自职责检验。事后处理与实际历史可得实验不可无提示混比；模型事后知识污染未知时结论明确限制，不声称已消除泄漏。

## 风险评价与执行约束的分工

风险分析仍由评估负责，实时账户限制归实盘，策略预算归策略，模拟规则执行归回测。评估引用[共用交易约束](../../product.md#execution-risk-semantics)和实际采用的政策、输入、触发与订单证据，区分策略计划、准入拒绝和成交结果；结论只提供审阅依据，不自动改变账户限制或下单。

## 与配置、调度和通知的交接

评估拥有评价配置、固定证据与报告结论。系统可关联计算任务和诊断，但不由日志或通知级别推断风险结论；提醒用户查看报告不自动改变真实账户状态。具体公共分工见[运行支撑边界](../../product.md#operational-support-boundaries)。

## 指标公式、分母与不可计算

下表固定当前产品计算定义，不声称只有这一种金融口径。输入均为扣除已记费用的固定账户事实；金额采用账本精度，统计输出保留方法参数及精度。行情涨跌、合约价格收益、策略净收益和账户权益收益不可混称。

| 指标 | 计算约定 | 不能计算或比较的条件 |
| --- | --- | --- |
| 投资利润 | 期末权益−期初权益−净外部流入；净流入为入金减出金 | 现金流范围不完整时保留未核对标记，不称最终利润 |
| 无现金流总收益 | 期末权益/期初权益−1 | 期初权益非正或存在未处理现金流时拒绝套用 |
| 时间加权收益 | 在每个外部现金流边界取流入前与流入后估值，分别计算无现金流子区间收益；总收益为各(1+r)连乘减1 | 缺边界估值不能以期末减现金流近似冒充精确结果 |
| 年化收益 | 总收益的增长倍数按1/Y次幂减1；Y为起止实际日历秒数除以365.2425天 | Y≤0或增长倍数≤0不可计算；不足一年标明短区间年化，不作实现收益承诺 |
| 年化波动率 | 等间隔收益的样本标准差乘sqrt(A)，A为所选日历/频率下明确的年期数 | 少于2个有效周期或频率不一致不计算；不得混合分钟和日收益。标明平方根时间缩放，未作自相关调整 |
| Sharpe | 同频超额收益均值除以其样本标准差，再乘sqrt(A)；无风险收益先按明确复利口径换到同频 | 无风险输入未配置、标准差为0或样本不足，显示不可计算，不显示0/无穷；标明常规年化及未作自相关调整，不能据此宣称跨期风险聚合准确或统计显著 |
| 回撤 | 资金流调整后的净值相对截至当时高水位的下降比例；最大回撤取最大下降幅度，显示起点、谷底、恢复时点及是否未恢复 | 不把现金出入当回撤；缺资金流处理时可单列原始权益变化但不可混称净值回撤 |
| 胜率/盈亏比 | 以声明的闭合交易分组和扣费盈亏为单位；胜率=盈利笔数/全部闭合笔数，零利润计入分母；盈亏比=平均盈利/平均亏损绝对值 | 无闭合交易、无盈利或无亏损时相应比率不可计算；部分未平与成交流水不当闭合交易 |
| 换手与费用 | 换手=期间各成交名义金额绝对值之和/期间正权益算术均值，采用双边口径；费用为实际记账费用之和 | 权益均值非正则换手不可计算；不能用保证金替代权益分母；滑点已计入成交价不重复扣款 |
| 归因 | 按固定成交/持仓归属汇总成员、品种、方向和时段贡献；各贡献加未分配残差须等于已核对总额 | 分配未知保留残差，不按权重强行分摊而称实际贡献 |

### 历史尾部与压力

损失样本L为固定同频收益取负，正值表示损失。历史VaR采用经验分位：升序第ceil(q×n)项；q为明确置信水平。ES采用最差(1−q)×n个样本的均值，不足整数的边界样本按尾部概率质量分摊；并列按相同损失值处理。显示n、q、频率、区间和预计尾样本数量；本交付要求预计尾样本数至少5，否则显示样本不足。此门槛是产品判定规则，不保证尾部风险估计可靠。

静态价格冲击仅在固定持仓及线性合约口径下估算损益；冲击保证金率单独影响资金需求，不直接当作损失。需要路径、成交或动态仓位的情景回到回测产生事实。来源规则、情景参数和限制随结果固定，不能把静态最坏单项相加冒充已验证联合分布。

### 可独立手算的验收例

- 无现金流：1000→1034，利润34，总收益3.4%。
- 有现金流：1000→1100后流入500，流入后1600→1680；投资利润180，两个区间收益10%、5%，时间加权总收益15.5%；不能用68%代表投资收益。
- 净值100→120→90→108，峰值120到谷底90的最大回撤25%，最后仍未恢复到峰值。
- 不存在亏损交易时，盈亏比不可计算；不得用0作平均亏损分母或标为“无限优秀”。



### 年化指标的解释与验证记录

年化波动率和Sharpe同时展示原始采样频率、A、观测区间、有效数量及无风险收益转换规则。sqrt(A)定义为产品的常规年化展示；存在序列相关时，该值不等于完整考虑协方差的跨期风险。报告不得把它表述为独立性检验或未来收益保证。时间聚合风险需考虑各滞后的协方差；没有适用估计及足够资料时不自动补做修正。方法解释参考[Lo：The Statistics of Sharpe Ratios](https://rpc.cfainstitute.org/research/financial-analysts-journal/2002/the-statistics-of-sharpe-ratios)。

研究独立性按[信息使用与研究谱系契约](../analysis/README.md#information-use-contract)检查。评价更换来源快照、采样频率或报告名称不清除观察历史；评估页面打开最终留出统计也要记录已观察事实。绩效、风险和稳健性共用这些记录，不重复维护互相冲突的“未见”标记。
