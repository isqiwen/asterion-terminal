# 分析

[返回上级](../../README.md) · [需求总纲](../../README.md) · [界面规范](../../common/ui-designs.md) · [跨模块流程](../../workflows/README.md)

开发前产品需求规格。本页定义目标功能、界面操作、业务规则及验收条件。

**模块目标：** 从数据中发现规律，构造特征与因子，评价有效性并形成有适用边界的研究结论。

**职责边界：** 读取固定数据，产出假设、变量定义和评价证据；不负责基础数据修复、账户成交模拟、仓位分配或交易授权。

目标入口为**分析 → 数据探索 / 特征与因子 / 有效性评价与筛选**，具体视图见[界面设计总览](../../common/ui-designs.md#target-navigation)。一级和二级导航分别对应本模块与子模块。页面字段、动作前提及状态在对应UI条目中定义。

## 业务范围与职责

本模块按研究活动划分为数据探索、特征与因子、有效性评价与筛选三个子模块，业务结构不决定插件或服务进程数量。覆盖规则策略和多因子研究，不要求所有研究都使用机器学习或以IC作为唯一评价方法。

| 子模块             | 回答的问题                         | 输入                           | 输出                               |
| ------------------ | ---------------------------------- | ------------------------------ | ---------------------------------- |
| 数据探索与统计分析 | 发生了什么，有哪些值得检验的规律？ | 固定数据、样本范围、可观察资料 | 统计观察、反例、研究假设及样本计划 |
| 特征与因子构建     | 怎样把想法表达成当时可计算的变量？ | 假设、数据引用、定义与参数     | 变量、标签、时间边界及结果引用     |
| 有效性评估与筛选   | 是否有用、是否稳定、哪些值得继续？ | 固定变量、标签、计划与基准     | 评价证据、候选集、限制和交接包     |

指标是变量的一种计算方式；特征是决策时可使用的输入；因子是具有研究解释的变量或评分；标签是事后用于评价的结果。信号评分与交易仓位分别定义，不允许把研究分数直接当资金比例。

## 与其他模块的交接

| 对端       | 分析负责                                         | 对端负责                                                     | 交接条件                                                       |
| ---------- | ------------------------------------------------ | ------------------------------------------------------------ | -------------------------------------------------------------- |
| 数据       | 声明所需字段、时间角色、快照和用途；定位异常证据 | 采集、基础清洗对齐、连续序列生产、存储、查询、快照与引用保护 | 输入身份、来源、交易日历、可得时间和质量范围可核对             |
| 策略       | 交付固定变量、信号与评价依据                     | 开平条件、信号到仓位、组合与资金、固定策略包及交付           | 候选可以未通过验证，但状态与限制必须如实显示；不直接运行       |
| 回测       | 提供分析变量、样本及评价证据引用                 | 完整策略的历史成交与账户模拟，交付独立评估使用的事实         | 明确策略包、数据、模拟条件和必要风险，分析结论不能替代完整验证 |
| 任务与节点 | 保存运行条件、业务进度和结果引用                 | 调度、进程、资源、取消与终态查询                             | 显式获得运行身份，重复点击不重复提交；失联后先核实结果         |
| 风控与交易 | 提供研究来源与适用范围                           | 风险准入、账户授权和统一执行                                 | 统计分析不要求交易授权，也不能授予交易授权                     |

基础清洗修复数据事实；研究变换表达研究假设。基础缺失不得静默填零；如果某种研究方法明确需要估计或插补，必须登记方法、拟合范围和估计标记，原始缺失事实保留。中性化、降维、合成算法由可信插件提供，核心只提供定义、任务和结果追溯机制。

## 贯穿三者的研究记录

| 对象       | 必须保存的内容                                    | 生命周期与约束                                         |
| ---------- | ------------------------------------------------- | ------------------------------------------------------ |
| 研究问题   | 问题、机制、事实/假设、用途、支持与否定条件       | 可以先保存探索草稿；没有评价标准不标为验证结论         |
| 样本计划   | 数据快照、成员规则、日历、频率、角色、标签边界    | 最终留出在探索前隔离；换名不能恢复已经使用的独立性     |
| 定义       | 内容身份、算法/表达式、依赖、参数、单位、可得时间 | 固定定义可复用，修改形成新定义；旧实验继续引用原定义   |
| 运行       | 计划、定义、输入、拟合范围、资源、进度和失败阶段  | 完成/失败/取消都是事实；失联是观察状态，不等于运行终止 |
| 结果       | 有效数量、排除原因、数值口径、图表配置、结果引用  | 已完成结果不原地改写；来源修订后建立新运行进行比较     |
| 结论与候选 | 支持/不支持/不足、保留/剔除理由、证据和适用条件   | 交接只引用固定内容；任何交易行为另经策略、风控与授权   |

这些记录贯穿三个子模块，不增设第四个业务子模块。它们是真实研究活动记录，不是为开发历史添加格式版本计数器。

## 端到端操作与状态

1. 在数据模块确认可用快照，建立研究问题并声明样本角色。
2. 只在允许探索的范围查看分布、关系和事件，记录观察与反例。
3. 将假设表达为特征和目标，预览每项输入和结果的时间关系。
4. 先确定划分，再拟合处理；每个滚动训练窗口分别拟合并固定参数。
5. 在开发验证段检查方法，所有试验和重新选择均有记录。
6. 固定候选后使用未参与选择的最终留出评价；看过后调整方案则记录该资料已用于选择。
7. 保存结论并交接策略草稿，另行定义交易规则和完整回测条件。

探索可以回到新假设反复进行，但不能恢复“未见数据”状态。点击查看最终留出结果前，应明确提示该行为会使其成为已观察证据；打开普通探索图不得自动加载留出统计。

<a id="information-use-contract"></a>

### 信息使用记录与研究谱系

研究、候选、实验和评价必须关联研究谱系。每次派生记录父对象、变化理由与已用信息；另建研究也须检查所选资料与历史观察范围的重叠，不因新名称、新快照身份或重新聚合频率清除使用记录。识别依据为来源资料身份、真实合约/成员、原始观测时间区间及变换血缘；不能仅比较显示名或快照摘要。

信息使用事件记录观察人、观察时间、研究对象、数据范围、样本角色、展示或导出内容、用途及关联选择决定。查看最终留出前先展示范围并请求明确确认；只显示标题和覆盖数量不算读取结果，呈现统计、图形、标签或收益后即记录已观察，关闭页面或取消后续操作不能撤销。已经用于选择的证据还须标记选择污染；“已观察”和“已用于选择”分别展示。

信息记录跨分析、策略、回测和评估共享引用。复制研究、换频率、数据修订及重新命名均保留已观察区间的关联；数据修订增加的新内容也不能把同一已观察历史自动恢复为独立留出。用户另填外部工具、公开研究或记忆中已经接触的范围；没有声明时显示“外部观察范围未确认”，不宣称系统证明了研究者从未见过数据。范围重叠只说明信息使用事实；研究者须解释是否影响本次选择，系统不得把不相关问题一律判为无效。

资料与结论的保存、修订及删除同时遵守[固定引用与删除保护契约](../../common/contracts.md#reference-protection-contract)。删除实验结果不删除仍被谱系或选择决定引用的信息使用事实。界面可修正错误记录并保留原记录及理由，不能直接把已观察重置为未观察。用于候选独立验证的区间，须满足本次决策前未观察且未参与该谱系选择；否则只作开发/描述证据，或改用新的前瞻观察。

验收场景：研究甲已查看D1的T61～T80结果；新建研究乙并选择同源D2修订版或该区间周线时，仍显示重叠观察及来源，不自动标“最终未见”。在确认前取消查看不新增观察事件；结果已呈现后关闭页面，观察记录仍保留。


| 状态                    | 使用者看到什么                           | 可执行操作                         |
| ----------------------- | ---------------------------------------- | ---------------------------------- |
| 草稿                    | 未定字段、未检验条件                     | 保存、修改、校验，不显示成功结果   |
| 输入被阻断              | 缺少字段、错误时间、无效定义和受影响范围 | 定位并修正，保留已填内容           |
| 排队/运行中             | 当前阶段、已完成范围与运行身份           | 离开页面、查看任务、请求取消       |
| 取消中                  | 请求已送达但终态未确认                   | 等待确认，不把请求成功显示为已取消 |
| 完成/部分完成/失败/取消 | 实际覆盖、排除项、终态及可用结果         | 查看证据；补跑需要明确创建新运行   |
| 结果不明                | 最后已知阶段和待核实的运行身份           | 查询原运行，禁止自动重复提交       |
| 结论已保存/候选已冻结   | 具体证据与适用限制                       | 只读复核、派生新研究或交接策略草稿 |

单项结果完成不等于整个批次完成；统计排除无效行也不等于任务部分失败。两种情况分别显示，完整样本统计仍须给出排除数。

## 界面设计原则

业务工作台由问题与样本、探索图表、变量定义、标签时间、评价证据和候选清单组成，它们是六项交互规格，不强制增加六个菜单。视觉采用Terminal统一风格；具体字段、动作和异常见各子模块的UI条目。

六项界面共用研究身份、固定快照、样本角色和信息使用记录。页面跳转保持这些上下文；字段、按钮前提、结果下钻和返回行为由各UI条目约束。

## 验收与方法边界

重点核对：缺失不当零、常数相关未定义、特征当时可得、标签跨界剔除、训练内拟合、最终留出使用记录、部分失败不冒充全面验证、候选不产生仓位或授权。具体可观察验收均附在REQ/FR/UI条目下。

方法集合、推断方式与容量采用本章交付范围和非功能基线，窗口与样本门槛由用户为具体研究显式配置；不声称任意因子能被自动判定有效，不以固定阈值保证未来收益。支持的方法必须在界面中列出适用条件和所需资料，缺少能力明确不可用。

方法依据：[NIST探索性分析目标](https://www.itl.nist.gov/div898/handbook/eda/section1/eda14.htm)、[训练与评价数据泄漏](https://scikit-learn.org/stable/common_pitfalls.html)、[时间序列验证](https://scikit-learn.org/stable/modules/cross_validation.html#time-series-split)。这些资料支撑统计和验证原则；三子模块结构是本产品的职责设计，并非外部标准规定。

## 独立评估的交接

完整策略、组合和账户的绩效、风险分析及可靠性结论统一由[评估模块](../evaluation/README.md)负责。分析保留特征与因子的评价，策略保留逻辑、模型和组合定义；不能用局部变量证据替代完整策略验证。

## 情报输入与分析边界

[情报模块](../intelligence/README.md)交付带证据、时间语义和用途限制的结构化事件。分析负责定义事件强度、窗口与标签、检验预测关系及构建特征；不重复进行材料获取或改变情报发布状态。固定输入保留实际可得/事后研究模式，缺失或延迟不能默认为零事件。供应商结构化基本面数据可以直接来自数据模块。

## 与配置、调度和通知的交接

分析拥有样本、方法、计算定义和研究结果。周期研究先固定任务或明确输入范围规则，再由系统调度；完成和失败由分析确认。系统日志与通知只关联研究记录，不替代固定证据或判定方法有效性。具体公共分工见[运行支撑边界](../../product.md#operational-support-boundaries)。

## 分析交付范围

以下定义必须提供的业务能力、计算方法及拒绝边界。来源与部署条件按[交付与验收](../../delivery.md)核验；模块内“支持的方法/来源”以本表及显式能力检查为准。

| 能力 | 必须交付的行为 | 限制与拒绝条件 |
| --- | --- | --- |
| 研究与探索 | 研究按独立问题组织，支持标题、标签、Markdown笔记和来源引用；样本按市场/品种/真实合约/时间/流动性过滤，提供计数、缺失、分位数、直方图、时间序列、相关性及日/周/月/交易时段分组。 | 品种及周期是筛选维度，不固定为项目层级。样本资格按当时信息判断；缺连续性或历史不足时排除并保留原因。 |
| 特征定义 | 表达式编辑与可信算法插件两种入口；算子支持四则运算、比较/逻辑、滞后、收益差分、滚动均值/标准差/极值、横截面排序、截尾及标准化。窗口为正整数，缺失与预热规则必选。 | 无任意系统命令或Notebook环境；未来位移不可用于预测特征。输入字段、单位、类型及可得时点不符时定位到表达式与字段。 |
| 拟合与合成 | 训练内估计均值方差和截尾边界；支持固定权重与训练内线性合成、按品种组去均值。拟合输出固定供留出区间使用。 | 训练窗口、样本数及拟合参数有独立身份；禁止在全部样本上拟合后再声称样本外。其他中性化算法由显式插件能力说明，不默认纳入。 |
| 标签与评价 | 标签支持未来固定交易步数收益、方向和阈值事件；提供Pearson/Spearman相关、IC时序、分层表现、条件命中率、分段稳定性与特征冗余对照。 | 标签窗口重叠与观测/决策可得时间逐行检查。统计显著性不能用独立样本假设掩盖时间依赖；提供[移动块重采样](#resampling-contract)，固定联合时间抽样、统计量、块长、次数及随机源；未设合适条件只报告描述统计。 |
| 筛选与交接 | 在评价前保存选择指标、方向、阈值及留出范围；展示全部候选、排除原因和筛选历史，固定研究候选交给策略。 | 系统不预设盈利或IC合格线；阈值是每项研究必填的判断计划。研究候选不是固定可执行策略。 |

## 计算口径与可复核边界

| 方法 | 本交付采用的定义 | 缺失与验收边界 |
| --- | --- | --- |
| 滚动特征 | 以已完成观察为窗口末端，只含当前及过去数据；默认完整窗口才输出；滞后为正整数交易步数 | 缺失/跨停盘区间按固定规则解释，不把缺口当0；窗口不足显示预热中 |
| 均值/标准差与标准化 | 均值为有效值算术平均；样本标准差分母为n−1；训练标准化保存训练均值及标准差，应用时不重新拟合 | n<2或标准差为0时对应结果不可计算；不能以1替代分母悄悄继续 |
| 分位数/截尾 | 非加权样本采用线性插值：排序后位置q×(n−1)，按相邻值距离插值；q在[0,1]内 | 截尾上下分位必须有序，边界只在训练集估计；方法身份写入结果 |
| Pearson / IC | 有效成对样本的中心化乘积和除以两列离差平方和乘积的平方根；每个截面单独计算IC，再展示时序 | 任一列常数、配对不足则不可计算；数学可算不代表样本足以推断有效性 |
| Spearman / Rank IC | 对同一有效配对集合分别求平均秩（并列取平均），再按Pearson定义计算；方向随原标签定义 | 不使用忽略并列的简化式；不得在不同缺失集合上各自排名再拼接 |
| 标签 | h步简单收益为P(t+h)/P(t)−1，方向由显式阈值判定；价格比率要求起点为正，其他情形使用明确价格差标签 | 结果可得时间不得早于结束价格可得时点；越过样本末端标缺失，不回填0 |
| 分组与重采样 | 分组先固定维度，再报告有效数量和排除原因；移动块重采样遵守[计算契约](#resampling-contract)，固定联合时间索引、区间方法及用途 | 所有重采样结果保留范围，不能把重采样当独立新市场证据；不足块数不报告可靠区间 |

分位数的线性插值口径参考[NumPy quantile定义](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html)，Pearson及常数输入边界参考[SciPy pearsonr定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.pearsonr.html)。这些参考用于消除计算歧义，不要求核心直接依赖相应Python库，也不表示采用其默认显著性检验。

验收小例：输入[1,2,3]的均值2、样本标准差1、标准化[-1,0,1]；[0,10]的25%线性分位为2.5；同向非恒定配对相关为1，常数列相关为不可计算。输入、配对、分组和拟合区间必须能从结果反查。

## 移动块重采样计算契约

分析和评估共用非循环移动块重采样；用于固定时间序列的均值、逐时点IC均值以及同范围两个候选的成对均值差区间。重采样不重新训练模型、不生成市场成交事实、不增加独立市场证据，也不自动校正多重选择。其他统计量须由明确登记的方法另行声明，不能复用本契约的区间标签。

| 参数或步骤 | 必须固定的规则 |
| --- | --- |
| 输入与统计量 | 保存固定快照、样本角色、频率、时间索引、成员、缺失掩码、排除规则、统计量及单位。IC先按每个真实截面计算，再对其有效时间序列重采样；候选差异使用同一时点的配对差，不能比较两组独立抽样结果。 |
| 连续分段 | 依据固定日历和输入缺口确定连续片段；块不得跨训练/验证边界、未经解释的缺口或两个独立研究区间。每段分别抽样并保留原长度，汇总权重事前固定。交易日历中的合法休市不自动当作数据缺口。 |
| 块长 L | 正整数交易观察步数，由用户结合标签重叠跨度及依赖诊断声明依据；L=1须说明采用独立抽样近似的理由。显示每段长度n、可选起点n−L+1及floor(n/L)作为长度支持信息，不称独立样本数。n<2L时不提供推断区间，可保留描述统计；通过长度门槛不等于依赖结构已被充分覆盖。 |
| 抽样 | 每段从0至n−L的合法起点等概率有放回抽取连续L行；拼接至不少于n行后仅截去末块超出n的行，不把序列尾部循环接回头部。一次抽样的时间索引同时用于全部品种、候选和缺失标记，保留同刻共同冲击。 |
| 次数 B 与随机源 | B为显式正整数；保存方法身份、随机源身份、种子、B及每次抽样起点清单。要求B×(1−c)/2≥10，使区间两端预期各有至少10个重采样统计量，否则只显示模拟分布并提示分位支持不足；该显示门槛不保证统计可靠。 |
| 区间 | 用户选择置信水平c，0<c<1；对B个统计量取(1−c)/2与(1+c)/2分位，采用本模块线性插值分位定义，标为“移动块百分位区间（未作多重选择调整）”。不将区间未跨0自动转为候选通过或因果结论。 |
| 缺失与未定义 | 缺失标记随时间块一起移动，每次按同一事前配对规则计算并报告有效数量。任何重采样统计量未定义时显示其数量及原因，本次不出具完整B次的推断区间，不静默删掉失败样本后仍标完整。 |
| 适用性 | 记录近似平稳及块长能够代表依赖结构的研究理由；强结构变化、很少片段或长依赖无法覆盖时只作探索并披露。按品种各自打乱、跨训练验证拼块、仅对胜出候选隐藏全部尝试均不合格。 |

可复核算例：固定两列A=[1,2,3,4]、B=[10,20,30,40]，L=2，某次已记录起点为[1,0]（从0计数），对应时间行[1,2,0,1]。抽样A=[2,3,1,2]、B=[20,30,10,20]，均值分别2与20；两列必须保持同一行映射。此例只检查抽样和联合关系，不计算可信区间；正式区间仍检查次数、依赖与全部尝试。
