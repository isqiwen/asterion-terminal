# CSV 历史逐笔数据

`asterion.data.csv` 是通过 `MarketDataPort` 接入的第一个数据插件。只读取用户指定的文件，不生成数据、不写回文件、不连接券商。

构建后运行：

```sh
./build/Debug/asterion replay-csv /absolute/path/trades.csv VENUE SYMBOL crypto USD 0.01 0.001 1
```

位置参数依次是文件、场所、实际标的、资产类别、计价币种、价格步长、数量步长和合约乘数。资产类别接受 `equity`、`futures`、`option`、`crypto`、`fx`、`bond`、`commodity`；此命令只做逐笔规格校验，不表示已支持该资产的交易/结算规则。

文件首行必须为 `timestamp_ns,price,quantity`，后续每行恰好三列，按时间非递减排列。时间为非负 UTC epoch 纳秒；价格/数量是最多八位小数的十进制数字，数量必须为正并符合步长。支持 LF 和 CRLF。不接受空行、未知列、自动字段映射、引号转义、指数格式或静默舍入；这是一种明确的数值 CSV 契约，不是任意 CSV 导入器。

整个输入校验完成后输出记录数和最后一条数据的时间、价格；异常输出具体行号并以非零状态退出。仅有表头表示该文件无记录，不代表市场当天无成交，也不建立行情覆盖或发布版本。

停止后重新启动会从文件头重新读取。失败后禁止继续读取；用户需要修复源文件并显式重启。相同时间戳的成交保持文件内顺序，不推断其是否重复，不声称 exactly-once。
