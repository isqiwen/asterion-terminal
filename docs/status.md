# 现状与下一步

## 已可用

| 模块 | 状态 |
| --- | --- |
| 桌面链路 | Electron + Node-API + C++ 编排，启动检查、自动升级、设置窗口、中英文；开发与安装版默认分离 Agent、数据、凭据及界面配置 |
| 实时行情 | CTP 全市场目录与订阅、期货全景、自选、五档、分时、分钟 K 线、1 分钟涨速、增量同步 |

| 研究 | 持久化任务、历史 K 线 SMA 组合回测、动量因子评价；研究内包含回测、因子与历史回放；从历史仓库版本直接进入回测或日线因子，不依赖下载任务；行情与结算版本固定，支持同合约跨下载拼接、保存具名合约组合并整组恢复，数据草稿绑定研究服务，切换合约不沿用旧计量参数 |
| 策略 | 可信 SMA 策略宿主、授权交接、重启重放 |
| 实盘 | CTP 账户连接（凭据不落盘）、按连接和交易日授权、合约白名单与交易单位校验、涨跌停与价格偏离检查、订单限额风控、先记录后发送、断线不重发、重连重建柜台快照、迟到查询回报隔离、未确认委托提示、账户费率查询 |
| 原生插件管理 | 本机安装预览、并存版本、卸载、研究服务启用清单；任务和账本固定算法摘要 |

| 服务管理 | 本机 launchd Agent、远程 Linux SSH 引导与 mTLS、健康监督、自动升级；数据与研究按需准备本机环境，远程断线不自动切换 |

## 已知限制

- 历史数据只来自数据源，生产历史插件目前只有 Tushare。已支持具名固定版本的研究组合和显式跨下载拼接；已支持手动预览增量及原范围重取缺口，尚无定时自动更新及依赖清理；覆盖核对只比较整日缺口，不证明日内完整性。
- 动态 ABI 已接入历史数据、连接验证和订单限额风控；策略、存储、CTP/执行和分析工具仍待迁移。远程插件配置界面、多风控组合及任意风控配置编辑器未开放。
- 实盘只有限价单，风控为订单限额加价格检查（每笔委托查询一次行情，约多等 1 秒）；只在测试用 CTP SDK 替身上验证，未在真实券商或仿真环境验证。
- 组合账户只支持单币种，保证金按合约相加，没有跨品种保证金优惠或相关性风险；组合内合约必须交易日相同。
- 没有交易所规则库：模拟交易与回测的保证金和手续费由用户填写或从费率模板填入（模板可来自实盘账户的券商费率），最小变动价位和合约乘数在有 CTP 合约目录时自动带入；费率按已固定版本的生效日期切换，尚无历史费率自动获取、盘中调整或返佣规则。
- 分钟线只来自行情服务运行期间的观测，服务重启后从头开始；不是历史分钟档案。
- 回测合计最多 200000 根 K 线，因子只支持单合约；模拟交易与策略会话合计最多 20000 根（逐根记账，1 分钟单合约约两到三个月）。
- 期货全景的境外行情、指数行情条、金融期货基差没有数据源。
- `Decimal` 范围约 ±922 亿，足够单账户，不适合累计成交额等大数。
- 远程节点的长操作（SSH、上传、升级）和本机服务的启动（研究、模拟会话、策略）在操作锁之外串行执行，同时只能进行一个。
- 本机 launchd 之外的系统服务、多物理机器网络只在容器和回环环境验证过。

## 下一步

1. **可复用数据集**：具名合约集合、范围、计量参数及固定数据版本已支持保存和整组恢复。同合约跨下载组合已支持，重叠去重、冲突拒绝。手动增量下载和缺口重取已支持，新下载作为独立版本供显式选择；已支持当前研究服务的任务／已保存数据集引用查询及本窗口草稿检查。本机默认目录中的停止账本和本机 Agent 清单中运行的回放账户均已纳入只读检查，无法读取的账户明确标为未完成。已连接远程节点中运行的回放服务及当前直连账户也已支持 mTLS 引用查询；停止与不可达的远程账本明确列为未检查。已连接节点的其他研究服务也已纳入检查，按服务展示任务和已保存输入，即使源文件副本不在该服务也可查找引用；停止的本机研究服务已支持只读账本检查，不恢复任务或重新发布数据；已登记但未连接的节点单独展示检查缺口，停止的远程服务仍未检查。接下来补齐远程停止账本范围和删除前一致性检查；当前仍不开放物理删除。
2. **因子数据管线**：共享因子输入输出与计算规则，分开特征和未来收益标签，固定训练处理器状态，并逐步支持分块读取。
3. **策略复用**：固定策略版本和参数，从回测结果创建新的历史回放运行，保留数据、费用和风控来源；再接入实时仿真策略，不能将历史回放冒充实时模拟。

4. **券商仿真验收（尽早并行）**：按 [验收清单](acceptance/ctp-simulation.md) 用提供商的仿真账户核对登录、结算确认、报单、撤单、成交回报和断线恢复；SDK 替身通过不等于此项通过。
5. **持续运行**：在仿真环境跨交易日运行，记录重连、授权失效、服务重启和账本恢复结果。
6. **交付验证**：在真实 Linux x86_64 节点验证部署、升级和恢复；macOS 完成开发者签名与公证。
