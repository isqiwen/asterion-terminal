## 用户任务与反馈

默认体验面向一台机器、一个本地工作环境。业务区承载工作模板，不应要求用户理解插件、任务租约或数据发布步骤才能完成操作。

- 主视图显示当前对象、关键结果、来源、适用交易日、时效与一个主要操作。配置按需展开，技术标识和完整证据进入详情；阻断错误与未知状态保持可见。
- 历史、实时和合成测试数据明确区分。报价连通、数据完整、任务成功和允许交易分别表达，不能用统一的绿色在线指示代替。
- 长操作立即反馈提交状态，受理后附着任务引用。网络超时先核实原请求，不自动换请求身份再提交；刷新、打开面板和布局恢复不触发业务写入。
- 未配置、无结果、无权限、读取失败、陈旧结果和已确认空仓分别呈现。错误说明影响与可执行下一步，不把未知金额转成零。
- 所有主要操作可用键盘完成，焦点可见；弹窗关闭回到触发位置。后台刷新不夺焦点、清空草稿或跳动选中项。
- 任务中心统一管理任务详情与恢复，业务区只保留阶段、异常摘要和定位入口。

## 对象、命令与视图状态

目标以稳定的工作区、面板实例和对象 ID 导航；显示名不作为持久化主键。固定研究输入必须包含版本，“最新”在执行前解析为确定输入。命令由同一登记入口服务菜单、快捷键和搜索；权限及不可用原因一致。

| 状态 | 所有者 |
|---|---|
| 分屏、标签、排序、筛选、视口和联动组 | 工作台布局与插件面板状态 |
| 密度、涨跌颜色等偏好 | 用户偏好 |
| 已发布版本、研究运行、账户、委托和任务结果 | 对应后台业务插件；面板只保存引用 |
| 未提交参数 | 业务面板草稿，明确已保存/未保存 |

工作台、共享 UI 和薄 Rust UI 桥同属 L4，业务界面各为独立面板包，在构建期组合，不是运行时插件，也不与领域或应用打包在一起。布局、状态 schema 与边界以[模块与层级](architecture.md#层级与模块)和[当前代码归属](engineering-structure.md#当前代码归属)为准。布局不得携带凭据或大规模行情；不支持的记录保留原内容并报错，缺失面板保留占位。移动面板须在目标确认后释放来源，失败不丢视图；冲突不能静默覆盖其他窗口修改。关闭视图释放其消费者资源，UI 展示节流不能改变策略输入。

## 开箱与配置

正式入门只有连接真实来源与导入本地文件；合成数据用于开发和测试，不设置正式演示工作区。已有历史测试产物保留明确标记。当前首次设置会准备隔离 Python 环境，系统数据库与平台前置条件见 [桌面运行](desktop-runtime.md)，不能承诺所有平台无需系统准备。

本地账号与未来可选云身份分开；本地注册不代表验证邮箱所有权。当前注册要求 PIN，本地账号共享工作环境，不是多租户数据隔离。

设置保留独立窗口，业务配置由所属插件提供。常用字段优先，高级参数按需显示；测试说明实际检查范围，成功不代表所有接口或未来网络可用。配置修改保留草稿、修订冲突和凭据保留/替换/清除意图，运行任务绑定确定修订。查看设置不得意外启动已停止的后台。

未来配置/模板导入导出必须校验当前契约、预览差异并脱敏；不能携带实盘授权、自动连接陌生账户或改变历史结果。尚未实现时不显示已完成入口。

## 验收任务

| 流程 | 完成依据 |
|---|---|
| 首次使用 | 明确开始设置、真实进度、失败重试、进入工作台；无数据仍显示真实空态和可用来源/导入入口 |
| 获取与核对数据 | 选择来源及固定依据、提交、查看任务、打开版本、检查覆盖；未知日期不能显示为齐全 |
| 更新主力角色 | 核对品种、实际合约、来源与生效日；一次业务提交衔接采集/计算，失败保留最后已发布结果 |
| 研究 | 确认固定数据和规则、保留参数草稿、提交、查看结果与证据；不以界面完成代替领域验收 |
| 连接与账户 | 保存/切换/断开命名连接、自选和状态同步；账户身份、陈旧与未知值明确，真实联调范围单独记录 |
| 工作台恢复 | 对象与视图恢复，无重复任务；不支持状态和保存失败明确可见，缺失显示器时窗口仍可达 |
| 插件管理 | 在设置中检查来源与能力、安装、启停、查看声明式视图；失败不破坏固定结果 |
| 故障恢复 | 断线标时效，重连读取权威状态；提交或订单状态未知时查询/对账，不创建新的业务意图 |

验收覆盖无数据、未配置、权限错误、部分失败、响应丢失和成功路径。模拟接口、真实供应商、浏览器、原生安装包分别记录证据，不能互相替代。性能目标与测量口径统一见 [架构设计](architecture.md)，不得用入口数量或单元测试数量代表产品完成度。

## 服务详情

底栏「● 服务」展开诊断，打开期间每 5 秒读取，也可手动检测。请求失败清除旧结果并显示无法确认；API 可达、数据库查询、任务进程观测与各插件状态分别呈现。进程存在不证明任务成功，保存凭据不证明外部接口可用。该入口继续遵守账户与 PIN 访问限制。

新增或修改 UI/操作前的 Fincept 实机要求以 [AGENTS.md](../AGENTS.md) 为准；观察、采用方式和未验证范围写入 [交互记录](fincept-interaction-review.md)。
