# Terminal 设置窗口

设置属于 Terminal 宿主，入口为左下角齿轮、服务状态面板的连接设置和 Cmd/Ctrl+,。参考 rust 分支的窗口交互，使用当前 C++ 应用契约。

桌面设置是与主窗口关联的非模态窗口，不阻塞工作台。默认内容尺寸 760×540，最小 640×440；首次在主窗口所在屏幕相对主窗口居中，再按屏幕可用区域调整位置。先定位再显示，避免窗口闪跳。重复打开保留用户位置；屏幕变化导致窗口越界时，重新放回主窗口所在屏幕的可用区域。小屏幕允许降低最小尺寸，内容内部滚动。

齿轮和 Cmd/Ctrl+, 只恢复并聚焦唯一设置窗口，不重置分类；连接设置等明确入口才切换到对应分类。原生关闭按钮和 Cmd/Ctrl+W 隐藏设置窗口，保留当前分类、输入与位置，并将焦点交还主窗口。同一次应用运行内复用这些状态；再次启动应用保留选中分类，窗口重新定位。主窗口销毁时一并销毁设置窗口，退出不停止 Agent 和业务服务。工作台始终不卸载，当前页和未提交输入保留。

设置分类为偏好设置、连接与部署、插件和关于。偏好设置集中语言、密度与涨跌配色，保存后同步到工作台；当前没有独立主题选择器，不添加无效控件。连接与部署区分本机和远程 Linux，技术说明折叠，部署操作保持显式。关于中的版本来自桌面打包配置。侧栏不重复显示窗口标题和关闭按钮。

两窗口共享同一 C++ Runtime。设置分类的显式导航和偏好变化通过同源存储事件同步；窗口创建、定位和生命周期由 Electron 主进程负责，不引入业务进程。浏览器开发使用同源 popup，关闭后重新创建并保留分类；它不能替代原生窗口的隐藏、归属、焦点和多屏验收。

工作台导航栏使用 Cmd+B（macOS）/ Ctrl+B（Windows、Linux）切换展开与收起，不提供常驻收起按钮。左上角标识的悬停提示显示快捷键；图标导航及底部设置、任务入口保持可用。
