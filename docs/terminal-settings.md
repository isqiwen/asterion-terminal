# Terminal 设置窗口

设置属于 Terminal 宿主，入口为左下角齿轮、服务状态面板的连接设置和 Cmd/Ctrl+,。参考 rust 分支的窗口交互，使用当前 C++ 应用契约。

桌面由 Tauri 创建独立 `settings` 窗口（820×620，最小 700×500），重复打开恢复并聚焦已有窗口。工作台不卸载，当前页和未提交输入保留。浏览器开发环境使用同源独立窗口。关闭设置只关闭该窗口，不停止 Agent 或业务服务。

设置分类为通用、外观、连接与部署、插件和关于。语言归通用，密度与涨跌配色归外观；偏好保存后同步到工作台。连接与部署区分本机和远程 Linux，技术说明折叠，部署操作保持显式。关于中的版本来自桌面打包配置；当前通过安装包更新，不提供未实现的在线更新按钮。

两窗口共享同一 C++ Runtime，Tauri 请求使用既有互斥访问。设置分类切换与偏好变化通过同源存储事件同步；窗口创建与管理仅由 Tauri 薄桥负责，不引入新的业务进程。
