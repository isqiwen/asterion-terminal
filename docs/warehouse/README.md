# Warehouse 数据服务

`asterion_warehouse` 是运行在 Linux 主机上的单一 C++ 服务，负责历史数据采集与版本化管理，向多个 Terminal 与 Lab 提供统一研究数据集。它不连接柜台、不持有柜台凭据。开发者导读见[开发者导读](architecture.md)，安装与配置见[部署](deployment.md)。

## 仓库与固定版本

Warehouse（`apps/services/warehouse/`）统一管理九张表：日线、分钟线、交易日历、合约表、结算参数、历史报价单位、仓单、会员持仓与库存周报。历史报价单位保留 8 位小数，其余保留 6 位，写入时拒绝需要舍入的数值。内部按来源分仓保存（Tushare 在 `warehouse/`，其余来源与合成结果在 `sources/<来源>/warehouse/`），客户端只按固定版本读取合成后的统一数据集（`research`），不感知底层来源。

| 表 | 来源顺序（前者优先，后者只补缺，唯一维护于 `composition.cpp` 的 `sources_of()`） |
| --- | --- |
| 日线 | Tushare → 上期所、能源中心、郑商所、大商所、中金所、广期所 → 新浪财经 |
| 分钟线 | Tushare → 新浪财经 |
| 合约表、交易日历 | Tushare |
| 结算参数 | 上期所、能源中心、郑商所、广期所 → Tushare |
| 历史报价单位 | 内置核验表（`verified`） → 郑商所 → 国泰君安期货 |
| 仓单 | 上期所、能源中心公开原件 → Tushare |
| 库存周报 | 上期所 → Tushare |
| 会员持仓 | 上期所、能源中心、广期所官网 → Tushare（其余交易所） |

> 理由：行情优先采用结构统一的 Tushare、公开源补缺；结算参数与部分基本面以交易所原件为准；最小变动价位极少变更，使用经核验的内置生效区间表并每日增量核验。

| 机制 / 运维 | 规则与入口 |
| --- | --- |
| 不可变版本与零拷贝合成 | 启动时固定各来源版本，仅在采集任务结束时将已落盘批次通过硬链接零拷贝合入统一数据集并原子切换 `current`（无变化不发新版本）；版本清单按“表 / 交易所 / 月份”拆分为内容寻址分片（`shards/<sha256>.json`），读取校验摘要。`tests/warehouse/fixtures/record-format/` 固定格式样本防回退 |
| 固定版本只读契约 | 首次请求可留空版本号获取当前版本，后续分页与下载须携带同一版本号；指定版本不存在直接失败，不回退最新版（见[通信协议](../protocol.md#8-warehouse)） |
| 合约级覆盖与缺口 | 开市日范围取 `[上市日, min(下市日, 昨日)]`；首尾已有数据间缺少开市日记缺口，末日之后记待更新，首日之前不计缺口，“来源无数据”单独计数；库存周报仅展日期范围不计日频缺口 |
| 数据质量自检 | `build/electron-resources/python/bin/python3 -I -B -m asterion_lab.audit --warehouse-dir <数据目录>`（或 `--lab-dir`），自动交叉校验缺日、分日成交量差、OHLC 合法性与异常跳变，异常返回非零并支持 JSON 报告 |
| 离线垃圾回收（GC） | 停服后执行 `sudo -u <服务账户> /opt/asterion/warehouse/bin/asterion_warehouse gc [--data-dir <目录>] [--keep-last 5] [--keep-source-last 1] [--keep-version <sha256>] [--keep-file <清单>] [--apply]`（默认干跑）。持独占锁校验清单与分区完整性后按“清单 → 分片 → Parquet”回收无引用旧数据；开发期可配 `--keep-last 1 --keep-source-last 1 --apply` |

### 中金所早期日历

Tushare 的 CFFEX 2010～2014 年日历仅返回开市日，上市后未返回日期与中金所官方休市完全一致，不应据此补采；[2010-04-16 正式交易前](http://www.cffex.com.cn/cn/jystz/20100331/10718.html)记录按上市日截断。休市依据：[2010 劳动节](http://www.cffex.com.cn/cn/jystz/20100427/10715.html)、[端午](http://www.cffex.com.cn/cn/jystz/20100602/10733.html)、[中秋国庆](http://www.cffex.com.cn/cn/jystz/20100917/13115.html)，及 [2011](http://www.cffex.com.cn/cn/jystz/20101229/14637.html)、[2012](http://www.cffex.com.cn/cn/jystz/20111229/16211.html)、[2013](http://www.cffex.com.cn/cn/jystz/20121228/16922.html)、[2014](http://www.cffex.com.cn/cn/jystz/20131226/17482.html) 公告。

### 历史最小变动价位

`price_ticks` 记录交易所、品种、交割合约（为空表示品种通用）、最小变动价位、来源网址与生效区间 `[effective_from, effective_until)`；回测区间内缺失或同日冲突即禁止回测，因子评价不依赖该表。

| 来源机制 | 行为 |
| --- | --- |
| 内置核验表（`verified`） | 启动时读取 `config/exchange_rules.json` 中经公告核验的六所生效区间幂等写入统一数据集，离线亦可覆盖完整历史 |
| 每日增量核验 | 开启每日更新后核对各所最近一个开市日：郑商所读官方参考 XML 的 `TckSz`，其余五所读国泰君安期货[历史交易日历](https://www.gtjaqh.com/pc/calendar)（排除期权行）；一致不重落盘，发现新品种或变更时任务报错提示更新规则文件 |

### 仓单、会员持仓与库存周报

| 表 | 来源与范围 | Tushare 权限 |
| --- | --- | --- |
| `warehouse_receipts` | 上期所、能源中心优先读官网仓单日报，缺原件及其他商品所用 [`fut_wsr`](https://tushare.pro/document/2?doc_id=140) | 2000 积分 |
| `member_positions` | 上期所、能源中心、广期所读官网合约排名，其余所用 [`fut_holding`](https://tushare.pro/document/2?doc_id=139) | 2000 积分 |
| `inventory` | 上期所优先读官网库存周报，缺原件及能源中心用 [`fut_inv_weekly`](https://tushare.pro/document/2?doc_id=495) | 5000 积分 |

```mermaid
flowchart LR
  Day["报告对应日 day"] --> Pub["来源发布时间 published_ms（官网原报 UTC；无则留空）"]
  Pub --> Obs["入库接收时间 observed_ms（UTC 毫秒）"]
  Obs --> Ver["写入不可变版本（修订重采生成新版本，旧观测永久保留）"]
```

> 理由：历史研究必须区分报告日期、信息可知时点与事后修订，补采绝不用报告日冒充发布时间；Lab 消费时的 PIT 闸门见[Lab 主力连续](../lab/README.md#主力连续)。

| 口径与特例 | 规则说明 |
| --- | --- |
| 请求粒度与权限 | 按交易所与报告日分区；Tushare 仓单/库存按存续品种逐个查，会员持仓按存续品种与四位年月合约分别查（防分页漏重）；触及返回上限拒收，权限不足报错 |
| 上期所 / 能源中心仓单 | 优先读官网 JSON；上期所文件缺失时读同日 HTML，按表头区分厂库与地区；排除合计，由增减推算上日量。仓单与库存均以 `warehouse_type` 区分同名仓库和厂库 |
| 上期所库存周报 | 优先读官网 JSON，缺失时按报告日读[早期归档表](https://www.shfe.com.cn/data/tradedata/future/weeklydata/20140103weeklystock.html)或[现行分品种表](https://www.shfe.com.cn/data/tradedata/future/stockdata/weeklystock_20261120/ZH/all.html)。只刊期货量的表保留库存小计空值；燃料油按品级存明细，排除小计；黄金仅存一行汇总，库存等于仓单量，库容留空 |
| 广期所与代码归属 | 广期所先从[官网](http://www.gfex.com.cn/gfex/rcjccpm/hqsj_tjsj.shtml)取当日公布合约再读三榜（Tushare 漏早期碳酸锂）；Tushare 归在 `SHFE` 的能源中心仓单/库存改归 `INE`，`CU` 中“铜(BC)”归 `INE/bc`、其余归 `SHFE/cu`；郑商所 `PTA` 归 `ta` |
| 会员合并与防重复 | `contract` 仅来源明确给交割月时填写；三所官网按合约与会员合并成交/多/空三榜，未上榜留空（不填零）、不入库榜单合计；排除混入品种、早年合约类型汇总与 `*actv` 活跃月合计；正常空榜记“来源无数据”不伪造零。套保压力研究另需商业套保分类数据 |
| 单位与前端翻页 | Tushare 仓单/库存保留 `unit` 及明细/小计/合计标签（聚合前须筛同层级与单位，编号存文本保前导零）；Terminal 浏览按日分片从最新日期向回翻页，仅读当前页报告日 |

## 历史采集

`apps/services/warehouse/acquisition/` 用 C++ 直连数据源，采集截止至前一个交易日（避免未收盘当日存为完整分区）；来源启用、频控与凭据仅在服务主机配置。

```mermaid
flowchart LR
  Task["采集任务"] --> Prereq["补齐前置（日历 / 合约 / 结算）"]
  Prereq --> Fetch["按来源顺序逐源补缺"]
  Fetch --> Src["落盘来源仓库（Parquet）"]
  Src --> Compose["任务结束零拷贝合成"]
  Compose --> Publish["原子切换 current 版本"]
```

```mermaid
flowchart LR
  Auto["每日自动更新 / 更新到最新"] --> Cat["1. 后台刷新合约表"]
  Cat --> Bars["2. 优先调度：日线 → 分钟线（含主力序列自动纳入）"]
  Bars --> Fund["3. 低优跟进：仓单 / 会员持仓 / 库存周报（遇行情任务完成当前分区后让行）"]
```

### 来源与限速

| 来源 | 提供内容 | 限速 | 关键边界 |
| --- | --- | --- | --- |
| `tushare` | 合约、日历、日线、涨跌停（`ft_limit`）、1 分钟线、结算参数、仓单/持仓/库存 | 1–500 次/分（共享） | 夜盘归下一开市日；`ft_limit` 按 7 日缓存（触 4000 行缩单日，无权留空）；不自动重试，触上限拒收防截断 |
| `shfe` / `ine` / `czce` / `gfex` | 各自日线与结算参数；`shfe`/`ine` 另供仓单；三所另供会员持仓；`shfe` 供库存周报；`czce` 供报价单位 | `gfex` 共享 2 秒间隔，其余 45 次/分 | `gfex` 走 HTTP 且突发连发会被拒；早年郑商所为 GB18030 年度 ZIP |
| `dce` / `cffex` | 各自日线 | 各 45 次/分 | HTTP 公开接口，高频易被门户拦截或断连 |
| `gtja` | 除郑商所外五所历史报价单位 | 45 次/分 | 连续约 60 次请求会被断连 |
| `sina` | 日线与 1 分钟线（末级补缺，不含中金所） | 60 次/分 | 依赖 Tushare 合约表；无成交零值入库为缺；分钟线仅回溯约 2 日，首日标 `partial` 不重取 |

> 日线中为零的开高低记为缺失，三者全缺时收盘留空，结算价与成交量照录；交易所保证金与手续费均不含期货公司加收。

### 结算参数口径与历史边界

| 交易所 | 来源与口径 | 历史边界与特殊规则 |
| --- | --- | --- |
| 郑商所 | 官网优先，Tushare 补缺（比例万分比，每手元） | 2016 起可读；2022-11-07 前按每手读（首个比例收费 2023-07-20）；2017-06-22 前平今仅给减半标志；三位代码按日补十年位 |
| 上期所 / 能源中心 | 官网优先，Tushare 补缺（比例千分比，每手元） | 上期所 2015-05-25 前的结算原报按官网文件路径定日；2024-07-22 前官网原件无平今费，入库为缺 |
| 广期所 | 统一取官网接口 | 不使用 Tushare 结算参数 |
| 中金所 | Tushare（保证金率为百分数，如 `0.5` → `0.005`） | 比例与每手填同值：国债按元/手、股指按万分比；平今按普通手续费百分比换算（[原表](http://www.cffex.com.cn/sj/jscs/202611/23/20261123_1.csv)中股指 `1000%` 即 10 倍） |
| 大商所 | Tushare（保证金小数；按 `exchange_rules.json` 的 `dce_settlement_fees` 判计费单位） | 元/手与万分比混填于 `trading_fee`（不含独立日内开仓费），未登记或越界整日拒收；23 品种已核对至 2026-11-17（15 按手、8 按金额，依据[华金表](https://www.huajinqh.com/UserFiles/upload/file/20260709/手续费标准表20260710.pdf)、[大商所通知](https://www.ghlsqh.com.cn/company/news/show-28785.html)、[申万公示](https://www.sywgqh.com.cn/Pc/Aboutus/Public_Info/history_fee/132274.html)） |

> 其余交易所 Tushare 保证金率均为小数；换算后 `≥ 1` 拒收。

### 任务范围与调度规则

| 任务类型 | 指定范围 | 自动前置依赖 | 说明 |
| --- | --- | --- | --- |
| 日历、合约表 | 交易所 + 区间 | 无 | 仅采该表 |
| 结算参数、历史报价单位 | 交易所 + 区间，或品种/合约 | 无 | 按品种/合约请求仍整日采所在所全合约 |
| 日线 | 交易所 + 区间，或品种/合约 | 日历 → 合约 → 结算参数 | 整日存储以便对照日历判齐 |
| 分钟线 | 仅品种或合约 | 日历 → 合约 → 结算 → 日线 | 缺日期时先刷合约表取存续期 |
| 仓单、会员持仓、库存周报 | 交易所 + 区间，或品种/合约 | 日历 → 合约 | 按交易所整日采集 |

- **队列与故障保留**：任务串行、队列上限 16；日线/分钟线高优，其余任务完成当前分区后让行。单源断连/鉴权失败/限流后本任务不再重试该源并转后续来源补缺；空响应与 404 记缺口，412/拒收/解析错误使任务失败；取消或失败时已落盘批次照常合入数据集。客户端断线不取消任务，服务重启未完成项标中断。
- **来源无数据**：单表正常结束且某分区全来源返回空并已过 2 个开市日，写入 `acquisition/empty-<表>.txt` 后续跳过（重采有数后移除）；库存周报非发报日空响应不计日频无数据。
- **自动更新与后台维护**：每日定时或手动“更新到最新”自动刷新合约表（后台静默运行，仅失败告警），按已入库交易所补齐日线、未摘牌分钟线（自动重建只向后换月主力序列并纳入新主力）及结算参数，随后跟进补齐已有行情日期范围内的三张基本面表。

## 连接与协议接入

- **双向指纹 mTLS**：Terminal 与 Lab 共用本机客户端证书指纹（在 Terminal“设置 → 关于”复制并登记到 Warehouse 主机，服务端指纹存入 `terminal/data/warehouse.json`）；已登记客户端均可读数与管理采集，采集只追加新版本。Lab 读数约定见[固定数据版本](../lab/README.md#固定数据版本)。
- **核心 RPC**（详见[通信协议](../protocol.md)）：采集调用 `start_acquisition`（调用方生成唯一任务 ID，回复丢失先用 `get_acquisition_task` 查状态，重复同 ID 返回 `CONFLICT`）；读数先调 `get_dataset_version` 取得固定版本号，分页与下载均携带该版本并校验分区整文件 SHA-256。
