# 行情与数据

## CTP 实时行情

`asterion-market-data` 通过 `plugins/data/ctp` 连接 CTP 行情前置，只读。

- **连接**：行情前置、经纪商、用户、密码。密码不保存，每次连接时输入。
- **合约目录**：配置目录查询前置（CTP 交易前置）、AppID 与授权码后，自动加载全市场合约并全部订阅；只查询合约，不开通交易。
- **自选**：最多 50 个实际月份合约，独立于全市场订阅。
- **报价字段**：最新价、买卖一及 2–5 档、开高低、昨结算、昨收、涨跌停、持仓量及日增仓、成交量、交易日、单位均价。缺失值保持缺失，不补零。
- **事件流**：服务保留有界的有序报价事件（断档、断线和乱序都会标记），供分钟线和最近报价曲线使用。

### 均价

CTP 的 `AveragePrice` 在郑商所是单位均价，其他交易所是成交额／成交量（含合约乘数）。服务用合约目录中的乘数归一；乘数未知或当日无成交时不报告均价。

### 当日分钟线与 1 分钟涨速

服务从有序事件流构建每个合约当日的 1 分钟线（`core/domain/intraday_bars`）：

- 开高低收取最新价；分钟成交量是累计成交量的差值，交易日第一条观测只作为基准。
- 事件断档、断线或累计量回退时标记“曾中断”；换交易日重新开始。
- `first_observation_ms` 标明服务开始观测的时间，更早的分钟未知，不补齐。
- 1 分钟涨速 = 最新价相对同一交易日内至少 60 秒前最近一次观测的百分比；不足 60 秒或中断后为空。

分钟线只保存在服务内存中，服务重启后从头观测。终端通过只读命令 `market.minutes` 查询。

### 分时横轴

分时图按 `config/futures-sessions.json` 的交易时段排布横轴，左轴价格、右轴相对昨结算百分比。未列入该配置的品种只按已观测分钟排列。

## Tushare 历史数据

在“数据”工作区选择品种和具体月份合约，下载该合约完整上市期间的数据：

- **分钟线**：1、5、15、30、60 分钟，分段下载，可中断恢复。
- **日线**：包含结算价；图表可聚合为周、月、季、年。

下载由研究任务服务执行（`data-pipeline` 工作程序）。Token 单独保存在任务目录中受当前账户保护的文件，不出现在任务列表和结果中。图表查询按页读取，每页附带均线和 MACD（从数据集第一根 K 线开始计算，前 33 根为预热）。

## 成交数据集

模拟交易、回测和因子使用不可变的“已发布成交数据集”：单个实际月份合约，最多 10000 笔，内容身份是规范化合约与成交序列的 SHA-256。在“数据 → 数据存档”中查看和选用。当前没有能产生新成交数据集的数据源，只能使用已有发布版本（见 [现状](status.md)）。

## 结算表

回测需要结算表：每个交易日的时段和结算价。在“数据 → 结算表”导入 CSV 并发布，回测按版本引用。

```csv
trading_day,session_begin,session_end,settlement_price,schedule_source,settlement_source
2026-09-25,2026-09-24T21:00:00+08:00,2026-09-24T23:00:00+08:00,105,"模板 SHFE/rb","交易所公告"
2026-09-25,2026-09-25T09:00:00+08:00,2026-09-25T15:00:00+08:00,105,"模板 SHFE/rb","交易所公告"
```

- 每行一个时段；同一交易日的行连续，结算价和来源一致。最多 64 个交易日、每日 16 个时段、1024 行、1 MiB。
- 交易日 `YYYY-MM-DD` 严格递增；时间必须带时区，转成 UTC 后不得重叠或倒序。系统不推断节假日和夜盘归属。
- 结算价为规范十进制；回测只接受正数且对齐价格步长的结算价。

可按交易时段模板生成：

```sh
asterion-data-pipeline calendar-generate --sessions config/futures-sessions.json \
  --venue SHFE --product rb --settlements settlements.csv \
  --previous-trading-day 2026-09-25 --output calendar.csv
```

`settlements.csv` 表头为 `trading_day,settlement_price,settlement_source`，由使用者依据交易所公告提供。交易日 D 的夜盘在上一交易日晚上，且仅当两者之间只隔周末；长假前最后一个交易日晚上没有夜盘。临时停夜盘等例外需要手工修改结果。
