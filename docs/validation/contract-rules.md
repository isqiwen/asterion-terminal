# 合约规则插件验证记录

日期：2026-09-20。当前源码及本轮生成的 macOS 应用包；测试数据均为离线构造，不代表交易所参数。

## 完成范围

- 独立规则插件拥有存储、规则校验、登记 API、公开读取能力、备份检查与前端规则编辑/证据组件。
- 研究必须显式依赖规则插件；新运行验证已登记版本、合约与覆盖日期，冻结完整规则快照。
- 连续生效期间、按手/按成交金额收费、开平仓分别计费、分期保证金比例；结果披露规则版本与实际费率。
- 草稿与模板、原输入重跑、结果 ZIP、复现包及备份恢复使用当前契约。没有增加旧参数入口或迁移逻辑。
- 使用现有核心存储、能力、授权、任务与备份机制，核心机制文件无本轮功能修改。
