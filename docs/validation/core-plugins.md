# 核心与插件机制验收

日期：2026-09-20。范围是当前内置插件与用户明确认可的本地 Python 插件，不是全部未来量化业务功能或恶意代码安全执行。

## 已验收机制

| 边界 | 实现与证据 |
|---|---|
| 所属表存储 | 启动仅授予 `Storage`；拒绝未授权表、直接任务状态写入、原始 SQL 和只读事务写入；任务读取按领域过滤，包含别名和子查询测试 |
| 结构预检 | 当前字段、类型、可空性、主键、唯一约束及外键检查；全部预检后按外键依赖顺序建表；损坏结构不会自动迁移 |
| 原子发布 | 任务完成/进度由核心端口校验类型、数据库归属及租约；任务完成与业务写入一起提交或回滚 |
| 恢复 | 全量当前格式校验、任务取消与必需领域清理共用事务；遗漏、异常、吞掉异常及重复/过期操作有测试 |
| 服务端授权 | 工作台功能凭证绑定账户会话、路径/方法和有效期；不能升级自身权限；worker 使用独立身份，禁止访问账户、来源配置或插件安装 |
| 包与依赖 | 当前 manifest 严格校验、SHA-256、原子回执、文件锁、同版本内容不可替换、精确依赖/循环检查、依赖缺失阻止启用、被依赖插件禁止直接停用 |
| 外部进程 | 请求身份/协议、输出/时间限制、错误脱敏、环境不传递运行凭据、停用终止正在执行的进程；源码和工件执行前复核 |
| 数据源 | 安装、配置发现、固定任务工件、独立采集、标准校验与发布；内置和外部来源共享计划准入，供应商参数不再承担通用日期分段契约 |
| 声明式界面 | 安装与显式信任确认、来源设置、自动表格视图、文本转义、停用缺失状态及保留工件移除 |
| SDK | 标准库公开入口和确定性打包工具；可复制到独立仓库的 HTTPS 日历/表格样例；不需要修改核心登记代码 |

## 验证结果

- 全量 Python 测试：**374 通过**，设置独立 `ASTERION_TEST_DATABASE_URL`，真实 PostgreSQL 测试未跳过。使用临时数据库和独立服务实例。
- 前端单元测试：**23 通过**。
- 浏览器：**38 个独立场景通过**，其中 36 个 mock 场景和 2 个真实 API/worker 场景。数据源凭据移除测试改为等待保存完成后断言；没有通过提前读取异步状态判断成功。
- Pyright、Ruff、TypeScript 类型检查及 `git diff --check` 通过；OpenAPI 和前端类型重新生成。
- macOS 冻结包：从不含 uv/pnpm/cargo/开发 venv 的 PATH 启动 PostgreSQL、API、worker；安装独立插件，使用打包 SDK 运行表格；正式 worker 采集开发用外部日历插件并发布固定包摘要；停用、作用域拒绝、离线备份与隔离恢复通过。
- `release/Asterion_Terminal.app` 重建；`codesign --verify --deep --strict` 通过。源码层面的原生实现本轮未改动，Rust 此前 8 项验证仍作为历史证据标记，不冒充本轮重新执行。

本地验证日志：`.state/core-postgres-tests.log`、`.state/core-browser-tests.log`、`.state/core-data-ui-recheck.log`、`.state/core-real-pipeline.log`、`.state/core-architecture-build.log`、`.state/core-frozen-extension-smoke.log`。日志仅作当前工作区证据，不要求开源仓库提交测试运行目录。

## 当前支持边界

本地插件依然是同 OS 用户的受信代码；它可以绕开公开接口访问该用户可访问的文件或网络。当前交付的是包完整性、服务接口授权、故障隔离和显式信任流程，不能声称有恶意代码沙箱。没有在线插件市场、任意原生依赖安装或公共 SDK 包索引发布。

研究方法、实时行情/交易连接器、命名布局、配置导入导出及跨平台强制隔离是后续业务或平台扩展。现有核心提供接入机制，但没有用数据采集协议替代它们各自的业务正确性验收。许可证和公共发布准入仍按维护者决定处理。

未修改或清理用户业务数据，未重启用户已运行的工作台，未连接真实交易账户。
