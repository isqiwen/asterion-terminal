# 固定版本日线批次读取验收（2026-09-22）

研究提交与复现包的本地版本解析通过数据插件 `VersionAccess.scan` 读取 STANDARD 日线。请求固定版本、规范实际合约、交易日区间和列；批次包含来源证据。未修改核心调度或 UI，未生成安装包。

## 实际验证

`tests/test_data_scan.py` 使用隔离 SQLite 和真实 Parquet：

- 跨月版本只打开目标月份的数据工件；只返回请求列与规范身份、来源列，提前关闭生成器释放文件句柄。
- 新版本修订同一交易日后，扫描旧版本仍返回原值。
- 未声明列、版本外合约、被破坏的目标工件明确失败。
- 合成的 7,000 行版本请求 5 天，只返回 5 行，70 个 Parquet 行组中只解码 1 个；请求超过执行上限则失败，不截断。该合约身份是明确声明的长生命周期测试数据，不代表真实交易所合约。

相关研究、复现、覆盖、结算、规则、角色、备份及插件边界回归一并执行，结果见 [验证总表](../VALIDATION.md)。现有回归覆盖本地版本缺失、来源约束和离线复现。

## 边界

每个消费工件仍需流式读取全部压缩字节以核验校验和；行组裁剪减少解码，不保证省去这些完整性读取。合约筛选在有界批次内解析规范身份后完成。研究仍冻结最多 5,000 行到任务载荷，单合约执行引擎未改成无限流式执行。当前日线导入保持单合约契约。

本轮未验证真实供应商历史、多合约研究、分钟数据、百万行扫描峰值内存或桌面原生体验；不能把先前百万行增量合并基准当作扫描基准。
