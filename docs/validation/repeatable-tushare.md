# 可重复的 Tushare 真实验收

`scripts/verify_tushare.py` 是主动运行的开发验收工具，不属于发行版默认业务或策略。它读取用户明确选择的已保存命名连接，在独立输出目录运行当前数据、规则和研究插件，不创建用户账号，不关闭身份校验，不向活动环境提交数据或研究任务，也不重启桌面服务。

## 运行

先在应用设置中保存并启用 Tushare 连接。用连接 ID 指定唯一来源；命令行不接受 Token，配置从本机当前加密快照读取。

```bash
uv run python scripts/verify_tushare.py \
  --connection c_填写实际连接ID \
  --case examples/validation/tushare-rb2505.json \
  --output .state/tushare-check-本次唯一名称
```

默认宿主为 macOS 应用目录；其他位置使用 `--host` 显式指定。读取当前活动环境的配置时使用 PostgreSQL 只读事务，沿用数据插件的当前配置字段与加密校验。凭据对象构造和读取不创建目录或改权限；写入新的加密配置时才创建目录。

输出目录必须全新，且不能位于活动环境或宿主目录内，也不能包含它们。已有结果绝不覆盖。重复运行指定另一个输出目录；不提供历史验收格式迁移或隐式续跑。

## 明确输入

示例针对 SHFE 的 RB2505、2025-01-06—2025-01-17。文件包含合约、日期、提前的结算采集起点、乘数、价位、费用字段和单位、保证金单位、依据说明以及研究周期。结算到结束日期的范围限制为 31 天，避免验收变成大量采集。

例中的千分数、保证金比例及上一已返回交易日参数使用规则是明确研究假设，不是按数据大小猜测的换算，也不证明历史公布时刻、经纪商加收或真实可成交性。不同合约需自行核实并修改 case；不能直接套用示例参数。固定初始资金、单手与单跳滑点仅用于技术验收。

## 产物和判断

输出目录包含：

- `report.json`：连接修订、每个阶段状态、版本 ID/摘要、覆盖状态、规则指纹、研究运行 ID、复现比较和结果摘要。
- RAW 采集证据及标准版本文件、隔离 SQLite 数据库。
- `research.asterion.json`：附带本次行情和规则证据的复现包。
- 隔离环境自身的加密配置和权限为 0600 的运行密钥。此目录应作为本机私有资料保存，不要提交到版本库或整体公开分享。

流程为连接读取、两阶段研究准备（日历/资料发布后自动提交固定身份日线）、结算同步、固定覆盖核对、规则确认、回测、重跑、导出和离线复现。覆盖必须为 `COVERED`，日线数须超过慢均线周期，每个期间必须有更早交易日的结算依据；缺失不补默认值。重跑比较完整输出字节，离线复现禁用来源与规则目录访问，并要求结果指纹一致。

成功退出码为 0；失败为 1。失败报告保留阶段和异常类型，以及之前已完成的版本与采集证据。异常正文可能包含网络或数据库敏感内容，因此不输出、不保存到报告；不得据此把失败归类为无数据或权限不足。该工具不替代完整桌面进程/GUI 验收。
