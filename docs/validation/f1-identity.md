## 唯一契约与所有权

数据功能插件拥有品种、实际合约、来源代码及不可变目录。`Contract.id` 固定交易所、品种、完整交割年月与上市日期，例如 `SHFE.RB.202505.20240516`；身份同时保存最后交易/交割日期及来源证据。外部代码只用于有来源、有适用期间的映射，不能从当前年份猜测生命周期。

交易时间由 `trading_time` 插件提供，合约规格与费用规则由 `contract_rules` 插件提供。目录没有另一份乘数、最小价位、时段或费用规则。研究通过公开契约消费这些对象；没有新增核心业务分支。

`RuleSpec.contract` 为完整 `Contract`，资料映射和结算预览请求使用 `contract_id`，规则资料依据使用 `ContractBasis.contract_id`，结算证据保存 `SettlementEvidence.contract`。规则、行情、时间品种及执行区间须一致；资料依据的上市与最后交易日也须与身份一致。研究当前唯一执行器为 `daily-session-settlement.v6`。

新建规则从已发布目录选择实际合约；资料映射生成的身份锁定。研究插件只有目录列表和内容读取授权，不能发布目录。规则身份的来源版本进入规则、运行、草稿与包的资料引用统计。

## 接入与拒绝门槛

| 链路 | 当前门槛及证据 |
|---|---|
| 目录发布/解析 | 固定标准资料、SHA-256、完整年月与上市生命周期；代码复用、来源歧义、缺失和信息截止时间验证 |
| 本地日线/日内导入 | 显式文件代码映射；预览、提交、Worker 与发布校验；日内先解析交易日，再解析实际身份 |
| 来源日线/结算 | 必需固定同源资料；提交、采集、发布与恢复校验完整目录和逐行身份；缺失依据不能重试或补齐 |
| 覆盖/研究准备 | 固定资料依赖、原子排队与固定配置重试；覆盖冻结目录，不回退查询最新合约 |
| 规则/结算 | 按规范 ID 而非行情代码比较；来源对象、生命周期与原值一致；不透明供应商代码可正常使用 |
| 研究执行 | 提交与 Worker 核对目录、逐根实际合约及规则 ID；单合约执行拒绝跨生命周期，探索模式不能跳过身份 |
| 导出/离线复现 | 包含完整固定身份、规则与来源证据；不重新访问供应商或选择最新规则 |
| 备份恢复 | 当前结构和指纹验证；非法身份拒绝且不改写证据；没有兼容入口、自动迁移或旧执行器 |

## 证据边界

真实来源仅验收上述 SHFE/RB2505 样本；跨源、代码复用、其他身份和故障边界由明确的离线构造用例验证，不代表全部交易所、品种或供应商均已完成真实验收。今天采集的历史资料没有历史公布时点证明；规则中的人工依据和结算期间假设不等于交易所认证，也不能用于宣称正式交易可用。

目录能力目前由数据插件拥有，未独立拆包；这不改变唯一所有权或公开契约。后续角色与交易插件须消费同一身份，不能重新创建代码式身份模型。活动账户、已有行情和历史研究记录未被迁移或清空。

下一阶段为 F2：区分供应商主力角色映射与自行计算结果，固定候选合约、输入版本、选择依据及可知时间，并用交易时间插件确定夜盘和节假日的生效边界。
