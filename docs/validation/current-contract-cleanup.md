# 当前契约校验与验收

日期：2026-09-20。遵循根目录 [AGENTS.md](../../AGENTS.md)，代码、测试和文档只描述当前有效契约。

## 当前边界

| 边界 | 契约与失败行为 |
|---|---|
| 服务状态 | 生命周期与验证状态必填；界面拒绝缺失必填状态的响应 |
| 数据源配置 | 使用修订配置、草稿校验、已保存配置验证和加密快照 |
| 同步任务 | 提交时固定配置；领取不改输入，采集与发布检查完整配置 |
| 导入 | 类型、频率、来源标识与映射统一进入提交、执行与发布 |
| 覆盖与重试 | 覆盖报告满足完整结构，前序重试关系使用明确的 `retry_of` |
| 研究 | 执行、发布、重跑与复现检查完整参数、输入指纹与固定覆盖依据 |
| 账号 | 注册时建立完整安全状态；读取时缺失则拒绝，密码验证重设遵循当前流程 |
| 工作区 | 原生模式以宿主持久化为唯一来源；无记录时创建默认布局，非法记录报错且禁止写回 |
| 模块引用 | 调用方直接引用职责所属模块的公开接口 |

测试从当前合法夹具构造缺字段、未知版本、非法值或损坏内容，不维护具体历史格式样例或废弃接口清单。校验失败不覆盖输入、不触发采集或重跑，是当前数据正确性要求。不可变研究结果、历史行情和任务记录属于业务数据。
