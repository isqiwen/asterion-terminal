# 终端界面

## 视觉语言

极简、科技感、未来感。信息优先，装饰让位于数据。

- **底色**：近黑的深空底（`--canvas`），面板只用 1px 发丝线和极轻的明度差分层，不用厚边框和阴影堆叠。
- **强调色**：单一冷色（青蓝）标示焦点、选中和可交互状态；涨跌红绿只用于行情数值。
- **字体**：界面用系统无衬线字体；数字统一等宽表格数字（`tabular-nums`），价格列右对齐。
- **密度**：行情表 24–26px 行高，紧凑但不拥挤；控件高度统一，圆角最小化。
- **动效**：只在状态变化时出现短促的淡入和高亮，不做装饰性动画。
- **空状态**：缺数据源或未连接时直接写明原因和下一步操作，不留空白，也不填假数据。

- **控件**：按钮、输入框、下拉框、复选框和表格只在 `src/ui/theme/style.css` 开头定义一次，
  悬停与焦点状态在同一文件定义一次。控件用 `--line-strong` 描边，输入和选择框用 `--field` 实底；主操作
  （`.primary`）是青色描边加极淡底色，不用实心色块。组件样式只设置自身的尺寸与布局，
  不重新定义控件外观。
- **下拉菜单**：统一使用 Electron 的 `appearance: base-select`，保留原生选择、键盘和无障碍语义。
  展开菜单在顶层使用不透明 `--raised` 底色、细边框和轻阴影；当前选项显示青色勾选，悬停与
  键盘焦点有独立反馈。默认向下展开，下方空间不足时向上避让；长列表限高滚动。
  组件只设尺寸与布局，不覆盖菜单颜色或展开方向。
- **分区**：一个面板内的各段共用同一左右留白，用发丝线分隔，不各自设置外边距。

样式令牌在 `apps/clients/terminal/src/ui/theme/tokens.css`（结构线 `--line`、控件描边
`--line-strong`、输入底色 `--field`），组件样式在各功能目录。

## 页面规则

- **标签即标题**：页面不重复标签名、服务名和“已连接”；服务不可用时才显示一行提示。
- **一个节奏**：页面内容统一左右留白和纵向间距；字段标签在控件上方，多个字段排成一行。
- **说明从简**：页面说明最多一句；限制说明、数据与程序身份（摘要、来源表）收进折叠项，比较用的参数直接可见。
- **一次一步**：多步流程只显示当前一步；主操作在表单末尾。
- **只列可用的**：未接入的数据源不放进导航，也不为它们留占位页。

## 结构

```
┌ 标题栏：搜索 · 应用名 ─────────────────────────────┐
│侧 │ 工作区                                        │
│栏 │                                               │
│   │                                               │
├───┴───────────────────────────────────────────────┤
│ 状态栏：服务 · 状态时间 · 交易连接                    │
└───────────────────────────────────────────────────┘
```

标题栏由界面自己绘制，不使用系统标题栏，整条可以拖动窗口：macOS 的窗口按钮嵌在它的左端；Linux 的窗口按钮画在它的右端（数量和顺序跟随桌面环境的设置，GNOME 默认只有关闭），颜色取主题的 `--canvas` 与 `--text`，系统的浅色或深色主题不影响它。Linux 上设置窗口同样如此。

侧栏业务模块（⌘1–⌘4 / Ctrl+1–Ctrl+4）依次为：行情、研究、交易、数据；侧栏底部是本机服务和设置（⌘, / Ctrl+,，独立窗口）。导航只有两级：模块，以及模块内一行视图标签——行情（市场、自选、合约）、研究、交易、数据（数据覆盖与采集）。只有一个视图的模块不显示标签行；没有内容的入口不出现。第一次启动先显示安装页：Python 解释器、核心、报表、AKShare 数据源各一行，显示大小、进度与状态，安装自动开始，失败给出原因并可重试，完成后进入工作台；以后启动直接进入工作台，行情服务和已保存的交易账户在后台连接，结果在各自的页面和状态栏显示。首次打开默认进入数据，之后恢复上次的模块与视图；同一窗口内保留各视图的位置和草稿。

**研究页**在 lab 上工作（见 [lab](lab.md)）：顶部是策略仓库（设置 → 研究 里选择，保存在 `terminal/data/research.json`）与当前提交号、是否有未提交改动；左侧列出仓库里的策略、因子函数和导入失败的模块，以及数据集版本；右侧是运行配置——品种、区间、参数（一格填多个值即为扫描）、资金、每个品种的费用、滑点、限额、统计设定、验证方式（不验证、留出、滚动验证）和并行进程数；中间是结果：核心指标（有留出或滚动验证时另列各段）、逐日权益、带买卖点的 K 线、月度收益、成交和收起的复现信息，扫描则显示按指标的排名和两个参数的热力图，因子显示各持有期的 IC 与衰减、累计 IC 和分组累计收益，单次运行可展开 QuantStats 指标；底部是运行记录，扫描合为一行，勾选两次运行可叠加比较净值和指标。

账户资金和风险在交易页查看，回测与扫描的进度在研究页的运行记录里，采集进度在数据页，服务异常在状态栏明确显示。

## 市场（期货全景）

布局参照同花顺期货通：

- 顶部一行分类：期货全景、主力合约和各交易所；没有接入来源的资产和指数分类不出现。右端是实时／历史切换和 `⋯` 行情设置（品种概览／全部月份、表头设置、行情连接）。未登录时分类下方是一条登录栏（行情账户、密码、授权码、保存到钥匙串、连接）；登录后，更换来源、清除凭据和重新加载目录收进 `⋯` 菜单的“行情连接”。“按代码添加自选”是单独的折叠项，供没有合约目录时使用。
- 左侧为分组行情表：上海商品期货（上期所＋能源中心）、郑州、大连；右侧为金融期货、广州商品期货。分组只在有合约时显示；未接入的境外行情不展示占位分组。
- 列：名称、现价、涨跌幅(结)、涨跌、1分钟涨速、持仓（成交量可在表头设置中开启）。品种概览每个品种一行，名为“品种＋主连”，实际是该品种持仓量最大的月份合约，不是拼接的连续合约；没有合约目录时列出已订阅月份。
- 右侧是上下两个图表窗格，周期为 分时／Tick／1分／5分／10分／日K／更多（周K、月K、季K、年K、历史K线）。上窗格默认分时，下窗格默认日K。历史周期读 lab 已入库的日线与分钟线（见下文“原生命令边界”后的历史行情说明）；没有入库时这些周期不可选，图上给出去「数据」采集的入口。

## 自选与合约

- **加入自选**：加入或移出自选的按钮在合约标题旁，市场、自选、合约三页都是同一个按钮，不经过菜单。
- **自选**：自选与最近浏览列表，右侧两个图表窗格。
- **合约**：左侧自选列表，中间是图表和同品种其他月份的一条“相关合约”，右侧报价、五档、成交明细和下单区（仅引导到 CTP 交易页）。没有数据来源的页签（资讯、外盘、社区、T 形报价、F10）不占位。
- **自选表的列**：只保留期货合约可能有的字段。尚无来源的字段（主力净额、量比、成交额、内外盘等）保留并置灰、不可排序；总市值、净利润、市盈率这类股票字段不出现。

## 交易

- **交易**：左侧是全部可交易的 CTP 账户及各自状态，右侧是所选账户的面板；多个账户可以同时打开。首次使用某个账户时开通交易：账户的柜台信息始终显示在上方，分两步填写——合约与风控 → 确认创建。缺合约目录时可在当前步骤读取柜台规格，不需要先去行情页。创建不登录、不授权。此后账户面板一次只给出当前这一步：核对环境并连接柜台 → 显式允许发送委托 → 下单；未到的步骤不显示为禁用的表单。授权长期有效（撤销、修改风控政策或交易服务重启后失效），所以已授权的账户重新连接后直接回到下单这一步。账户已连接但本窗口尚未核对环境时，先单独核对环境。仿真/真实资金是用户确认的标记，不能由前置地址自动推断，也不代表柜台验证的资金性质。标记仅保留在当前窗口的账户草稿中，重开窗口须重新核对。密码与授权码不持久化。
- **日常交易**：压缩资金摘要，保留下单区。下单区是合约、开平、手数、限价，加“买入”“卖出”两个带账户名称的按钮；在输入框里按回车不会发送委托。合约已订阅行情时可一键填入最新价、买一或卖一。委托发出后自动切到委托列表。持仓、委托、成交、费率、风控用同一排标签切换，不再另设折叠项。CTP 账户身份、环境和权限保持可见，撤销授权与断开账户在同一行。离开账户只断开 Terminal，服务继续运行；断开柜台不等于撤销已有委托。
- **自选为空时**：写明原因（行情未连接，或尚未加入自选）并给出前往市场页的按钮。

开发版窗口标题及标题栏显示“开发环境”，其服务、账户、数据、凭据与安装版默认分开；关闭开发主窗口即停止本机开发服务，交易主机上的服务不受影响；具体目录见 [开发指南](development.md)。

## 启动与设置

Terminal 自己启动本机服务：行情服务在进入工作台后启动，lab 在第一次使用时启动。用户停止的服务不被普通启动自动改回运行；交易服务只重新连接，不登录柜台或交易。每次启动不自动执行采集。

设置窗口的每一页由带标题的分区组成：分区说明在标题下，操作在右上，字段的标签在上、输入在下，技术细节收进“技术详情”。

- **偏好设置**：语言、显示密度、涨跌配色。
- **本机服务**：列出本机的行情与 Python 研究服务，每个一行，显示状态（行情未登录时显示“未登录行情”），行内给出适用的操作（已停止的可启动，要求运行的可重启或停止）；服务名、PID、套接字、目录、自动重启次数和错误在“技术详情”中。停止和重启前先确认，取消不发送命令。本机服务随 Terminal 退出。
- **交易连接**：生成本机客户端证书并显示指纹；登记交易主机的地址、端口、实例名和证书指纹，连接或断开，见[交易](trading.md)。
- **数据源**：数据从哪里来，三个区：
  - **实时行情（CTP）**：本机行情服务登录行情和查询合约目录用的期货账户，其中一个提供行情；
  - **行情录制主机**：录制主机只读接口的地址和端口，数据页读取录制数据时使用；
  - **历史数据供应商**：Tushare 的 Token 与每分钟请求上限。
- **研究**：策略仓库目录。

## 多语言

支持简体中文与英文，宿主和每个功能各自提供语言资源（`src/i18n/`、`features/*/locales/`）。键缺失、两种语言键不一致或占位符不一致会在启动时直接报错。服务诊断以错误码在界面本地化，原始英文诊断放在详情中。

## 功能契约

`features/contract.ts` 定义工作区、headerTools/toolbar 和语言资源，`src/features.ts` 列出当前产品的内置功能。功能声明它通过 query 调用的 Native 命令，宿主限制命令范围；这用于防止误用，不构成沙箱。界面只提交意图和展示服务投影，持久业务状态由服务拥有。研究与数据页经 `src/bridge/lab.ts` 直接以 Protobuf 请求 lab。

UI 功能与宿主统一编译发布，组件按需懒加载。需要新增菜单或设置贡献时按真实需求扩展类型契约。

## 原生命令边界

Native 命令按职责分在 `native/commands_*.cpp`：行情（`market.*`）、交易账户（`live.*`）、连接与凭据设置
（`ctp.connections.*`、`trading.*`、`recorder.endpoint.*`、`data.credentials.*`、`research.repository.*`）、本机服务（`node.action`）、
Python 运行时（`runtime.python.*`）与 lab（`lab.endpoint`、`lab.source.configure`）。快照（`runtime.snapshot`）给出本机服务、行情、
交易账户与各项设置；历史数据和研究不经过快照。

历史行情读 lab：合约列表是 Tushare 与录制服务已入库的合约（`stored_contracts`），有分钟线的在前；图表的 K 线、均线所需的收盘价
和 MACD 来自 `chart_bars`（规则见 `asterion_lab/chart.py`）：分钟线按所选来源聚合为 1、5、10、15、30、60 分钟，
日线聚合为日、周、月、季、年；两种来源都有分钟线时可切换，不拼接、不混用。没有采集过的合约可从图表跳到「数据 → 数据覆盖」采集。


Native RPC 按数据、控制、管理分别共享 128/128/8 MiB 的序列化载荷额度；回复由最后
一个读者释放，连接结束不会提前归还解析队列仍持有的字节。到界面的编码回复另有
快照 256 MiB、命令 128 MiB 的独立保留额度，单项 JSON 编码最多 128 MiB。超额明确
返回容量错误；命令可能已执行时提示结果未知，不自动重发。上述额度约束传输与完成
队列中的序列化长度，不代表 Native、V8 或进程总内存上限。


快照在状态 owner 上固定发布修订及不可变引用；响应队列保存这些引用和查询附加字段，
由同一个响应工作展开、编码并释放临时 JSON。排队期间状态刷新不会改变旧回复的修订，
大快照不会先展开后交回 owner 等待第二次编码。


### 历史图表的浏览恢复

在同一窗口内，离开自选/合约/历史行情再返回，会恢复该图表窗格的周期、分钟线来源和所在页（默认最新一页）。复用窗口草稿，不写磁盘；合约、来源或周期不同时不继承页位置。

仅记住每个图表窗格最后一次位置，不是逐合约书签；历史与实时分开显示，不拼接、不补缺值。

### 图表引擎

行情 K 线、Tick、分时、回测权益与 QuantStats 日收益图统一使用 Lightweight Charts 5.2.1。供应商数据、交易时段、周期聚合和指标仍由现有数据/算法层提供。图形坐标使用观测序号映射原始纳秒时间，避免浮点时间碰撞；缺失分时槽保留空白，折线和面积在缺口处断开。成交量与 MACD 使用独立窗格，双侧价格/百分比轴共享同一可见价格范围。

支持鼠标缩放/平移与十字线、原有按钮及键盘；连续行情更新保留浏览窗口和仍存在的选中观测。价格及金额读数保留原始字符串，浮点仅用于坐标与统计展示。TradingView 署名链接和 Apache 2.0 许可证随应用提供。

### 命令参数类型

`src/bridge/commands.ts` 定义当前命令名与参数结构，`TerminalCommand` 从该映射导出。
工作区、宿主及共享组件通过关联方法与参数的 `CommandCall` / `CommandHandler` 传递调用。
`features/contract.ts` 的 `QueryCommand` 限制功能可用的查询方法。
交易面板的账户绑定适配器补入固定账户 ID，调用方不能借可选参数改换目标账户。
传输仍为 Native 边界上的 JSON，响应使用 `Snapshot` 等界面类型；领域计算不消费界面快照。
