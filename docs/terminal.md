# 终端界面

## 视觉语言

极简、科技感、未来感。信息优先，装饰让位于数据。

- **底色**：近黑的深空底（`--canvas`），面板只用 1px 发丝线和极轻的明度差分层，不用厚边框和阴影堆叠。
- **强调色**：单一冷色（青蓝）标示焦点、选中和可交互状态；涨跌红绿只用于行情数值。
- **字体**：界面用系统无衬线字体；数字统一等宽表格数字（`tabular-nums`），价格列右对齐。
- **密度**：行情表 24–26px 行高，紧凑但不拥挤；控件高度统一，圆角最小化。
- **动效**：只在状态变化时出现短促的淡入和高亮，不做装饰性动画。
- **空状态**：缺数据源或未连接时直接写明原因和下一步操作，不留空白，也不填假数据。

样式令牌在 `apps/clients/terminal/src/ui/theme/tokens.css`，组件样式在各插件目录。

## 市场（期货全景）

布局参照同花顺期货通：

- 顶部为资产行（期货；其他资产显示未接入）和分类行（期货全景、主力合约、各交易所、期货夜盘等）。右端是实时／历史切换和 `⋯` 行情设置（品种概览／全部月份、加入自选、表头设置、CTP 连接）。
- 左侧为分组行情表：上海商品期货（上期所＋能源中心）、郑州、大连；右侧为金融期货、广州商品期货、境外商品期货、境外金融期货。境外分组显示“境外行情源尚未接入”。
- 列：名称、现价、涨跌幅(结)、涨跌、1分钟涨速、持仓（成交量可在表头设置中开启）。品种概览每个品种一行，名为“品种＋主连”，实际是该品种持仓量最大的月份合约，不是拼接的连续合约；没有合约目录时列出已订阅月份。
- 右侧是上下两个图表窗格，周期为 分时／Tick／1分／5分／10分／日K／更多（周K、月K、季K、年K、历史K线）。上窗格默认分时，下窗格默认日K。

## 自选与合约

- **自选**：自选与最近浏览列表，右侧两个图表窗格。
- **合约**：左侧自选列表，中间图表与合约信息，右侧报价、五档、成交明细和下单区（仅引导到模拟交易）。

## 启动与设置

首次启动检查本机环境，协调 Agent 升级，启动行情和研究服务并验证连接后进入工作台。设置窗口将数据源与连接部署分开。

- **连接与部署 → 当前运行位置**：按行情、研究与计算、模拟交易、实盘交易、策略显示当前连接的位置和业务状态。未创建的会话标记本机默认、按需启动；连接到行情进程不等于已登录柜台。
- **机器管理**：选择一台机器查看其服务；程序、端口、目录和原始诊断进入详情。停止、重启、更新及切换服务连接前展示目标和已知业务影响，取消不发送命令。
- **添加远程机器**：机器信息 → 初始化机器 → 核验并连接。默认只填写名称和地址；SSH 端口、专用账户和管理端口放在高级选项。本机生成公钥，管理员初始化，用户核验主机身份后再安装。
- **部署服务**：在选中的远程机器上部署行情、研究或模拟交易。部署不会自动切换连接，成功后明确提示；选择“使用此服务”才切换。任务与账本不自动迁移。
- **数据源**：独立管理供应商连接和访问验证。直接填写证书的交易连接保留在部署页的高级入口，不属于默认添加机器流程。

## 多语言

支持简体中文与英文，宿主和每个插件各自提供语言资源（`src/i18n/`、`plugins/*/locales/`）。键缺失、两种语言键不一致或占位符不一致会在启动时直接报错。服务诊断以错误码在界面本地化，原始英文诊断放在详情中。

## 插件契约

`plugins/contract.ts` 定义工作区、总览卡片、任务和语言资源。插件声明它调用的 C++ 命令，宿主只把这些命令开放给它。插件在构建时注册，按需懒加载。
