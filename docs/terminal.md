# 终端界面

## 视觉语言

极简、科技感、未来感。信息优先，装饰让位于数据。

- **底色**：近黑的深空底（`--canvas`），面板只用 1px 发丝线和极轻的明度差分层，不用厚边框和阴影堆叠。
- **强调色**：单一冷色（青蓝）标示焦点、选中和可交互状态；涨跌红绿只用于行情数值。
- **字体**：界面用系统无衬线字体；数字统一等宽表格数字（`tabular-nums`），价格列右对齐。
- **密度**：行情表 24–26px 行高，紧凑但不拥挤；控件高度统一，圆角最小化。
- **动效**：只在状态变化时出现短促的淡入和高亮，不做装饰性动画。
- **空状态**：缺数据源或未连接时直接写明原因和下一步操作，不留空白，也不填假数据。

样式令牌在 `apps/clients/terminal/src/ui/theme/tokens.css`，组件样式在各插件目录。

## 结构

```
┌ 标题栏：搜索 · 应用名 ─────────────────────────────┐
│侧 │ 工作区                                        │
│栏 │                                               │
│   │                                               │
├───┴───────────────────────────────────────────────┤
│ 状态栏：服务 · 任务 · 状态时间 · 交易连接              │
└───────────────────────────────────────────────────┘
```

侧栏工作区（⌘1–⌘6）按显示顺序排列：自选、合约、市场、数据、研究、交易。首次打开默认进入自选，之后恢复上次使用的工作区；设置窗口不改变这个记录。设置是独立窗口（⌘,）。

账户资金和风险在交易页查看，回测及下载进度集中在任务中心，服务异常和失败／中断任务在状态栏明确显示。点击任务进入对应业务页并收起任务中心。

## 市场（期货全景）

布局参照同花顺期货通：

- 顶部为资产行（期货；其他资产显示未接入）和分类行（期货全景、主力合约、各交易所、期货夜盘等）。右端是实时／历史切换和 `⋯` 行情设置（品种概览／全部月份、加入自选、表头设置、CTP 连接）。
- 左侧为分组行情表：上海商品期货（上期所＋能源中心）、郑州、大连；右侧为金融期货、广州商品期货、境外商品期货、境外金融期货。境外分组显示“境外行情源尚未接入”。
- 列：名称、现价、涨跌幅(结)、涨跌、1分钟涨速、持仓（成交量可在表头设置中开启）。品种概览每个品种一行，名为“品种＋主连”，实际是该品种持仓量最大的月份合约，不是拼接的连续合约；没有合约目录时列出已订阅月份。
- 右侧是上下两个图表窗格，周期为 分时／Tick／1分／5分／10分／日K／更多（周K、月K、季K、年K、历史K线）。上窗格默认分时，下窗格默认日K。

## 自选与合约

- **自选**：自选与最近浏览列表，右侧两个图表窗格。
- **合约**：左侧自选列表，中间图表与合约信息，右侧报价、五档、成交明细和下单区（仅引导到历史回放）。

## 交易与回测

- **研究 → 历史回放**：账户列表 → 新建 → 选择历史数据 → 账户与规则 → 确认创建。账户名称对应本机受保护的独立记录目录，同名创建拒绝覆盖；自定义目录放在高级入口。已托管账户从列表打开，列表以 Node Agent 实际服务为准；未列出的账户可从指定目录恢复。
- **交易 → CTP 账户**：账户列表 → 账户信息 → 合约与风控 → 确认创建。缺合约目录时可在当前步骤读取柜台规格，不需要先去行情页。创建不登录、不授权；随后核对账户、前置地址和环境，再连接柜台与显式允许发送委托。仿真/真实资金是用户确认的标记，不能由前置地址自动推断，也不代表柜台验证的资金性质。标记仅保留在当前窗口的账户草稿中，重开窗口须重新核对。密码与授权码不持久化。
- **日常交易**：压缩资金摘要，保留下单区；持仓、委托、成交切换查看，历史模拟另有策略页签。CTP 账户身份、环境和权限保持可见，费率与模板收在详情。离开账户只断开 Terminal，服务继续运行；断开柜台不等于撤销已有委托。
- **均线回测**：已完成的下载可通过“用于回测”带入数据来源和所属研究服务；切换服务必须重新选择，不能因任务编号相同而复用。默认显示记录，新建按历史数据 → 参数与交易规则 → 确认运行分步填写；提交后显示进度，完成后单独查看固定参数和结果。草稿与任务结果分开，不把编辑中的参数当成历史实验输入；中断、取消和失败记录可显式重新运行。因子分析保留独立入口。

开发版窗口标题及标题栏显示“开发环境”，其服务、账户、任务、凭据与安装版默认分开；关闭开发主窗口自动停止本机开发服务与 Agent，安装版及远程服务继续独立运行；具体目录见 [开发指南](development.md)。

## 启动与设置

首次启动检查本机环境，协调 Agent 升级，启动行情和研究服务并验证连接后进入工作台。设置窗口将数据源与连接部署分开。进入数据与研究页面时自动准备未连接的本机研究环境；失败后显式重试，不循环启动。当前页面中主动停止服务或服务失联时保留状态，由用户重试，不自动撤销停止操作。已选择远程研究服务时不自动切回本机。

- **连接与部署 → 当前运行位置**：按行情、研究与计算、模拟交易、实盘交易、策略显示当前连接的位置和业务状态。未创建的会话标记本机默认、按需启动；连接到行情进程不等于已登录柜台。
- **机器管理**：选择一台机器查看其服务；程序、端口、目录和原始诊断进入详情。停止、重启、更新及切换服务连接前展示目标和已知业务影响，取消不发送命令。
- **添加远程机器**：机器信息 → 初始化机器 → 核验并连接。默认只填写名称和地址；SSH 端口、专用账户和管理端口放在高级选项。本机生成公钥，管理员初始化，用户核验主机身份后再安装。
- **部署服务**：在选中的远程机器上部署行情、研究或模拟交易。部署不会自动切换连接，成功后明确提示；选择“使用此服务”才切换。任务与账本不自动迁移。
- **数据源**：独立管理供应商连接和访问验证。直接填写证书的交易连接保留在部署页的高级入口，不属于默认添加机器流程。

## 多语言

支持简体中文与英文，宿主和每个插件各自提供语言资源（`src/i18n/`、`plugins/*/locales/`）。键缺失、两种语言键不一致或占位符不一致会在启动时直接报错。服务诊断以错误码在界面本地化，原始英文诊断放在详情中。

## 插件契约

`plugins/contract.ts` 定义工作区、任务和语言资源。插件声明它调用的 C++ 命令，宿主只把这些命令开放给它。插件在构建时注册，按需懒加载。
