# 终端界面

## 视觉语言

极简、科技感、未来感。信息优先，装饰让位于数据。

- **底色**：近黑的深空底（`--canvas`），面板只用 1px 发丝线和极轻的明度差分层，不用厚边框和阴影堆叠。
- **强调色**：单一冷色（青蓝）标示焦点、选中和可交互状态；涨跌红绿只用于行情数值。
- **字体**：界面用系统无衬线字体；数字统一等宽表格数字（`tabular-nums`），价格列右对齐。
- **密度**：行情表 24–26px 行高，紧凑但不拥挤；控件高度统一，圆角最小化。
- **动效**：只在状态变化时出现短促的淡入和高亮，不做装饰性动画。
- **空状态**：缺数据源或未连接时直接写明原因和下一步操作，不留空白，也不填假数据。

- **控件**：按钮、输入框、下拉框、复选框和表格只在 `src/ui/theme/style.css` 开头定义一次，
  悬停与焦点状态在同一文件定义一次。控件用 `--line-strong` 描边，输入和选择框用 `--field` 实底；主操作
  （`.primary`）是青色描边加极淡底色，不用实心色块。组件样式只设置自身的尺寸与布局，
  不重新定义控件外观。
- **下拉菜单**：统一使用 Electron 的 `appearance: base-select`，保留原生选择、键盘和无障碍语义。
  展开菜单在顶层使用不透明 `--raised` 底色、细边框和轻阴影；当前选项显示青色勾选，悬停与
  键盘焦点有独立反馈。默认向下展开，下方空间不足时向上避让；长列表限高滚动。
  组件只设尺寸与布局，不覆盖菜单颜色或展开方向。
- **分区**：一个面板内的各段共用同一左右留白，用发丝线分隔，不各自设置外边距。

样式令牌在 `apps/clients/terminal/src/ui/theme/tokens.css`（结构线 `--line`、控件描边
`--line-strong`、输入底色 `--field`），组件样式在各插件目录。

## 页面规则

- **标签即标题**：页面不重复标签名、服务名和“已连接”；服务不可用时才显示一行提示。
- **一个节奏**：页面内容统一左右留白和纵向间距；字段标签在控件上方，多个字段排成一行。
- **说明从简**：页面说明最多一句；限制说明、数据与程序身份（摘要、来源表）收进折叠项，比较用的参数直接可见。
- **一次一步**：多步流程只显示当前一步；主操作在表单末尾。
- **只列可用的**：未接入的数据源不放进导航，也不为它们留占位页。

## 结构

```
┌ 标题栏：搜索 · 应用名 ─────────────────────────────┐
│侧 │ 工作区                                        │
│栏 │                                               │
│   │                                               │
├───┴───────────────────────────────────────────────┤
│ 状态栏：服务 · 任务 · 状态时间 · 交易连接              │
└───────────────────────────────────────────────────┘
```

标题栏由界面自己绘制，不使用系统标题栏，整条可以拖动窗口：macOS 的窗口按钮嵌在它的左端；Linux 的窗口按钮画在它的右端（数量和顺序跟随桌面环境的设置，GNOME 默认只有关闭），颜色取主题的 `--canvas` 与 `--text`，系统的浅色或深色主题不影响它。Linux 上设置窗口同样如此。

侧栏业务模块（⌘1–⌘7 / Ctrl+1–Ctrl+7）依次为：行情、数据、分析、策略、回测、评估、实盘；侧栏底部是任务中心、连接与部署和设置（⌘, / Ctrl+,，独立窗口）。导航只有两级：模块，以及模块内一行视图标签——行情（市场、自选、合约）、数据（历史数据、全市场数据、数据仓库、资料）、分析（因子、因子比较、样本、统计、变量）、策略（规则、策略包）、回测、评估（绩效、风险、回测比较）、实盘。只有一个视图的模块不显示标签行；没有内容的入口不出现。首次打开默认进入数据，之后恢复上次的模块与视图；同一窗口内保留各视图的位置、任务参数和草稿。

账户资金和风险在交易页查看，回测及下载进度集中在任务中心，服务异常和失败／中断任务在状态栏明确显示。点击任务进入对应业务页并收起任务中心。

## 市场（期货全景）

布局参照同花顺期货通：

- 顶部一行分类：期货全景、主力合约和各交易所；没有接入来源的资产和指数分类不出现。右端是实时／历史切换和 `⋯` 行情设置（品种概览／全部月份、表头设置、行情连接）。未登录时分类下方是一条登录栏（行情账户、密码、授权码、保存到钥匙串、连接）；登录后，更换来源、清除凭据和重新加载目录收进 `⋯` 菜单的“行情连接”。“按代码添加自选”是单独的折叠项，供没有合约目录时使用。
- 左侧为分组行情表：上海商品期货（上期所＋能源中心）、郑州、大连；右侧为金融期货、广州商品期货。分组只在有合约时显示；未接入的境外行情不展示占位分组。
- 列：名称、现价、涨跌幅(结)、涨跌、1分钟涨速、持仓（成交量可在表头设置中开启）。品种概览每个品种一行，名为“品种＋主连”，实际是该品种持仓量最大的月份合约，不是拼接的连续合约；没有合约目录时列出已订阅月份。
- 右侧是上下两个图表窗格，周期为 分时／Tick／1分／5分／10分／日K／更多（周K、月K、季K、年K、历史K线）。上窗格默认分时，下窗格默认日K。日K 及以上的周期读全市场日线表（见[查看](market-data.md#查看)），不需要下载；全市场日线表还没有入库时这些周期不可选，图上给出去「数据 → 全市场数据」更新的入口。分钟周期读已下载的分钟线。

## 自选与合约

- **加入自选**：加入或移出自选的按钮在合约标题旁，市场、自选、合约三页都是同一个按钮，不经过菜单。
- **自选**：自选与最近浏览列表，右侧两个图表窗格。
- **合约**：左侧自选列表，中间是图表和同品种其他月份的一条“相关合约”，右侧报价、五档、成交明细和下单区（仅引导到 CTP 交易页）。没有数据来源的页签（资讯、外盘、社区、T 形报价、F10）不占位。
- **自选表的列**：只保留期货合约可能有的字段。尚无来源的字段（主力净额、量比、成交额、内外盘等）保留并置灰、不可排序；总市值、净利润、市盈率这类股票字段不出现。

## 交易与回测

- **交易**：左侧是全部可交易的 CTP 账户及各自状态，右侧是所选账户的面板；多个账户可以同时打开。首次使用某个账户时开通交易：账户的柜台信息始终显示在上方，分两步填写——合约与风控 → 确认创建。缺合约目录时可在当前步骤读取柜台规格，不需要先去行情页。创建不登录、不授权。此后账户面板一次只给出当前这一步：核对环境并连接柜台 → 显式允许发送委托 → 下单；未到的步骤不显示为禁用的表单。授权长期有效（撤销、修改风控政策或交易服务重启后失效），所以已授权的账户重新连接后直接回到下单这一步。账户已连接但本窗口尚未核对环境时，先单独核对环境。仿真/真实资金是用户确认的标记，不能由前置地址自动推断，也不代表柜台验证的资金性质。标记仅保留在当前窗口的账户草稿中，重开窗口须重新核对。密码与授权码不持久化。
- **日常交易**：压缩资金摘要，保留下单区。下单区是合约、开平、手数、限价，加“买入”“卖出”两个带账户名称的按钮；在输入框里按回车不会发送委托。合约已订阅行情时可一键填入最新价、买一或卖一。委托发出后自动切到委托列表。持仓、委托、成交、费率、风控用同一排标签切换，不再另设折叠项。CTP 账户身份、环境和权限保持可见，撤销授权与断开账户在同一行。离开账户只断开 Terminal，服务继续运行；断开柜台不等于撤销已有委托。
- **自选为空时**：写明原因（行情未连接，或尚未加入自选）并给出前往市场页的按钮。
- **历史数据仓库**：每个版本一行；“使用情况”“查看数据”“下载后续数据”都在所点的那一行下面展开，一次只展开一个。
- **全市场数据**：数据页的第三个标签。上方是更新表单（起止日期、要更新的按日数据表——日线、结算参数、仓单日报、成交持仓排名，默认全选；没有保存凭据时另有请求速率和凭据），提交后在表单下方显示进度；结束后列出新入库、没有变化、数据源未返回数据的分区数，以及未能入库的分区和逐行原因。下方的表按“数据表 × 交易所”列出范围、分区数、行数、相对交易日历缺少的交易日和最近取得时间，还没有数据的写“尚未下载”；点“查看数据”在表下方翻看任一分区，缺失的单元格显示“—”，列名按所在的表显示（同是 `volume`，日线里是成交量，仓单日报里是今日仓单量）；结算参数、仓单日报、成交持仓排名的分区上方各有一句读数须知（单位口径因交易所而异、行号只在当天有效、合约或品种的写法）。
- **历史下载**：表单自上而下分两段——数据源账号（凭据、每分钟请求上限、应用共享额度），然后选择合约（交易所、品种、月份合约、周期）并下载。品种和月份合约取自这个数据源的合约表（全市场数据表），选择时不向数据源发请求；合约表还没有入库时给出去「全市场数据」更新的入口。
- **因子**：只有一个因子页和一种因子任务。页面顶部选择序列从哪里来：“K 线”读取所选数据集（分钟线，或全市场日线表里的日线合约、日线主力连续），可选价格动量、期限结构或波动率三种因子，选一个合约时评价它自己，选 3 个以上时做截面评价，每根 K 线上比较当时有数据的合约（每个观测的 IC、秩 IC 与参与的合约数、各段的均值、信息比率和每侧 K 个的分组收益）；“全市场数据表”从全市场日线表读取，填起止日期并逐个添加品种（`SHFE/rb`，按主力连续读取）或合约（`SHFE/rb/2026-10`），或一次添加范围内有合约在市的全部品种，1 个或 3–100 个，三种因子都可选，页面显示各交易所已入库的范围和这次读取所依据的快照，还没有入库数据时提示并可跳到「数据 → 全市场数据」；窗口、预测跨度和评价方式（全样本、时间留出、滚动验证）是同一组参数，两种来源都可用。任务列在同一张分析记录里，结果在记录下方展开，同一页显示来源证据、分段评价和可翻页的样本明细。
- **策略回测**（回测页）：已完成的分钟线下载可通过“用于回测”带入数据来源和所属数据服务；切换服务必须重新选择，不能因任务编号相同而复用。默认显示记录，新建按历史数据 → 参数与交易规则 → 确认运行分步填写。第二步选择[策略](strategies.md)（均线交叉、通道突破、时序动量、布林回归，或给多个合约排序的截面动量、截面期限结构、截面波动率——合约数不够每侧持有的两倍，或按期限结构排序而所选的不全是带期限结构数据的主力连续时，表单说明并不能继续）并填写它的窗口、目标手数（排序规则填每个合约的名义金额）和持仓方向，以及每个合约的保证金、手续费和滑点跳数（默认 1 跳）；窗口可以用逗号填多个值，各种组合成为候选策略，这时须选比较方式——留出（填留出起始日）或滚动验证（填训练交易日数和每轮验证交易日数），表单随填写显示候选个数，候选为 0 或超过 32 个时不能继续。结果页的标题写明所用（比较时为选中）的规则和窗口；留出比较的结果另有候选策略的前段得分表，以及选中策略在前段和留出段的绩效，见[参数比较与留出](backtest.md#参数比较与留出)；滚动验证的结果列出各轮跟随的策略和验证段表现，以及样本外绩效，见[滚动验证](backtest.md#滚动验证)。选择历史数据时，“本次使用的数据”始终列在最上方（可在此保存为数据集）；添加数据的五种方式——日线合约、日线主力连续、分钟线合约、分钟线主力连续、已保存数据集——用标签切换，一次只显示一种，各是一张独立的表单（见[数据集输入](market-data.md#数据集输入)）。日线的两种直接从全市场日线表读，填合约或品种和起止交易日即可，不需要先下载；默认打开“日线合约”，从“用于回测”进入时打开“分钟线合约”；提交后显示进度，完成后单独查看固定参数和结果。草稿与任务结果分开，不把编辑中的参数当成历史实验输入；中断、取消和失败记录可显式重新运行。因子分析使用同一个数据选择区，选中的主力连续作为一条序列评价（见[主力连续序列](factors.md#主力连续序列)）；回测与因子两页版面相同——页头是页面标签、活动任务容量和服务状态三行窄条，表单全宽在上，记录与结果在下，每页只列出自己提交的任务。

开发版窗口标题及标题栏显示“开发环境”，其服务、账户、任务、凭据与安装版默认分开；关闭开发主窗口即停止本机开发服务，交易主机上的服务不受影响；具体目录见 [开发指南](development.md)。

## 启动与设置

每次启动显示行情服务、恢复已有工作区、交易服务三步。Terminal 自己启动本机服务：已有 Data 或 Research 时启动并等待它们健康；无既有工作区时不创建，用户进入 Data 或 Research 流程后按需准备。用户停止的服务不被普通启动自动改回运行。准备失败明确显示所属步骤并显式重试；交易服务只重新连接，不登录柜台或交易。没有阻塞或提示时进入工作台；插件失效、中断任务或部分交易服务不可用会先提示。每次启动重新核验健康，不自动执行下载。

设置窗口的每一页由带标题的分区组成：分区说明在标题下，操作在右上，字段的标签在上、输入在下，技术细节收进“技术详情”。

- **偏好设置**：语言、显示密度、涨跌配色。
- **本机服务**：列出本机的行情、历史数据、研究与 Python 研究服务，每个一行，显示状态（行情未登录时显示“未登录行情”），行内给出适用的操作（已停止的可启动，要求运行的可重启或停止）；服务名、PID、套接字、目录、自动重启次数和错误在“技术详情”中。停止和重启前展示目标与可见的未完成任务，取消不发送命令。本机服务随 Terminal 退出。
- **交易连接**：生成本机客户端证书并显示指纹；登记交易主机的地址、端口、实例名和证书指纹，连接或断开，见[交易](trading.md)。
- **数据源**：数据从哪里来，三个区：
  - **实时行情（CTP）**：本机行情服务登录行情和查询合约目录用的期货账户，其中一个提供行情；
  - **行情录制主机**：录制主机只读接口的地址和端口，数据页读取录制数据时使用；
  - **历史数据供应商**：Tushare 等的凭据、每分钟请求上限与访问验证；历史数据服务未运行时可在此启动它。
- **插件**：各服务启用的数据源插件（运行中的服务须先在本机服务页停止才能修改）、插件目录与安装。
- **业务资产目录**、**数据备份与恢复**：只读的资产查询；所选服务停止后的冷备份、核验与恢复到新目录。

## 多语言

支持简体中文与英文，宿主和每个插件各自提供语言资源（`src/i18n/`、`plugins/*/locales/`）。键缺失、两种语言键不一致或占位符不一致会在启动时直接报错。服务诊断以错误码在界面本地化，原始英文诊断放在详情中。

## 插件契约

`plugins/contract.ts` 定义工作区、headerTools/toolbar、任务入口和语言资源，`src/plugins.ts` 选择当前产品的内置贡献。插件声明它调用的 Native 命令，宿主限制 query/trade 的命令范围；这用于防止误用，不构成沙箱。界面只提交意图和展示服务投影，持久业务状态仍由服务拥有。

UI 模块与宿主统一编译发布，不使用独立运行时 API 版本；组件可按需懒加载，由 React 管理挂载、卸载和 effect 清理。当前没有第三方 UI 包安装器。需要新增菜单或设置贡献时按真实需求扩展类型契约，不经全局服务定位器传递任意对象。

原生插件管理与 UI 贡献分开：Native 返回目录和可选资格，界面不自行判断原生能力版本。启用选择和版本切换属于编辑草稿，保存须经 Native 重新验证。详见[原生插件 SDK](native-plugins.md)。

## 原生命令边界

命令名称对应实际职责，插件只声明当前使用的名称，旧综合命令不保留别名。原生入口分别位于
`native/commands_data.cpp`、`commands_task.cpp`、`commands_backtest.cpp`、`commands_factor.cpp`
和 `commands_node_workspaces.cpp`。

| 命令 | 职责 |
| --- | --- |
| `data.datasets`、`data.dataset.*`、`data.coverage` | 历史目录、具名数据集与当前数据选择 |
| `data.minutes.page`、`data.tables.daily` | 分钟档案分页与全市场日线图表 |
| `data.download.*`、`data.credentials.*` | 下载定义、更新计划、授权与共享请求预算 |

页面、快照与服务契约的实施及验收。

快照用 `data` 表示历史仓库连接和采集任务页，用 `research_service` 表示研究连接和计算任务页，`task_result` 表示本次读取的结果。服务类型为 `data` 与 `research`，默认工作区使用 `historical-data` 和 `research` 实例 ID。通用读控命令必须携带 `owner {kind,node_id,service,connection_id}`，同名任务不跨所有者合并。不存在旧命令别名，不改写既有实例目录。

Native RPC 按数据、控制、管理分别共享 128/128/8 MiB 的序列化载荷额度；回复由最后
一个读者释放，连接结束不会提前归还解析队列仍持有的字节。到界面的编码回复另有
快照 256 MiB、命令 128 MiB 的独立保留额度，单项 JSON 编码最多 128 MiB。超额明确
返回容量错误；命令可能已执行时提示结果未知，不自动重发。上述额度约束传输与完成
队列中的序列化长度，不代表 Native、V8 或进程总内存上限。

### 历史图表的浏览恢复

在同一窗口内，离开自选/合约/历史行情去研究或数据工作区再返回，会恢复该图表窗格最后的数据页和显式选择的分钟数据版本。复用原有窗口草稿，不写磁盘。目录短暂未加载时不覆盖保存位置；服务实例、合约、数据版本、日线快照或周期不匹配时不继承页偏移，用户显式切换周期/版本仍从第一页开始。

仅记住每个图表窗格最后一次数据页，不是逐合约/逐周期书签库；窗口重载、图形内部缩放/十字线不在本次恢复范围。历史/实时仍分开显示，不拼接来源，不补缺值，不改变数据或研究输入。验证与边界。

### 图表引擎

行情 K 线、Tick、分时、回测权益与 QuantStats 日收益图统一使用 Lightweight Charts 5.2.1。供应商数据、交易时段、周期聚合和指标仍由现有数据/算法层提供。图形坐标使用观测序号映射原始纳秒时间，避免浮点时间碰撞；缺失分时槽保留空白，折线和面积在缺口处断开。成交量与 MACD 使用独立窗格，双侧价格/百分比轴共享同一可见价格范围。

支持鼠标缩放/平移与十字线、原有按钮及键盘；连续行情更新保留浏览窗口和仍存在的选中观测。价格及金额读数保留原始字符串，浮点仅用于坐标与统计展示。TradingView 署名链接和 Apache 2.0 许可证随应用提供。

### 命令参数类型

`src/bridge/commands.ts` 定义当前命令名与参数结构，`TerminalCommand` 从该映射导出。
工作区、宿主及共享组件通过关联方法与参数的 `CommandCall` / `CommandHandler` 传递调用。
`plugins/contract.ts` 限制查询方法集合；宿主继续检查插件声明的命令权限。
交易面板的账户绑定适配器补入固定账户 ID，调用方不能借可选参数改换目标账户。
传输仍为 Native 边界上的 JSON，响应使用 `Snapshot` 等界面类型；领域计算不消费界面快照。
