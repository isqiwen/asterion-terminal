# CTP 实时期货行情

## 市场与自选的产品要求（2026-09-30）

维护者明确：连接行情后，“市场”应展示行情源支持的完整期货合约目录及对应报价，不要求用户逐个输入合约；“自选”是用户从市场目录中选取的独立子集。旧版将最多 50 个手工自选作为市场列表，导致空自选登录后仍为空。当前目录与自选已分离。

实现需要真实目录来源、目录与自选分离，以及按页面可见范围和自选需求管理订阅、分页和订阅状态。行情登录与目录就绪、订阅成功、首笔报价分别呈现。不得用猜测月份代码生成目录，不得把历史目录直接声称为当前 CTP 可交易全集，不得用虚构报价填表。当前 CTP MdApi 没有 TraderApi 的完整合约资料查询；其组播合约查询不能直接当作普通行情前置的完整目录。完整目录须通过明确的数据能力获取，不能仅放大订阅上限或修改空状态文案来声称完成。CTP TraderApi 的只读合约查询与下单授权分开，不能为获取目录自动开放实盘执行。

验收需覆盖空自选登录后市场仍有真实目录、按交易所浏览和搜索、添加／移除自选不改变市场全集、合约订阅／拒绝／首笔状态、重连恢复，以及真实供应商连接。目录、自动订阅及自选分离已实现；隔离测试与真实供应商验收分别记录在本文末尾。

Terminal 的市场工作区提供“实时行情 / 历史行情”。实时页启动本机行情服务后，填写服务方提供的行情前置、经纪商代码、用户代码与密码，配置独立的目录查询前置及服务方要求的认证信息，再连接；目录就绪后自动订阅全部在市期货，自选可以为空。未配置目录时仍可显式添加实际月份合约，界面不会把该子集称为完整目录。没有默认前置地址，也不把历史 CSV 当作实时行情。远程 Linux 在设置的服务管理中部署“实时行情”，随后连接该服务。

## 实现归属

- `plugins/data/ctp/`：CTP 6.7.7 MdApi 行情和独立 TraderApi 只读合约目录查询；不调用交易执行插件或委托接口。
- `core/include/asterion/domain/live_market.hpp`：报价、订阅状态与实时数据端口。
- `apps/services/market-data/`：CLI11 独立宿主，管理插件生命周期及请求路由。
- `protocol/proto/asterion/v1/market.proto`：连接、订阅、快照推送、合并前事件分页与心跳。
- `apps/clients/terminal/native/market_client.*`：本机 IPC / TCP+mTLS 客户端。
- `apps/clients/terminal/plugins/futures-market/`：行情工作区与中英文资源。

Agent 显式区分 paper / market 服务类型，负责部署、启动、私有健康探测与有限重启。Terminal 关闭只断开观察连接。SDK 网络重连后重新登录并恢复订阅；服务进程重启后需用户重新输入密码，不能因进程存活就显示行情正常。

## 数据与凭据

密码仅存在于本机输入、认证通道请求及服务内存，服务内存保留至断开以支持自动重登录；不会进入快照、日志或持久配置。远程服务通过双向 TLS 接收密码。前置、经纪商、用户代码和自选保存在 Terminal 本机。

订阅只接受六家期货交易所的实际月份合约；自选最多 50 个，目录最多 20000 个，行情按每批最多 50 个合约订阅／退订，不支持主力/连续合约别名。订阅成功与收到首笔分开；单合约订阅失败可见。买卖一档、价格、成交量、持仓量显示空值而不是伪造零价格。报价时间使用 ActionDay + UpdateTime + UpdateMillisec（北京时间），保留 TradingDay，不将交易日当作自然日。缺失时间、超前时间、30 秒未更新、断线旧报价分别标识；这不是交易日历判断，休市也会显示未更新。

终端每 250ms 接收合并快照，中间 tick 可能被合并，不能用作逐笔历史归档或无损策略行情源。旧时间戳报价不覆盖界面最新值，并单独计数；合并前事件流仍保留该报价及乱序标记。CTP 原始浮点报价只在供应商边界转为八位 Decimal，非权威账本输入。

## SDK 与构建

首次构建显式运行 `python3 scripts/prepare_ctp.py`，再运行 Conan / CMake 或桌面脚本。脚本按照 `conan/ctp/sources.json` 的固定提交和 SHA256 获取 SDK，并导入本机 Conan；CMake 和 Conan 配方不会隐式下载 SDK。供应商 SDK 镜像来源为 [ctp2rs 固定提交](https://github.com/pseudocodes/ctp2rs/tree/2bad971d48d30ee5923f75e82f39dd58b8fe0af9)，使用其中的 MdApi 与 TraderApi 头文件和动态库（Conan 包 `ctp`，行情库 `ctp-md`、交易库 `ctp-trader`）。发布方需遵守供应商 SDK 的使用和分发条款。

当前 6.7.7 材料提供 macOS arm64/x86_64、Windows x86_64、Linux x86_64。Linux 暂时仅支持 x86_64，Terminal、Agent 和服务均不支持 Linux ARM64。桌面包包含本机 SDK 和 Linux x86_64 SDK，不需要用户另行下载。

## 验收边界

单元测试覆盖时间、缺失报价、实际合约和 Protobuf 表示；独立进程测试使用仅测试构建的 SDK 替身，覆盖登录、订阅拒绝、推送、乱序、断线恢复和 Agent 健康。浏览器测试经过真实 C++ 服务与测试 SDK，不代表实际 SimNow 验证。真实账号登录、交易时段新鲜行情仍需独立验收；当前只实施 macOS Terminal。

macOS 保留 hardened runtime，打包签名授予加载外部原生库的 library-validation entitlement，以支持没有相同 Team ID 的供应商 SDK（本机构建为 ad-hoc 签名）。Electron Builder 将此 entitlement 用于包内可执行程序；这不是插件安全隔离。Agent 仍只加载平台、摘要校验通过的显式 SDK 材料。

TCP/mTLS 集成测试另行覆盖匿名客户端拒绝、原生 Terminal 客户端接收报价，以及断开客户端后服务继续运行。SDK 的回环测试只访问 `127.0.0.1`，不使用真实账号或外部前置。


CTP SDK 的三平台准备入口均为 `python scripts/prepare_ctp.py`（macOS/Linux 也可用 `python3`），从脚本位置定位仓库，不依赖当前工作目录。Conan 环境脚本输出到忽略的 `build/ctp-sdk/<os>-<arch>/conan/`，它们包含本机绝对路径，不能提交或跨机器复用。`conan/ctp/` 只保留配方 `conanfile.py` 和固定来源/摘要清单 `sources.json`；清单中的 URL 是可复现依赖定位，不是开发者本机路径。macOS 的 `lipo` 和 `codesign` 仅在 macOS 分支运行，Linux/Windows 使用各自 SDK 库。

## 合并前事件流

`LiveMarketDataPort.events_after(stream_id, cursor, limit)` 读取供应商边界标准化后的事件；CTP 插件在更新界面快照之前记录报价，按回调接收顺序分配独立序号。订阅状态、连接、断线、重连、错误和显式断开也记录为状态事件，状态事件不重复携带旧报价。记录中没有供应商配置或凭据。

每个 Feed 实例有独立流身份，连接重建保留同一实例的事件和连续序号；服务进程重启或创建新 Feed 会生成新身份。首次读取可使用空身份与零游标，之后必须使用返回的身份；旧实例身份、未来游标和非零匿名游标一律拒绝。此序号不是交易所序号，连续只表示插件记录入口的顺序，不能证明上游网络没有丢包。

默认保留最近 4096 个事件，插件可配置容量 1..65536；另设 65536 个记录行的总上限（每个状态事件按 1 加订阅条目数计），避免全市场状态快照放大内存；每页 1..1024 个。读取不消费事件，调用者只有在自己的持久提交成功后才推进游标。返回最早/最新序号和 `gap`：游标落后于已淘汰记录时明确报告缺口，同时提供尚保留的后缀，不能把后缀冒充完整数据。分配或记录异常使 `failed` 永久置位；已有前缀仍可读，该流不能再作为完整记录来源。状态与报价共享这一容量，消费端必须处理两类事件。

行情宿主通过 `market.proto` 的 `ReadEvents` / `EventBatch` 暴露相同分页，支持本机 IPC 和 TCP/mTLS；私有健康通道不接受行情读取。原 250ms `Watch` 保持界面合并快照语义。当前未提供持久归档、历史补取、Terminal 录制按钮或实时策略驱动。

这些是 **标准化报价观察**，不是供应商原始报文或逐笔成交。保留 CTP ActionDay、TradingDay、来源与接收时间及缺失价格；价格沿用八位 Decimal 转换。`volume` 是累计成交量，不转换为逐笔成交数量，不能直接送入当前基于成交事件的回测和模拟撮合。下文说明当前增加的盘口和当日价格字段。

本阶段 macOS GoogleTest/真实子进程验收覆盖：界面丢弃但事件保留的乱序报价、SDK 断线重连、无凭据状态、非破坏分页重读、缓冲溢出与缺口、旧流身份及游标拒绝。测试使用仅测试构建的 SDK；不代表真实 CTP 账号或交易所数据完整性验收。

补充验证：macOS Debug 与 Linux x86_64 Release 均通过 8/8 项相关测试，包含 CTP/事件流 GoogleTest、本机真实进程、TCP/mTLS 和 Agent 行情管理回归。证据为 `build/market-events-integration-tests.log`、`build/market-events-linux-tests.log`；Linux 使用 Ubuntu 24 x86_64 容器。Windows 原生未执行，本阶段代码尚未重新打入 DMG。

## Terminal 最近报价走势（2026-09-29）

桌面 MarketClient 从既有 ReadEvents 接口读取有序事件，不从合并后的报价快照采样。保持 stream_id 与序号游标，每批最多 1024 个事件；展示缓存最多保留跨合约合计 512 个有效报价，价格使用原始十进制字符串，时间为供应商时间。乱序标记、无最新价或无有效来源时间的记录不进入图表。状态仍由独立 watch 快照更新，事件读取失败不关闭该订阅。

序列缺口、失败标记、非 connected 状态或连接中断清除旧段；读取失败后从新游标重新取得服务仍保留的事件，不宣称补齐缺失数据。服务实例或流变化不拼接旧曲线。保留中断提示，展示当前合约的可用记录。缓存按到达顺序有界保存，不是全天历史存储；频繁报价合约可能挤出其他合约的早期记录。

右侧「最近报价走势」使用共享 PriceChart，提供缩放、回看与回到最新。累计成交量不作为逐笔成交量或成交量柱；这不是完整分时、分钟聚合、K 线或持久行情录制。报价详情折叠，优先显示走势。源接口与交易所时间规则尚不能支持右侧双图和指标的完整期货通体验。

验证使用测试专用 CTP SDK 经过真实 Agent、行情服务、IPC、C++ 桥，不使用生产行情替代测试。MarketHistory 单元测试覆盖缓存上限、精确价格、事件缺口、失败、断开、流重置及乱序；浏览器覆盖追加跟随、回看不漂移、切约、恢复后重置和价格轴边界。真实 CTP 账户未验收。

## 五档盘口与当日价格（2026-09-29）

CTP 回调的 Bid/AskPrice2..5 和 Bid/AskVolume2..5 经过领域模型、Protobuf、Node-API 到达合约盘口；买卖一档继续使用报价摘要。协议中每侧固定四项，对应二至五档。无效价格使该档价格和数量同时缺失；零价格且无正数量视为 SDK 未提供的空档，已知价格的零数量保留为 0，负数量显示缺失。界面不会由其他档位推算价格或挂单量。

OpenPrice、UpperLimitPrice、LowerLimitPrice 分别显示为开盘、涨停、跌停，使用供应商边界的八位 Decimal 转换，不从本机收到的首笔价格或涨跌幅推算。缺失保持 null，合法零值保留；后续报价缺失字段时界面清除旧值。自选表开盘列支持显示与排序。昨收使用 PreClosePrice，独立于涨跌计算使用的昨结算价；日增仓使用同条回调 OpenInterest 减 PreOpenInterest（SDK 的“昨持仓量”），在 CTP 插件内用 Decimal 相减。当前或昨持仓量缺失、非有限或为负时，差值保持缺失；合法零值和负差值保留，不从本地缓存的首笔或上一笔报价计算。均价和完整分时仍未接通。

`pnpm test:desktop` 在通用桌面验收后运行 `tests/electron_depth.cjs`。后者在临时目录复制原生资源并替换为明确的测试 SDK，使用未修改的 Electron 宿主、实际 Agent、行情服务和 Node-API，检查多档盘口及当日价格的显示。此测试不连接真实柜台，不代表真实账户、交易所五档权限或安装包验收。

## 全市场目录与自选分离（2026-09-30）

行情登录不等于合约目录查询成功。目录查询需要服务方提供的 Trader 前置；不由行情地址推测端口。AppID/授权码按服务方要求成对输入。目录查询只执行认证、登录和合约资料查询，不确认结算、不查询账户、不下单。前置和 AppID 可保存在本机；密码和授权码不持久化。已登录行情可在连接详情中单独加载目录，不需断开行情。

查询在独立工作线程执行。只有最后响应成功后发布目录；部分失败、超时、取消、非法字段、重复条目和超限不会发布部分全集。目录包含供应商在市的实际月份期货及中文名称（GB18030 转 UTF-8），排除期权。目录成功且行情登录成功后自动订阅目录与自选的并集。加入／移出自选不删除目录合约。查询失败展示错误，真实供应商首笔尚未到达时仍显示订阅状态，不伪造报价。目录当前在用户连接／主动查询时刷新，尚无自动跨交易日刷新。

Agent 部署与更新材料增加独立目录 SDK 摘要，正式包同时内置行情 SDK 和目录 SDK。旧服务缺少目录材料时明确不可用，需经正常服务更新边界升级；不修改用户账户配置或静默替换运行中程序。

验证日志：`build/catalog-final-tests.log`（CTP、目录、真实服务进程和部署资源检查），`build/catalog-ui-final.log`（浏览器与真实隔离服务）。原生桌面与安装包验证另行记录；测试 SDK 行情不代表真实账户或交易所新鲜数据验收。

CTP 接入不绑定 SimNow 或某家期货公司。行情前置、目录查询前置、经纪商代码、用户代码及 AppID/授权码全部由服务提供方配置；不内置公司地址、认证码或地址推断规则。SimNow 仅为一次真实验收环境，供应商特定填入按钮已移除。支持范围受服务方是否提供兼容 CTP 接口、账户权限和终端认证要求约束；非 CTP 服务需要对应数据插件。

## 当日分钟线、均价与 1 分钟涨速（2026-09-30）

- CTP `AveragePrice` 在郑商所为单位均价，其他交易所为成交额／成交量（含合约乘数）。行情服务在目录加载后把乘数传给 CTP 插件归一为单位均价；未知乘数或尚无成交时不报告均价。
- 行情服务从有序事件流（不是合并快照）构建当日每合约 1 分钟线（`core/domain/intraday_bars`）：开高低收取最新价，分钟量为累计成交量差值，交易日第一条观测只作为累计量基准。事件缺口、断线或累计量回退标记 `interrupted`；换交易日重新开始，不与旧曲线相连。`first_observation_ms` 标明服务开始观测的时间，之前的分钟未知，不补齐。
- `change_1m_percent` 为最新价相对同一交易日内至少 60 秒前最新一条观测的百分比（8 位小数，四舍六入五成双）；不足 60 秒观测或中断后为空。
- 协议：`Quote.average_price`、`Subscription.change_1m_percent`、`MinuteRequest`／`MinuteSeries`。Terminal 通过只读 `market.minutes` 查询，服务 I/O 在操作锁外执行。
- 限制：分钟线只保存在行情服务内存中，服务重启或升级后从头观测；不是历史分钟档案，也不替代下载的历史数据集。行情服务程序在本机部署后不会随 Terminal 更新自动替换，需要在服务管理中停止后更新。
