# 终端 PIN 与锁屏

新账号注册必须设置 6 位数字 PIN；现有账号首次登录后先补设。PIN 与邮箱验证码完全独立，即使使用本地“任意邮箱验证码”模式，也必须用已设置的正确 PIN 解锁。

默认在终端所有窗口均无操作 5 分钟后锁定。设置 → 安全可选择 1、5、10、15、30 分钟；状态保存在本机账号中。切换到其他应用、最小化、无操作和睡眠期间均继续计时。任一已解锁且有焦点的终端窗口中的真实鼠标/键盘活动更新账号活跃时间，轮询和后台任务不会延长活跃时间。系统恢复或窗口重新获得焦点时立即检查期限。

所有该账号的窗口，包括设置窗口，在轮询时同步锁定（正常服务下约 1 秒）。当前窗口可通过侧栏“锁定终端”或 ⌘⇧L 立即遮蔽。锁定时保留工作区组件及布局，隐藏内容并禁止交互，后台业务 API 返回 423；worker 的租约、运行和产物发布继续。正确 PIN 解锁后恢复视图、刷新数据。首次登录验证账号密码后建立新的已认证会话。

## 存储与兼容

独立的 `identity_pin_security` 表保存账号 ID、盐化 scrypt 哈希、空闲期限、锁状态、失败计数和修订号，不改变现有账号表。旧账号没有哈希时只能访问补设流程。PIN 不写入 localStorage 或桌面布局文件，原生窗口间同步不传递 PIN。

后端锁定基于服务端时间；前端本地期限用于及时遮蔽，最终是否解锁由后台决定。5 次错误后限制尝试 5 分钟；过期后恢复尝试额度。解锁携带锁状态修订号，旧解锁请求不能覆盖新的锁。重设 PIN 必须验证账号密码，不能使用邮箱验证码直接改 PIN。

这是本机账号的终端锁屏，不改变此前本地邮箱验证码开发模式。日后切换正式账号服务时继续使用独立的 PIN 和锁定接口，不把本地验证码规则带入 PIN 校验。
