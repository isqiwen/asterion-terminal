# SimNow 行情接入

当前切片只接入 CTP MdApi，不连接交易柜台、不读取资金持仓、不提供下单。

## 使用

1. 在「总览 → 实时行情 → 连接与自选」打开 SimNow 配置。
2. 从 [SimNow 官方环境说明](https://www.simnow.com.cn/product.action) 获取交易时段环境的 **Market Front**，以 `tcp://主机:端口` 填入。不要填 Trade Front 或非交易时段测试环境地址。地址不自动猜测。
3. 填写 SimNow 投资者代码及密码；BrokerID 固定为 9999。此行情切片不要求交易认证 AppID/AuthCode。
4. 选择交易所，逐个添加月份合约来源代码，大小写遵循 CTP，例如实际存在的合约；不接受主力、连续或指数代码。当前不提供合约目录搜索，输入仍需以来源有效合约为准。
5. 点击「保存并连接」。保存配置和登录是不同状态：登录成功后自动订阅，收到报价才显示数值；拒绝订阅或等待报价单独标注。
6. 修改连接或自选前先在同一窗口「断开行情」，保存后重新连接。服务重启保留自选和非密码配置，需要重新输入密码。

密码只保留在本次连接内存，配置文件和 HTTP 状态不包含密码。前置地址与投资者代码、自选列表保存在本机数据目录 `market/simnow.json`（0600、原子替换）。无法读取当前配置时明确报错、保留原文件，不能自动覆盖。文件随本机数据目录备份，恢复后的 SDK 连接不会自动登录；本切片尚未单独验证备份恢复。

## 状态和语义

- 明确标注 SimNow 仿真来源；不能把仿真账户当作真实账户。
- SDK 前置重连后重新登录、重新订阅；密码仍只在进程内存。旧连接回调不能覆盖新连接。
- 每秒读取本机最新报价状态；总览频率不代表交易所推送频率。
- 报价时间使用来源 ActionDay + UpdateTime + UpdateMillisec（上海时区）；TradingDay 单独保留，不用于推断夜盘自然日期。
- 时间不可确认、源时间或接收时间超过 30 秒、断线时均显示过期。这个标记只说明新鲜度，不推断休市、停牌或网关故障。
- 无效价格哨兵值显示 `—`；涨跌按最新价与昨结算价计算；乱序旧时间报价拒绝覆盖。
- 这里的交易所与来源代码是行情观察身份，尚未绑定已发布实际合约生命周期目录，不能用作交易或结算依据。

## 插件与 SDK

`asterion.market` 通过身份插件公开访问检查及 DATA_ROOT 资源运行，贡献 `/market` API 和服务诊断；发行版声明请求授权，工作台只通过无凭据请求端口调用。核心没有 SimNow 分支。

SDK 使用 [openctp-ctp 6.7.7.1](https://pypi.org/project/openctp-ctp/6.7.7.1/)，该发布提供 macOS ARM64 构建，本机加载报告 `v6.7.7_MacOS_20240716`。固定使用这一依赖，并随桌面运行时打包。只初始化行情 API，未启用交易接口。

## 验证边界

已验证离线报价、过期、重连隔离、订阅错误、配置保留、凭据不落盘、接口鉴权和浏览器操作；本机原生 SDK 创建/释放成功。真实 SimNow 登录、有效月份合约订阅和交易时段连续行情仍需要用户本机凭据联调，不以模拟回调测试替代。
