# CTP 与 SimNow 只读接入

当前由 `asterion.connections` 管理连接、`asterion.connector.ctp` 实现 CTP 通信；行情与账户功能通过公开连接契约使用它们。SimNow 是仿真连接配置，券商实盘使用同一 CTP 插件及统一界面。实盘参数可配置，但本轮未使用真实券商凭据联调，不承诺所有券商认证变体均支持。交易执行未开放。

## 配置与操作

1. 从行情或账户面板点击「配置连接」，进入「设置 → 连接」，点击「添加配置」，填写连接名称及服务方参数；多个接入协议可用时选择协议。
2. 填写 BrokerID、投资者代码、行情/交易前置、AppID、认证码及密码。SimNow 的共享测试参数为 BrokerID `9999`、AppID `simnow_client_test`、认证码 `0000000000000000`；两组前置须来自 SimNow 官方环境说明中同一环境，不能互换。实盘使用券商提供的参数。
3. 点击「保存配置」，再点击「连接」，统一启用行情、账户查询和合约获取。点击「断开连接」后可以编辑配置，密码默认保留。
4. 在行情面板选择连接，打开自选合约，通过交易所、品种、名称或代码查找、勾选，最多 50 个。在线保存更新订阅，移除时退订。合约行只显示简称加月份，例如铸铝2610；名称缺失显示代码。
5. 连接选择在行情、账户和设置间同步。同时最多只有一个活动连接，在线切换先关闭原连接再启用所选配置。切换后不会显示前一账户的资金或自选。配置、密码、自选及当前选择重启后保留，点击「连接」即可使用，无需重复新建。

界面由功能插件提供；接入配置表单来自受限字段描述，没有供应商任意脚本。缺失接入插件保留档案并标不可用，不自动切换来源。能力不支持时操作不可用，不以空仓或零资金冒充成功。

## 持久化、身份与凭据

连接档案及 `selected_id` 保存在 `connections/profiles.json`（version 2）；秘密以专用 SecretPort/Fernet 用途域加密，绑定完整连接档案和配置版本，文件使用 0600 和原子替换。接口只返回 `secret_saved` 布尔映射，不返回秘密或密文；当前选择由后台与档案一起保存，浏览器不独立保存连接选择。

保存操作显式选择保留、替换、清除。修改连接目标需要重新填写凭据确认；改变账户身份或接入方式须保存另一份命名配置。配置版本冲突拒绝覆盖。非法格式、密文或身份不匹配时保留原文件并报错。旧连接配置不自动迁移，检测到时提示重新配置，不读取旧凭据创建新身份。

行情自选和目录分别位于 `market/connections/<connection_id>/watchlist.json`、`instruments.json`，目录附连接 ID/配置版本摘要和校验和。缓存不含秘密。正式合约身份和交易规则仍由期货领域插件负责，来源代码和 UI 简称不能充当交易准入依据。

当前接入插件是受信任的同进程实现，不是 OS 沙箱。加密也不能防御已经获取本机密钥的进程。备份必须同时保留相应数据和运行密钥；本轮没有验证新连接格式的完整备份恢复流程。

## 通信与状态

CTP 行情使用 MdApi；查询使用 TraderApi，只有认证、登录、品种、合约、人民币资金和持仓查询，无结算确认、委托或撤单接口。SDK 版本与平台依赖继续由桌面运行时固定。

每个连接的查询经过同一串行锁；查询实例在单次完整查询后释放，同实例查询请求至少间隔 1.1 秒。账户通道“连接”表示开启按需认证与定时查询，不宣称维持一个已订阅成交回报的交易长连接。资金和持仓为顺序查询快照，保留批次身份和起止时间。

账户后台每 30 秒刷新，无需打开面板；合约后台按上海日期判断是否需要更新，失败至少间隔五分钟重试。用户可手动刷新。完整末包、身份、时间和结构校验通过才替换缓存；失败、取消、断线和迟到结果不发布。查询失败保留同一连接的上次完整快照并标陈旧，断开连接隐藏快照。

行情保留来源日期、交易日、时间和接收时间，分别标注时间未知、超前、延迟、未更新和断开，不推断休市或停牌。到期清理使用已知生命周期：最后交易日保留、次日从该连接自选中移除；仅从新目录消失不算到期。未知证据不删除自选。

## 账户与风险

CTP 字段解码、今昨及方向分类校验在接入插件；交易插件消费规范模型并形成账户视图。资金与持仓按柜台口径显示，不将持仓盈亏冒称总日收益，不在缺少乘数和成本语义时猜测持仓均价。

风险面板只计算保证金/权益和可用资金/权益，权益必须大于零，未知金额不能转成零。总体风险、敞口、集中度缺少完整规则时明确无法评估。确认完整的空持仓才显示无持仓。

## 验证边界

新架构已通过插件装配、接口鉴权、加密重启、两个来源隔离、唯一活动连接、并发切换、迟到回调、查询完整性、原生 SDK 回调模拟、串行查询和界面流程验证。第二接入实现仅在测试中，不进入生产装配。此前真实 SimNow 查询验证不等于本轮新架构真实登录验证；本轮未复用旧配置秘密，也未连接真实券商或执行交易。

职责、依赖和进一步验收见 [账户连接与行情接入插件设计](broker-connections.md)。


连接配置支持编辑与删除：断开后可重命名、修改非身份参数和替换/清除密码；原密码默认保留，目标地址改变必须重新输入凭据。账户身份仍固定，更换账户保存另一份配置，避免改写历史归属。删除通过命名确认框提交配置版本；在线配置及版本冲突拒绝删除。成功后原子移除档案及密文，清空被删配置的当前选择，不自动选中或连接其他账户。保留该 ID 下的自选缓存、合约资料和历史数据。缺失接入插件的离线配置仍可删除。后台清理已删配置的内存消费者，迟到行情回调丢弃。

实时行情表显示最新价、涨跌额、涨跌幅、最高价、最低价、成交量和持仓量。CTP 的 `PreSettlementPrice` 明确规范为 `previous_settlement`；最高/最低分别读取 `HighestPrice`/`LowestPrice`，不由收到的局部 tick 重建日内极值。涨跌额=最新价−昨结算；涨跌幅=涨跌额/昨结算×100%。缺失或非正昨结算不计算两项涨跌，也不改用 `PreClosePrice`；来源无效数值显示未知。上涨、下跌方向与颜色使用相同的涨跌额基准。
