# CTP 与 SimNow 只读接入

当前可通过同一 CTP 插件配置 SimNow 或券商提供的连接参数，查看实时行情、资金及持仓。交易执行未开放；配置表单存在不表示已验证所有券商认证变体。开发契约与数据保护要求见 [连接契约](broker-connections.md)，产品目标见 [架构设计](architecture.md)。

## 配置与连接

1. 从行情或账户面板点击“配置连接”，进入“设置 → 连接”，添加命名配置；仅在多个协议可用时选择协议。
2. 填写服务方提供的 BrokerID、投资者代码、行情/交易前置、AppID、认证码及密码。前置必须属于同一环境；券商参数不能沿用测试环境值。
3. 保存后点击“连接”，统一启用行情、合约获取和账户查询。需要编辑时先断开，已保存密码默认保留；改变目标地址必须重新确认凭据。
4. 在行情面板管理自选，通过交易所、品种、名称或代码查询实际月份合约，最多 50 个。在线保存更新订阅，移除时退订。
5. 连接选择在行情、账户和设置之间同步。可保存多份配置，同时最多一个活动连接；切换先关闭原连接。重启保留配置、选择及自选，但需显式点击连接。

断开后可重命名、修改非身份参数、替换/清除密码或删除。更换账户另存配置。删除需要名称确认和当前修订，在线档案或版本冲突拒绝；成功删除档案与密文，保留其自选缓存、合约资料和历史数据，不自动选中其他账户。

缺失插件保留档案并显示不可用；配置损坏保留原文件并报错。不支持的能力不能用零资金或空持仓冒充成功。秘密不会出现在查询响应中，掩码不代表真实密码长度。

## 行情与账户含义

行情表显示最新价、昨结算基准涨跌额/幅、最高价、最低价、成交量和持仓量。涨跌额=最新价−昨结算，涨跌幅=涨跌额/昨结算×100%；缺失或非正昨结算时不计算，也不改用昨收盘。高低价来自来源字段，不由局部收到的 tick 推算。

报价保留来源日期、交易日、时间和接收时间，区分未知时间、来源超前、延迟、未更新与断线；这些状态不推断休市或停牌。已知最后交易日当天保留自选，次日可清理；来源目录短暂遗漏不等于到期。

账户后台约每 30 秒刷新，合约目录按上海日期维护，失败至少间隔五分钟重试；均可手动刷新。查询失败保留同连接的上次完整快照并标陈旧，断开隐藏；切换后不显示前一账户资金。资金与持仓是顺序查询快照，并非同一时刻的原子账户状态。

金额按柜台口径显示，不将持仓盈亏当成总日收益，不猜测持仓均价。风险面板仅计算保证金/权益、可用资金/权益，要求权益大于零；未知金额不转零。总体风险、敞口和集中度依据不完整时显示无法评估；只有完整空批次才显示无持仓。

## 当前限制与验证

连接与 CTP 为受信同进程实现，不是安全沙箱；其来源合约缓存尚未完成规范身份和交易规则绑定，不可用于正式下单。备份须包含匹配密钥，当前连接格式完整恢复尚未独立验收。

自动验证覆盖插件装配、鉴权、加密重启、来源隔离、唯一活动连接、切换/取消/迟到结果、查询完整性和界面流程，见 [连接测试](../tests/test_connections.py)、[生命周期测试](../tests/test_connection_lifecycle.py)、[SimNow 页面测试](../apps/terminal/e2e/simnow.spec.ts) 及 [验证索引](VALIDATION.md)。测试替身和历史真实 SimNow 查询不代替当前链路的真实只读联调，更不证明实盘能力。
