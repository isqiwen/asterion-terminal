# ADR：训练标准化采用样本标准差

状态：已接受；纠正现有需求内部单一冲突，不重新解释或改写已有正式产物。

## 问题与权威核对

[分析统一计算契约](../requirements/modules/analysis/README.md#analysis-calculation-contract)明确标准差分母n−1，训练标准化保存训练均值及尺度。[特征构建](../requirements/modules/analysis/features.md)“时间语义与拟合顺序”及UI-ANA-FTR-01交互例均使用训练[1,3]、均值2、标准差√2、验证5输出3/√2。唯FR-ANA-FTR-02-04-AC01原写总体标准差1及验证输出3。

当前main/a717802及工作区已读需求/评审没有更新决定改用总体分母。架构评审的优先级为建议，不自动修改现有要求；不存在用旧代码反推规格的依据。本次修正按统一契约和两处一致例收口孤立验收文字。

## 决定与替代方案

采用均值Σx/n与样本方差Σ(x−均值)²/(n−1)。参数只用固定训练窗口中明确合格的训练成员拟合，保存方法、样本数、训练范围、均值及标准差，验证/预测只应用原参数，不重新拟合。标准化默认仍为否，开启须明确选择及实际实现。

选择总体分母n会要求同时改统一计算契约、两处数值例及既有统计口径，且没有支持该变更的更新权威，故不采用。不保留双重默认或根据页面选择不同分母。

n<2或尺度为0时训练标准化明确不可用/拒绝，不以1或任意小值代替；不能静默关闭所选处理。描述统计可按自身口径报告常数列标准差0，这不等于允许训练除以0。未选标准化时，正alpha岭回归的合法常量特征仍按回归合同处理。

数值验收：训练[1,3]得到均值2、标准差√2；验证5输出3/√2≈2.1213203435596424。改变验证值不改变已拟合参数；缺样本/零尺度拒绝并可定位。验证必须使用实际计算代码，不能只测试文档字符串。模型训练集、处理参数与实际程序身份进入原产物及恢复证据。
