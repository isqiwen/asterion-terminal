# 回测

本文说明当前 `asterion-backtest` 的 SMA 策略回测行为。任务提交、执行尝试、取消、显式重试和结果复核见 [任务生命周期](tasks.md)。

## 输入与执行

- 策略：均线策略，快线高于慢线时持有目标手数的多单，低于时持有空单，相等时空仓。“持仓方向”可选多空、只做多、只做空，不允许的方向空仓。反手时先平仓，平仓成交后的下一根 K 线再开对侧，见 [目标持仓到委托](trading.md#目标持仓到委托)。
- 输入：一个或多个合约（最多 20 个月份合约，普通合约必须覆盖共同交易日；主力连续的月份可只覆盖其交易区间）的固定版本数据集，由历史仓库中固定版本的 K 线与日线结算数据生成，不依赖下载任务记录（合计最多 200000 根 K 线，1 分钟线单合约约一年半到两年半）；资金、风险限额和 SMA 参数，以及每个合约按交易日生效的费用版本表（日期、来源、八项参数）。完整版本表固定在任务输入中，实验详情可查看；重试和结果校验沿用原表，不读取当前模板。
- 使用组合账本、撮合和风控（见 [交易与风控](trading.md)）：所有合约的 K 线按时间合并为一个事件流；普通合约各有独立的均线，主力连续的各月份共用一组均线；先把该合约上一事件的策略目标按当前费用和结算后的持仓转换为委托并撮合，再把当前事件交给策略。交易日末保留策略目标（不是活动委托）、撤销剩余委托，按当日交易合约的结算价结算，持仓续接；没有当日行情和结算价的月份必须无持仓。
- 回测输入版本为 8，引擎为 `asterion.backtest.sma.v11`；不接受旧输入，不自动改写旧任务。费用切换与持仓重估规则见 [交易与风控](trading.md#按交易日生效的费率)。
- 输出逐事件权益、手续费、最大回撤金额，以及逐日每个合约的结算价与持仓（净手数，多为正、空为负）。

## 绩效指标

结果页在读取结果时由固定的权益记录算出下列指标；它们是统计值，使用浮点数，不写入结果，也不进入账本。

| 指标 | 算法 |
| --- | --- |
| 总收益率 | 最后一个交易日的结算权益 ÷ 初始资金 − 1 |
| 最大回撤 | 逐事件权益相对此前最高点的最大跌幅，占该最高点的比例（最高点从初始资金起算） |
| 盈利交易日占比 | 结算权益高于前一日（首日与初始资金比）的交易日所占比例 |
| 年化收益率 | (1 + 总收益率)^(1 ÷ 年数) − 1，年数 = 首末交易日之间的日历天数（含首尾）÷ 365.25 |
| 年化波动率 | 逐日收益率的样本标准差 × √(交易日数 ÷ 年数) |
| 夏普比率 | 逐日收益率均值 ÷ 样本标准差 × √(交易日数 ÷ 年数)，无风险利率取 0 |
| 卡玛比率 | 年化收益率 ÷ 最大回撤 |

年化指标需要至少 20 个交易日，且各日结算权益为正；否则不计算，界面显示“—”。逐日收益率没有波动时没有夏普比率，没有回撤时没有卡玛比率。年化按日历时间折算，不假设一年有多少个交易日；数据中间缺交易日会拉长日历跨度，相应压低年化数值。

模拟成交和目标仓位替换以账户事务维护原子性：仅暂存持仓、费用、估值和活动委托，失败时撤销新委托与成交、恢复原有活动委托；已完成的历史记录不再整本复制。成交记录按几何比例扩容，撮合顺序、费用和保证金规则保持不变。

日线和分钟线均可作为输入。交易日、分钟标签、结算价、覆盖缺口、分段拼接及具名数据集的通用约束见 [数据集输入](market-data.md#数据集输入)。

## 主力连续与换月

新建回测时可在数据选择中选择“主力连续”，按交易所、品种、周期和来源选择已下载的月份组，填写合约单位后预览换月日程。每个品种使用一套费用版本表，固定到参与回测的各月份；当前具名数据集只保存普通合约，不能保存主力连续。

服务按前一交易日的持仓量选择当前月份，交割月份只向后推进，序列从具备前一日持仓量的交易日开始。换月日前一天的新旧月份结算价确定价格调整比例；调整后的行情只用于均线信号，委托、成交、保证金和结算始终使用真实月份价格。先平旧月、再开新月，不同时建立两个月份的目标持仓。缺少所需行情、持仓量或结算数据时拒绝解析，不补造数据。

月份数据及换月日程随任务输入固定，结果校验和显式重试使用相同输入。重新连接同一任务库保留当前选择；切换到另一任务库同时清空普通合约和主力连续选择，返回旧库仍可读取原任务结果。

## 观察时钟与历史可知性

策略只在当前 K 线处理完成后收到该根数据；由此产生的委托从下一事件开始参与撮合，
不能用当前收盘信号成交于同一根开盘。日终结算是模型的账本事件，结算价不会作为此前
策略可观察的行情事件。日线 15:00 标签只用于确定回放次序，不是供应商公布时间。
合约规格、费用版本与换月日程固定在实验输入；按交易日生效也不等于当时已公开可知。

每个市场与结算版本的取得证据随输入固定并展示。当前来源公布时间未知，结果仅证明
固定输入与既定撮合/风险模型下的回放，不能证明历史当时可取得这些价格和参考资料，
也不能据此确认严格历史可交易性。见[历史时间与可知性](market-data.md#历史时间与可知性)。

## 限制

回测组合没有跨品种保证金和相关性风险。主力连续仅用于上述历史回测，不为 CTP 交易自动换月；没有显著性检验，没有按笔统计的胜率和盈亏比。撮合的成交量约束及未建模因素见 [回测撮合模型](trading.md#回测撮合模型)。
