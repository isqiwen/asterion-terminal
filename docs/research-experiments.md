# 参数批量实验

实验属于 `asterion.research` 功能插件，复用已有固定输入回测与 Worker。核心不识别实验或参数含义：只提供事务内批量提交与按授权任务类型取消的操作。

## 使用

先在研究页选择固定日线版本、日期、策略工件、参数与规则，核对覆盖并确认研究假设。展开“参数批量实验”，填写名称、勾选变化参数并逐项添加候选值。整数、小数、开关与枚举使用相同声明式控件；未勾选参数保持上方配置。最多 4 个变化参数、2—32 个笛卡尔积组合，不支持空候选或完全重复候选值。

提交前校验组合的完整参数与字段间约束，读取一次共同的行情、规则和覆盖依据，并检查各组合的预热容量。实验记录与全部任务在同一个存储事务中写入；任何校验或写入失败都不留下部分任务。任务继续使用 `research.backtest` 契约，独立执行、租约与结果发布校验不变。

实验记录按当前账户列出最近 100 项；选择后每 3 秒刷新。表格保留全部组合的状态、净收益、最大回撤、费用与成交数，失败和取消不作为零收益结果。可进入单项运行查看详细报告、原输入重跑或导出复现包。“取消未完成组合”只取消仍排队或运行的任务，保留已完成结果；取消与发布使用既有状态/租约检查协调。

参数比较属于样本内研究，不构成样本外有效性证明。已提供[单次后续区间验证](research-validation.md)；不提供自动择优、滚动验证、步长范围生成、无限参数扫描或交易下单。

## 当前契约

`POST /research/experiments` 接受 `{name, base, grid}`。`base` 为完整 `BacktestRequest`，包含客户端生成的 `command_id`；`grid` 为参数键到候选值列表的映射。小数保持十进制文本，开关保持 bool。实验 ID 由账户及命令 ID 确定，同一命令与相同规范 JSON 输入返回原实验，不重复建任务；同一命令用于不同输入则拒绝。关闭窗口后，已提交的实验仍在实验记录中，不自动重提。

`GET /research/experiments`、`GET /research/experiments/{id}` 与 `POST /research/experiments/{id}/cancel` 受账户身份保护；详情与取消检查实验所属账户。实验分组归属不改变当前工作台共享研究运行记录的访问规则。

`research_experiments` 保存名称、账户、时间、提交规格、任务 ID 列表及规格/关联校验和。冻结任务自身保存输入摘要；备份验证实验规格、校验和和任务引用是否完整，不因验证实验分组执行外部策略。行情引用继续由各冻结任务报告。

核心通用变更仅为任务端口增加事务内 `cancel_batch`：检查连接、目标任务存在及全部类型授权，再取消未完成项。单任务取消复用相同底层状态变更；领域插件不能直接写核心任务表。
