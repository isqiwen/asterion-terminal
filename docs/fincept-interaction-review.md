# Fincept 实机参考与验证边界

2026-09-22 整理，合并 2026-09-21 至 09-22 的既有记录。观察对象为当时本机 Fincept Terminal v5.0.3；本文保留实际观察、设计取舍和未验证范围，删除已经被后续决定替代的实施方案。**本次整理只核对文档与代码，没有新增 Fincept 操作、界面测试或供应商验收。**

现行体验和视觉规范分别见 [终端体验](terminal-experience.md)、[UI 规范](ui-style.md)；模块边界见 [架构设计](architecture.md)。本文件是证据记录，不再定义另一套产品路线或优先级。

## 参考要求

按 [AGENTS.md](../AGENTS.md)，每次新增/修改 UI 或用户操作，实施前体验 Fincept 对应或最接近的任务，记录入口、步骤、反馈、空态、错误和恢复。遇到登录/PIN、应用退出或工具不可用时记录阻断，不使用未验证行为作依据；已验证的相关观察和星枢当前契约可支持独立完成部分。截图和源码阅读不能替代实机体验，凭据不进入记录。

后续新增记录包含：日期与任务、实际操作路径、实际观察、采用/调整、星枢验证及未验证范围。当前规范直接更新所属文档，不再追加互相覆盖的“最新方案”。

## 阻断记录

- 首次设置及部分 Linux UI 工作期间，工具返回 `apps: []` 或仅有无 Fincept 页面的浏览器，无法操作原生应用。Fincept Begin Setup、语言切换、下载、重试和成功跳转均未实测；用户提供的设置截图只作明确要求的视觉参考。
- macOS 某些安装/更新核对停在 Fincept 登录页，未发现登录前依赖管理入口；后续多次停在 TERMINAL LOCKED/PIN 或异常退出恢复提示。没有读取、填写或绕过用户认证，未验证 Fincept 安装覆盖、系统包管理器和凭据保护行为。
- 09-22 角色首次发布、层级数据目录、历史批量下载、分钟周期选择和通信刷新期间，没有可用的 Linux 原生 Fincept 控制入口；工作区检索也未找到可运行项目。对应国内期货业务流程与内部通知机制没有实机证据。
- 连接下拉颜色核对同样受原生工具不可用阻断。浏览器截图没有捕获系统弹出菜单，不证明 Linux WebKitGTK 弹出层配色已验收。

Fincept 多窗口联动、完整布局恢复、真实回测、订单、连接测试、数据源保存以及异常退出根因均未验证。源码层面的数据管理核对单独见 [固定提交审计](fincept-data-audit.md)，不能混作实机证据。

## 星枢采用与调整

| 用户任务 | 采用的已观察组织 | 星枢当前取舍与依据 |
|---|---|---|
| 工作台入口 | 搜索/分类/用途说明、局部工具栏、直接切换 | 主导航保持少量业务区；插件管理进入设置。侧栏 64/40px 来自维护者决定，非 Fincept 尺寸测量 |
| Dashboard | 组件目录、行情与账户区域、可解释空态 | 默认实时报价、账户与持仓、风险三块；无数据保留结构。历史行情不进入总览；约 6:4 分栏、按需编辑和提醒抽屉遵循 [UI 规范](ui-style.md) |
| 数据与角色 | 按需展开、结果/配置分区、来源与更新状态 | 当前固定资料、实际合约、交易日、首次计算和历史批量流程以星枢领域契约为准；没有借 Fincept 界面宣称国内期货规则已完成 |
| 研究 | BUILD/RESULTS 分区和无结果下一步 | 保留固定输入、已有草稿/修订和结果证据；不提前开放无验证的优化能力 |
| 连接设置 | 集中设置分类、有限参数表单 | connections 管理命名档案及唯一活动连接，接入插件描述字段，行情/账户分别消费能力；见 [连接设计](broker-connections.md) |
| 自选合约 | 名称/代码搜索、列表选择、单项移除和确认 | 采用未到期实际合约候选，按交易所/品种筛选，最多 50 个；在线保存、自选隔离和到期处理以 [接入契约](simnow.md) 为准 |
| 报价与账户 | 数字对齐、名称主列、涨跌符号、局部时效 | 最新价及涨跌额/幅用相对昨结算的语义色；名称优先简称+月份；未知/陈旧、空仓和零资产分开。只读查询不启用订单 |
| 安装 | 用户明确指定的五步截图与点击后统计 | 800×640、中英文、真实进度、重试、当前依赖和物理网卡统计；实际来源和失败保护由 [桌面运行](desktop-runtime.md) 定义，不推断 Fincept 内部实现 |
| 恢复与错误 | 可见恢复入口、保留快照的说明 | 只恢复视图和引用，不重复提交任务或恢复下单意图；错误不能隐藏在全局在线状态中 |

现行设计不再采用初版全量组件首页、无数据隐藏总览、历史报价填充总览、独立重复资金卡、固定常驻 Pulse、手输自选或数据库下载附件。此处只说明收敛范围；不保留旧 ID 别名、旧执行入口或另一套状态协议。

## 2026-09-22：数据预览首行被表头遮挡

- 任务与入口：前端 L4 工程归位后的回归，从“数据 → 数据集 → 交易日历 → 采集版本”返回最新版本，再点击首行“查看该行来源”。
- Fincept 参考尝试：本轮 `cua.getState()` 返回 `apps: []`、`browsers: []`，当前工具禁用原生控制；只读核对本机进程和监听端口未找到 Fincept 浏览器服务。目录检索仅找到下载的 Linux 安装器，没有可操作的应用或浏览器入口，未安装、启动或填写认证信息。已有 MARKETS 表格观察没有验证本次滚动和固定表头行为，不能作为已体验的证据。
- 星枢实际证据：Chrome 浏览器模拟用例在 1440×1000 下，数据预览滚动区被上方摘要挤到仅容纳表头；正常点击首行被“原始来源”表头拦截。错误记录与截图来自本轮回归，不涉及真实供应商数据。
- 修正依据：按现行“常用操作可达、信息可读”的交互契约，只为数据预览保留表头及数据行的最小可视高度，并为滚动定位留出表头空间；不移除来源证据、不采用强制点击。Chrome 在 1440×1000 与 1280×720 两种视口下均通过普通 Playwright 点击首行来源、进入原始预览及数据内容断言；没有使用强制点击。未验证原生 WebKitGTK 或真实数据源。

## 2026-09-22：外部插件层级收敛

参考入口为 Settings 中插件安装与停用流程。本次 `cua.getState()` 返回原生应用为空，只有无页面的 Codex 内置浏览器；无法体验本机 Fincept 的对应操作。已有 Settings 观察未覆盖插件安装，不作为成功体验证据。按维护者最新单层单责约束，Python ZIP 仅接受 L3 数据源或策略之一；删除跨层表格贡献和相应视图入口，保留安装预检、显式信任、运行诊断、停用与保留工件的移除操作。该调整依据当前架构契约，不引入未经验证的 Fincept 交互假设。

实施后的 Chrome 全量 63 项通过，其中插件页仍使用模拟服务；另以安装后 wheel 的真实 API/Worker 验证单功能包预检、信任启用、策略/数据源子进程执行和停用后拒绝执行。两类证据分别验证交互与执行，不能合并声称原生插件页已完成人工验收。日志见[本轮验证](validation/run-history.md#2026-09-22-rust-分层替换)。
