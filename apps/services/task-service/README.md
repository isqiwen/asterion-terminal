# asterion-task-service

下载、回测和因子任务及其执行尝试的持久化队列：幂等提交、进度、取消、显式重试、结果摘要校验。工作程序由 Node Agent 启动。历史文件、版本目录与具名数据集由独立的 `asterion-data-service` 保管，任务服务通过 Data RPC 获取固定计算输入和协调下载发布。见 [任务管理](../../../docs/tasks.md) 和 [行情与数据](../../../docs/market-data.md)。

任务服务不链接或运行回测、因子计算引擎。完成验收与结果读取验证产物身份、文件摘要及领域一致性；重新执行是显式的工作进程任务。

每个任务目录通过 `instance.json` 固定实例身份及配对的数据实例。Store 在任何恢复写入前核对绑定；未封印的已有目录明确拒绝，不自动迁移。

下载提交仅携带 Data 授权引用。Task 保存固定定义、插件摘要和非秘密引用；worker 直接向 Data 领取凭据，Task 不实例化历史供应商或保管供应商秘密。

运行时由单条状态与 I/O 线程接纳提交、预留容量和决定状态变化；一条日志线程提交封闭记录，
两条有界文件线程保管和核验输入/结果。请求在文件、日志和非阻塞 RPC 等待期间挂起，主线程继续
处理其他请求。公开、worker 和健康通道共用该主线程；确认后才公开新状态，失败保留证据并要求恢复。
恢复期间显式报告未就绪；退出受统一 400 毫秒排空期限约束。
验证与剩余资源预算工作见[架构实施进度](../../../docs/reviews/architecture-implementation.md#任务单状态与非阻塞-io)。
